# Работа с визуальными эффектами

Перед изменением боевых эффектов прочитать `docs/VFX_RENDERING_RULES_RU.md`.

- Режим смешивания брать из материала/шейдера беты для конкретного эффекта и конкретного использования текстуры. Аддитивный свет рисовать через `blendMode="add"`; AlphaBlended-частицы сохранять с обычным смешиванием.
- Не исправлять вид «краски» одним уменьшением размера или альфы: сначала проверить режим смешивания. Не переводить все частицы в аддитивный режим.
- Сохранять принятую пользователем молнию; не заменять готовые слои погоды и растворение карты без отдельной задачи.
- У `BetaGwentBoard.as` сохранять UTF-8 BOM и CRLF, правки интерфейса повторять в пяти копиях согласно плану проекта. Лимит меню — 65 МиБ.

# Актуальный рабочий процесс

- Начинать с README.md, docs/BUILD_RU.md и docs/AI_DEVELOPMENT_RU.md. Старые планы в drafts и пронумерованные отчёты описывают свои исторические этапы.
- Текущий вход сборки: Build-0.9.3.cmd. Обычная сборка использует новый каталог; продолжение — только явно заданный незавершённый --out.
- Сохранять постоянные build-inputs, toolchains, текущие готовые релизы и замороженные входы/результаты действующих испытаний. Перед очисткой проверять зависимости и reparse points.
- ИИ переносится из читаемого C#-исходника в JS, затем WS на одном движке правил. Не возвращаться к native C# host/.NET/RPC; нативные компиляторы WitcherScript остаются частью приёмки.
- Hard сохраняет ограничения скрытой информации; у «Классической» доступ шире. Указывать это в сравнениях. Ошибки тестов не считать поражениями.
- Публичный Git — source-only checkout BetaGwent/publication. Не отправлять нефильтрованную локальную историю с игровыми ресурсами. Инструмент экспорта описан в BUILD_RU.md.
