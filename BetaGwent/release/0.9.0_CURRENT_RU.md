Запустить `D:\w3mod\Build-0.9.0-Final.cmd`. Он по шагам:

   скрипты из release090-integrated + исправление сообщения очистителя,

переезжают в необязательную папку `Optional-CopyButton/bin/...` с README, документы в архиве обновляются.
Результат для публикации: `BetaGwent/build/release090-final/package-candidate/archives-optional`.
Архивы AllLanguages в этой папке (release) — старые, 0.8.2 polish2 с новым номером; их не публиковать.

## Что вошло

- Копирование (необязательная папка Optional-CopyButton; мод работает и без неё):
  «Копировать» и Ctrl+C пишут BG1 прямо в буфер Windows через
  `bin/x64(_dx12)/dinput8.dll` + `plugins/GwentBetaClipboard.asi`. Сигнатуры
  проверены независимо по установленным 1.32 и Next-Gen DX12 exe: ровно одно
  совпадение каждой; оба exe импортируют DINPUT8.dll. Без файлов bin кнопка
  честно сообщает, что копирование недоступно. Copy-Deck-Code.cmd остаётся запасным путём.
- Classic не вылетает в редакторе: в меню нет `size--` (Number declocal).
  Старый упаковщик package_integrated090 брал меню без этого исправления.
- Очиститель: при неудалённых стопках показывается только INCOMPLETE и функция
  завершается; сообщение об успехе больше не перекрывает предупреждение.
- Тексты Nexus (13 языков), changelog и CLEANUP обновлены; копии старых — в tmp/backup-texts090*.
