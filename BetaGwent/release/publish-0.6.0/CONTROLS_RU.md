# Управление

В коллекции и редакторе кнопка «Создать» находится прямо на карте и показывает стоимость в осколках. Она неактивна при нехватке осколков и исчезает при полном наборе копий. Создание не добавляет карту в колоду автоматически.

ПКМ до размещения отменяет выбранную карту из руки или лидера. Во время уже начатой способности ПКМ открывает полное описание отряда и не подтверждает цель; повторная ПКМ закрывает просмотр. I и Shift + клик также открывают описание.

Обозначения Xbox; на PlayStation: A=×, B=○, X=□, Y=△,
LB/RB=L1/R1, LT/RT=L2/R2, View=Touchpad. Настройка игры для перестановки
подтверждения/отмены учитывается. Подсказка на экране зависит от текущего выбора.

| Действие | Контроллер |
|---|---|
| Навигация по картам, вариантам и кнопкам | Крестовина / левый стик |
| Выбрать, сыграть, подтвердить цель или место | A |
| Назад / отменить ещё не сыгранный выбор | B |
| Полное описание и исходная сила карты | X |
| Пас | Удерживать Y |
| Меню действий | Start / Options |
| Своя колода | View / Touchpad |
| Свой / вражеский сброс | LT / RT |
| Переключиться между полем и рукой | L3 |
| Способность лидера | R3 |
| Ряд при размещении, включая пустой | LB / RB |
| Место вставки между отрядами | Влево / вправо, затем A |
| Страницы каталога, редактора или выбора | LB / RB |
| Длинное описание | Правый стик / LB / RB |
| Ускорить показ действий (повторно — пропустить) | A |
| Пропустить показ действий | B |

Редактор: A добавляет/убирает копию, LT убирает, RT добавляет; View переключает
список, Y открывает поиск, Start сохраняет колоду. При переименовании выбирайте
буквы, X стирает, Y ставит пробел, LB/RB меняет язык клавиатуры, Start принимает
имя. Затем сохраните колоду. Обязательный выбор после розыгрыша отменить нельзя.
Карантир позволяет выбрать пустой противоположный ряд LB/RB и подтвердить
мороз без перемещения отряда.

Мышь: выбор/перетаскивание; полупрозрачная карта показывает место вставки.
Особые карты можно перетаскивать прямо на допустимый отряд или ряд.
ПКМ, I или Shift-клик — полное описание.

Клавиатура: стрелки — цель/ряд, Enter — подтвердить, F — завершить необязательный
выбор, Esc — назад, удерживать P — пас, L — лидер, Space/Enter — ускорить показ действий, повторное нажатие пропускает его.

0.2.1: ←→ рука, ↑ ближайший отряд поля, ↓ с нижнего своего ряда возвращает к руке. Вставка: ↑↓ или LB/RB ряд. Start — кнопки действий; навигация целей не переходит на боковую панель.

Поиск и переименование: нажмите поле, выберите RU/EN, напечатайте текст и подтвердите Enter / «Принять». Пустая строка сбрасывает поиск.
Пас мышью: удерживать монету; короткий клик отменяет удержание.

В окне выбора способности: «Посмотреть стол» / Tab / Y временно скрывает варианты. Кнопка «Вернуться к выбору», Tab, Y или B возвращает окно; обязательный выбор сохраняется. В коллекции наведение выбирает карту и сохраняет кнопку «Создать», когда курсор уходит с карты.


## Выбор «до N карт»

Нажмите «Завершить выбор» после 0, 1 или любого другого допустимого количества карт. Клавиша F и действие завершения на контроллере работают с тем же запросом. Замены за уже выбранные карты Саскии нужно получить полностью.

## Навигация 0.4.5

Вверх/вниз переходят по соседним рядам и сохраняют горизонтальную позицию; при осмотре доступны пустые ряды. LB/RB при размещении следуют тому же порядку. Движение влево/вправо останавливается на краю ряда. Отмена размещения и возврат из осмотра поля возвращают фокус к прежней карте руки.

## Дополнения 0.4.6

В окне обмена или выбора карты перейдите вниз под карты к кнопкам и нажмите A для подтверждения. На экране результата таким же способом доступен выход. В пустой области редактора можно перейти в соседнюю область или к кнопкам.
Особые карты без выбора ряда разыгрываются на подсвеченную половину поля. На контроллере это одна область подтверждения, мышью доступны также промежутки между рядами.

## Дополнения 0.5.0

Во время партии удерживайте LT для своего сброса, RT для колоды, оба курка для сброса соперника. Отпускание возвращает к текущему выбору. В редакторе LT/RT по-прежнему убирают/добавляют копию.

В окнах выбора способностей и каталоге движение за горизонтальный край продолжает список в следующем ряду; после последней карты список возвращается к первой. Навигация по боевым рядам сохраняет границы ряда.

В меню действий доступны последние десять событий и пауза перед ходом ИИ: 0 / 0,4 / 0,8 / 1,2 с. Настройка паузы сохраняется независимо от уменьшенных эффектов. В списке колод доступен сброс изменённой стартовой колоды к стандартному составу.


Возможности 0.6.0:
- Анимированы только 21 лидер: на столе, в руке и в правом портрете при наведении. Обычные карты используют статичные изображения.
- Используются спокойные клипы Loop. Крупные анимации появления Intro исключены; граница короткого цикла сглажена перекрытием кадров.
- Загрузка отложена; одновременно допускаются три небольших портрета и один правый. Смена карты и перерисовка выгружают прежний ресурс. При ошибке остаётся статичное изображение. Режим кратких эффектов отключает анимированные портреты.
- Добавлено независимое переключение текста RU/EN: кнопка «Текст RU / EN» в верхнем левом углу меню колод/коллекции и пункт текста в боевом меню настроек. Выбор сохраняется вместе с сохранением игры.
- Каждый архив содержит одну озвучку: RU или EN. Смена текста не меняет озвучку. После игровой проверки 0.6.0 планируется пробная 0.6.1 с переводами для отзывов.
- Поиск карт учитывает оба языка. Введённые названия колод и строки поиска не переводятся.

Переключение RU/EN действует на экраны мода и описания карт. Названия предметов в инвентаре и уведомления вне этих экранов пока зависят от языкового пакета и языка игры.
