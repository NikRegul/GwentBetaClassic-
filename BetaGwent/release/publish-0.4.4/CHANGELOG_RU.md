# Gwent Beta Classic 0.4.4

Изменения относительно 0.4.3.

- Карты с формулировкой «до N карт» позволяют завершить выбор после любого количества карт, включая ноль: Бьянка, Ваттье де Ридо, Морвран Воорхис, Бран Тиршах и Саския.
- Добавлена кнопка «Завершить выбор» и счётчик уже выбранных карт. Лимит не принуждает выбирать все доступные карты.
- Ваттье вскрывает у противника столько карт, сколько было выбрано у себя. Бран укрепляет и сбрасывает только выбранные карты. Саския выдаёт замену каждой выбранной карте; этот последующий этап нельзя пропустить.
- ИИ может завершать необязательный выбор, если оставшиеся варианты не имеют положительной оценки. Способности с обязательным количеством целей сохраняют свои правила.
- Исправлено направление «Геральта: Аард»: ближний ряд → дальний → осадный. Осадные отряды остаются на месте. Если следующий ряд заполнен, отряд остаётся в своём ряду и получает урон.
- Добавлен редактируемый PowerShell-скрипт `tools/Build-0.4.4.ps1`: RU, EN или обе версии; автоматические проверки включены по умолчанию.

Поведение проверено сценариями реальной логики WitcherScript в тестовом окружении. Проверка взаимодействия в обычной игре остаётся необходимой.
