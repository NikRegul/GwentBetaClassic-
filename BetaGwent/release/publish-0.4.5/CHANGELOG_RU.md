# Gwent Beta Classic 0.4.5

Изменения относительно 0.4.4.

- Улучшена оценка шпионов с добором силой 13: Талер, Пугач, Яевинн, Удальрик и Кантарелла. ИИ учитывает полезность полученной карты и возможность компенсировать отданные очки, чтобы раньше разыгрывать полезного шпиона и сохранять преимущество при невыгодном позднем доборе.
- Прогноз добора использует состав собственной колоды без подсматривания её порядка. Проверки не изменяют настоящую колоду или случайные числа партии.
- Добавлены подробности оценки шпиона в лог решений ИИ.
- Улучшена навигация контроллера между рядами: сохранение колонки, остановки на пустых рядах при осмотре и единый порядок для стика, крестовины и LB/RB при размещении.
- Отмена размещения и возврат из осмотра поля сохраняют прежний фокус в руке. Горизонтальный переход не перескакивает в другой ряд; добавлено сглаживание диагонального дрожания стика.
- Добавлен редактируемый PowerShell-скрипт сборки `tools/Build-0.4.5.ps1` для RU, EN или обеих версий с автоматическими проверками.
