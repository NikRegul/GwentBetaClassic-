# Gwent Beta Classic 0.7.0-vfx1

RU test package for The Witcher 3 PC Next-Gen 5.01, with 13 selectable text languages. Includes the full 0.6.6 feature set and fixes to Scorch burning, Alzur lightning and original audio, repeated special-card portraits, simultaneous Mourntart consumption, animated/static leaders, battle settings and controller navigation.

Close the game and back up saves. Remove the previous Mods/modBetaGwent0924 folder, then extract Mods into the game directory. Install one complete voice package only. Remove the obsolete modBetaGwentReduxCompat if present. REDkit and Wwise are not required to play.

Hold RMB anywhere during replay for temporary acceleration; releasing restores your selected tempo. Short clicks do not accelerate. Controller A accelerates, a second A skips. Settings use four tabs and LB/RB. New UI additions support RU/EN with English fallback for other languages. Ordinary premium artwork is excluded. Original effects are adapted for GFx; complete Unity visual fidelity is not claimed.

See UPDATE.md for the detailed Russian changes and acceptance checks. In-game visual, audio and controller acceptance remains pending.
