# Controls

In the collection and deck editor, Craft appears directly on each card below its copy cap and shows the scrap cost. Insufficient scraps disable it. Crafting does not automatically add the card to your deck.

Before placement, RMB cancels the selected hand card or leader. During an ability already in progress, RMB opens full card inspection without confirming a target; RMB again closes inspection. I and Shift + click also open the description.

Xbox labels below; PlayStation equivalents: A=×, B=○, X=□, Y=△,
LB/RB=L1/R1, LT/RT=L2/R2, View=Touchpad. The game's swapped confirm/back
preference is respected. Follow the contextual hint bar for the active screen.

| Action | Controller |
|---|---|
| Navigate cards, choices and buttons | D-pad / left stick |
| Select, play, confirm target or insertion | A |
| Back / cancel an uncommitted choice | B |
| Full card details, including base power | X |
| Pass | Hold Y |
| Action menu | Start / Options |
| View your deck | View / Touchpad |
| Your / enemy graveyard | LT / RT |
| Switch board inspection and hand | L3 |
| Leader ability | R3 |
| Row while placing, including empty rows | LB / RB |
| Insertion before / after units | Left / right, then A |
| Pages in catalog, editor or card choice | LB / RB |
| Scroll long descriptions | Right stick / LB / RB |
| Speed up action playback (press again to skip) | A |
| Skip action playback | B |

In the editor, A adds/removes a copy, LT removes and RT adds a copy;
View switches the active list, Y opens search, and Start saves the deck.
The name screen accepts controller-selected letters, X deletes, Y inserts a
space, LB/RB switches keyboard language, and Start accepts the name. Save the
deck afterwards. Required played-card selections cannot be canceled; follow
the highlighted legal targets. Caranthir also supports an empty opposite row
with LB/RB and confirmation without moving a unit.

Mouse: select or drag a card; hover previews its insertion position. Special
cards can be dragged directly onto eligible units or rows. Right-click,
I, or Shift-click opens full card details.

Keyboard: arrows navigate targets/rows, Enter confirms, F finishes an optional
choice, Esc backs out, hold P to pass, L uses the leader, Space/Enter speeds up playback; press again to skip.

0.2.1: ←→ hand, ↑ nearest field unit, ↓ from your bottom row returns to the hand. Placement: ↑↓ or LB/RB row. Start opens actions; target navigation does not drift into the side panel.

Search and rename: click the field, choose RU/EN, type and confirm with Enter / Apply. An empty query clears the search.
Mouse pass: hold the coin; a quick click cancels the hold.

During ability selection, View board / Tab / Y temporarily hides the options. Return to selection, Tab, Y or B restores them; the mandatory choice remains pending. In the collection, hovering selects a card and keeps its Craft button available after the cursor leaves it.


## “Up to N cards” choices

Use Finish selection after zero, one or any permitted number of cards. F and the controller finish action use the same request. Complete all replacements for already committed Saskia cards.

## Navigation in 0.4.5

Up/down follows adjacent rows and preserves horizontal position; empty rows are accessible during inspection. Placement shoulder buttons follow the same physical row order. Left/right stops at the row edge. Cancelling placement or returning from board inspection restores the previous hand card focus.

## 0.4.6 controls

In mulligan and card-choice screens, navigate down below the cards to reach the buttons and press A to confirm. The match-result Exit button is reachable in the same way. Empty editor panes allow navigation to the other pane and the buttons.
Specials without a row target use the highlighted half of the board. Controller navigation offers one confirmation area; mouse casting also accepts the gaps between rows.

## Additions in 0.5.0

During a match, hold LT for your graveyard, RT for your deck, or both triggers for the opponent's graveyard. Release to return to the current selection. In the editor, LT/RT still remove/add a copy.

In ability choices and the catalog, moving past a horizontal edge continues the list in the next row; the final card wraps to the first. Battlefield navigation still stays within the current row.

The action menu opens Action History: the last 32 actions, chain details and inspection of public cards. AI turn delay: 0 / 0.4 / 0.8 / 1.2 seconds. Delay is saved independently of reduced effects. The deck list can reset an edited starter deck to its default roster.

Battle settings have separate flashes, shake, chain hints and leader scenes (off / short / full). These switches last until the menu closes. In the editor, Undo card reverses a confirmed addition/removal, but not crafting. In a keg, Reveal all reveals the first four cards; the fifth still needs an explicit choice.

## Languages and animations in 0.6.3

Every package contains all 13 text languages: English, Russian, German, French, Italian, Polish, Spanish (Spain), Spanish (Latin America), Portuguese (Brazil), Japanese, Korean, Simplified Chinese and Traditional Chinese. Use the language button at the top left of the deck/collection menu or the battle settings. The preference persists with your game save.

Download only one complete package with the voices you want: EN, RU, DE, IT or PT-BR. Every text language is included in every package. EN is the main universal download with English voices. Changing text does not change voices. The keg troll speaks Russian in DE/IT.

This is a translation preview. Card texts are based on official Beta localization; AI-translated interface text needs native-speaker feedback. ES-MX and ZH-TW adapt ES and SC interface text with official card names. Native vendor card items follow the game's language; some service messages outside the mod interface still use RU/EN.

The 21 leader card portraits are animated on the board, in hand and in the right-side preview. They use full motion cycles at 24 fps with a blended loop seam. A large two-dimensional leader play scene uses existing artwork. Original three-dimensional entrances and animated illustrations for ordinary cards are excluded. Reduced effects disables animated portraits. Static artwork remains on loading failure.
