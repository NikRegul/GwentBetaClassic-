# Gwent Beta Classic 0.6.1

Мод переносит Gwent Beta 0.9.24 в The Witcher 3: 479 коллекционных карт, 21 лидер, пять фракций и 46 архетипов соперников. Текущая версия рассчитана на PC Next-Gen 5.01; отдельная версия для 1.32 запланирована к 1.0.

В 0.6.1 — анимированные портреты только лидеров, 13 выбираемых языков текста и пять отдельных полных пакетов озвучки: EN, RU, DE, IT, PT-BR. В каждом пакете все языки текста; язык голосов задаётся установленным пакетом. Крупные анимации появления лидеров — отдельная будущая работа. Новые переводы интерфейса требуют вычитки носителями.

Причина падения при показе лидеров исправлена; пользователь подтвердил результат на RU. Полная ручная приёмка всех лидеров и голосовых пакетов ведётся отдельно от сборочных проверок.
