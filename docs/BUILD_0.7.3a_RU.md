# Сборка Gwent Beta Classic 0.7.3a

Ревизия Stage 190: ИИ, передача хода и золотая выкладка. RU прошла 79 наборов регрессий, нативную компиляцию 70 скриптов и четырёх меню, проверку архива и сохранности предыдущих выпусков. Максимальное меню — 63,23 МиБ при лимите 65.

Пользователь подтвердил в игре отсутствие прежних фризов и работу золотого эффекта/звука. Это приёмка запрошенных исправлений, а не полная проверка всех карточных сочетаний: `docs/evidence/user-performance190.json`.

Все пять пакетов завершены и проверены; итоговый отчёт — docs/evidence/voice-batch190.json.

## Пять голосовых пакетов

В настроенной рабочей папке:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-All-0.7.3a.ps1
```

Команда использует проверенную RU-ревизию Stage 190 и продолжает незавершённые EN, DE, IT, PT-BR. Существующие архивы проверяются, не перезаписываются. Для отдельной проверки завершённых пяти пакетов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-All-0.7.3a.ps1 -Verify
```

Пакеты: `BetaGwent/release/GwentBetaClassic-0.7.3a-{RU,EN,DE,IT,PT-BR}.zip`. У каждого есть `.zip.sha256`. Каждый ZIP содержит 13 переключаемых языков текста. Для игры выбирается один полный голосовой пакет.

## Проверяемые входы и результаты

- `docs/evidence/validation190.json` — общая RU-ревизия, скрипты, меню, CRC, manifest, SHA-256 и размеры.
- `docs/evidence/voice-batch190.json` — результат проверки всех пяти архивов после завершения партии сборок.
- `docs/evidence/job-budget188.json` — сравнение поисковой нагрузки с исходниками до правок; fingerprint новой стороны совпадает с Stage 190.
- `docs/reviews/2026-10-14-ai-gold-freezes.md` — разбор обоих пользовательских журналов, исправления и границы подтверждения.

Пять голосов собираются из одних замороженных игровых исходников; отличаются звуковой каталог и пакетный выбор языка по умолчанию. Банки озвучки сохранены без пересборки. Команда не устанавливает мод в игру и не публикует архивы.

Новый выпуск с изменёнными исходниками требует нового номера версии и нового этапа. Инструменты, лицензированные локальные ресурсы и окружение REDkit/Wwise остаются локальными зависимостями проекта.
