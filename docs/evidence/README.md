# Отчёты и входные данные

Здесь сохранены отчёты актуального аудита и данные, на которые ссылаются инструменты.
Часть исторических JSON является входом для генераторов графики, звука и упаковщиков;
их нельзя удалять только из-за номера старого этапа.

Повторяющиеся результаты экспорта меню, старые инвентаризации и журналы компиляции
убраны из текущего дерева. Точный перечень и способ восстановления находятся в
[записи очистки](../reviews/2026-10-19-repository-cleanup.md).

Для final9 вместо подробных дампов сохранены [тактика](final9-audit/tactics/summary.json)
и [выбор рядов](final9-audit/rows/summary.json): исходные счётчики, fingerprint,
SHA-256 полного отчёта и ссылка на него в истории. Сводки относятся к прежнему
прогону; новые игровые или тактические тесты при очистке не выполнялись.
