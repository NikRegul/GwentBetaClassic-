Дополнительно пользователь проверил bgboard_open() на 1.32: в логе есть BOARD_OPEN_REQUEST, но меню не открылось. Снимок после команд — `reported-debug-console.log`. Отдельное зарегистрированное BetaGwentBoard не является рабочим входом этой установки Classic; штатный DeckBuilder уже работает для редактора и NPC.

## Исправления

- `PendingAimSourceId` возвращает ближайшего видимого создателя из стека розыгрыша. У запроса остаются настоящий источник и шаблон заклинания: правила выбора и урона не переназначаются.
- Мост передаёт UI отдельный ID видимого источника и настоящий шаблон запроса. Стрелка использует источник текущего запроса, без подмены прежним выделением/анимацией. Прямой выбор цели картой из руки сохраняется. Лидеры используют своё место.
- Все пять копий BetaGwentBoard.as обновлены с сохранением BOM и CRLF. Молния, погода, растворение, материалы и смешивание не менялись; правила VFX прочитаны перед правкой.
- Подготовка Classic направляет только bgboard_open через DeckBuilder. Инициализация меню распознаёт явный betaPracticeRequested до сброса флага. Режим 0 сохраняет выбор соперника и тренировочное исключение наград. Обычный DeckBuilder/NPC без флага сохраняет прежнее поведение. Next-Gen использует BetaGwentBoard.
- Заморозка 0.9.1 теперь включает изменённый developmentBoardMenu.ws. Обе платформы компилируются с тем же мостом.
