# Classic 0.8.1: fix10 — inline оформление и регистрация вспомогательных SWF

Пользователь подтвердил: fix9 загружает колоды, предматчевый выбор карт и поле
боя. На скриншотах видны иллюстрации карт и фон поля; отсутствует значительная
часть оформления редактора и некоторые элементы боя. Полная приёмка не пройдена.

## Данные одного подробного запуска

`classic132-full-feedback/20261016-163520-783041`: exit 0, timeout false,
130691 событие, JSONL 1139348502 байта. Все временные инструкции восстановлены,
файлы мода/exe не изменились. Снимок `state-loaded-26654.dmp` — 6671094779 байт.
Обработка mmap не исполняет данные и читает только структуры меню/текстур.

`texture-state.json`: все 30 внешних CSwfTexture редактора загружены, класс
правильный, linkageName совпадает с ImageInfo. Поле resource flags=34,
texture flags=2. Все 30 имеют render object по +0xd0; root CSwfResource содержит
карту textures с count=30. Это исключает отсутствие файлов/handles именно
в сохранённом состоянии, но не доказывает успешную отрисовку всех BitmapData.

Нативные inline CSwfTexture имеют file pointer по +0x58 равный нулю; внешние
страницы имеют отдельный file object. Точная причина различий отрисовки не
установлена. Поэтому fix10 возвращает оформление, фон и эффекты в обычные
inline exports. Только девять атласов карт, которые уже видны на скриншотах,
остаются внешними. GFx, все texture chunks, пиксели, имена и размеры сохраняются.

После переноса 36 card pages четыре главных меню укладываются в native async
предел 32 МиБ. Максимум — 32679352 байта (31.165 МиБ). 388 файлов bundle,
381 CR2W, прежние 339 фильмов и 444 текстуры. Никакие атласы не удалены как
«неиспользуемые»; меняется размещение данных. Версия 5.0+ не изменялась.

## Вспомогательные фильмы

Лог фиксирует Loader failed to open для ru_ru.swf, страниц betagwentleaders
и betagwentleaderintros. Эти пути присутствуют в bundle и metadata. В snapshot
каталоги представлены CDirectory, но новые каталоги имеют flags=0 и files=0;
при этом hard imports CSwfTexture успешно проходят через метаданные напрямую.
По логу AS загрузок соответствующих RESOURCE_GATE/CR2W load нет.
Это отдельная проблема доступности вспомогательных ресурсов, а не их размера.

Для них подготовлен отдельный `DLC/dlcBetaGwentClassic132Assets/content`:
335 побайтово идентичных фильмов, dep.cache v2, metadata v6, uncompressed bundle v3
и `.reddlc` с CDLCDefinition / CR4ScaleformContentDLCMounter. Использована
фактическая схема установленного Classic dlc1: flags 8192/8200, parent 0/1,
ptr array на mounter; visibleInDLCMenu=false. Никаких quest/item монтировщиков нет.
Монтировщик регистрирует `gameplay\gui_new\` в Scaleform. Первичные сведения:
[CDPR DLC Mods](https://cdprojektred.atlassian.net/wiki/spaces/W3REDkit/pages/6328346).
В установленном 1.32 наличие класса и вызов регистрации подтверждены
disassembly `scaleform-dlc-mount-full.txt` / `scaleform-add-dlc-directory.txt`.

В первой проверке вспомогательные фильмы сохранены также в Mods: одинаковые
GUID и payload позволяют не менять ни URL в AS, ни существующие ссылки.
После игровой приёмки упаковку можно упростить, повторно проверив доступность.
Регистрация через DLC пока является проверяемым исправлением, не заявленной
игровой приёмкой: ожидаем подтверждения загрузки языка/анимаций и оформления.

## Проверка и установка

40 тестов Classic прошли, включая смешанные inline/external handles с
сохранением обеих текстур. Мод прошёл все 16 структурных проверок. Отдельный
DLC проверен независимым reader: 336 записей, 335 фильмов, один native definition,
CRCs/размеры/paths/hash IDs/GUID/dependency coverage/схема mounter.
Максимальная запись DLC — 3356022 байта.

Итоговая сборка: `classic081-native-resources-fix10`, версия
`0.8.1-classic-native-resources-fix10`. Вариант `classic081-inline-ui-fix10`
был промежуточным кандидатом и не устанавливался отдельно.
Установщик заменяет четыре файла мода, сохраняет fix9 в installed-before,
добавляет отдельный DLC и проверяет SHA всех семи файлов. Скрипты/звук/
сохранения и исходники AS не менялись. Агент игру не запускал, Computer Use
не использовался. Подробный сборщик теперь учитывает также SHA этого DLC.

Пользователь проверяет редактор, изображения и оформление, возврат управления,
затем NPC-партию с заменой карт и несколькими ходами. После подтверждения
Classic 0.8.1 — коммит и пуш, затем задачи 0.8.2 по согласованному плану.
