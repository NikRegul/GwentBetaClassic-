## Сохранено

Исходники WitcherScript, ActionScript и C++, подготовленный Classic, все
платформенные классы фрагментов атласов, данные карт/языков, тесты и инструменты
сборки сохранены. Неиспользуемые копии старых публикаций удалены; каталоги,
на которые ссылается код инструментов, оставлены. Старые файлы completion/release
и cooked-strings, имена которых собираются динамически, также сохранены.
Локальные игры, ресурсы, CleanBuild и рабочая папка разработки не удалялись.

Полные отчёты тактики и выбора рядов заменены отдельными сводками с сохранением
счётчиков и SHA-256 оригиналов. Сырые данные доступны по ссылкам из сводок.
Это прежние результаты аудита, а не повторный прогон тестов.

Убраны устаревшие CMD-обёртки сборок 1–8, UIReview и r5, старый Repack и Verify
с неверным умолчанием. Оставлены запуск final9, соответствующий исходникам,
и сборка моста r7. Для первой сборки на новом ПК используется
[полный автономный комплект](../BUILD_FIRST_TIME_RU.md).
Экспортёр final9 больше не копирует старые CMD и полные дампы тактики/рядов.
В `.gitignore` добавлены временные журналы и подробные результаты аудита.
Указатель документации обновлён с устаревшей 0.6.6 на 0.9.0.

## Проверка очистки

По Git blob-хэшам сохранены без изменений 2340 файлов игрового кода,
платформенного интерфейса и данных; ещё 815 оставшихся файлов инструментов
не изменились. В единственном изменённом экспортёре проверен синтаксис Python.
Проверены BOM/CRLF обоих исходников Board и локальные ссылки актуальных
указателей документации. Полная сборка и игровые тесты при очистке не запускались.

## Как восстановить файл

Точный список удалённых файлов, их размеров, SHA-256 и причин:
[2026-10-19-repository-cleanup.json](2026-10-19-repository-cleanup.json).
Любой файл доступен в [снимке до очистки](https://github.com/NikRegul/GwentBetaClassic-/tree/3e18306295b1a437f88c3f3b720442d974517ca3).
В обычном клоне можно восстановить нужный путь:

```powershell
git restore --source=3e18306295b1a437f88c3f3b720442d974517ca3 -- 'путь/из/отчёта'
```

Эта команда заменяет указанный рабочий файл его исторической версией; сначала
сохраните свои изменения в нём. После восстановления при необходимости
добавьте файл в отдельный коммит.
