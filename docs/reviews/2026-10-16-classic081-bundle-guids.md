# Classic fix7: восстановлены GUID в таблице bundle v3

fix6 не устранил дефект. Установка версии и SHA-256 dep.cache проверены;
накладка удалена. Свежий scriptslog сохранён в classic081-fix6-feedback.
В логе по-прежнему BOARD_CLOSED revision=0 без MENU_CONFIG_BEGIN.
Пользователь уточнил два сценария: при редакторе камера остаётся подвижной,
нажатия позволяют вернуться в игру; при попытке партии возникает загрузка,
из которой выхода нет. Эти сценарии не объявляются одним подтверждённым
внутренним отказом и требуют отдельной игровой проверки.

Упаковщик Classic write_bundle обнулял поле 16 байт после имени (offset 256)
в каждой 320-байтовой записи. В нативных bundle 1.32 эти поля содержат
идентификаторы из cook.db. Для обоих пересекающихся штатных путей,
r4deck_builder.menu и r4gwint_game.menu, GUID из frozen cook.db совпал с
байтами установленной игры. Например DeckBuilder:
ec6f6b305e8845937804b9e471bb86ca. Те же GUID содержатся в dep.cache.

Добавлены cook_guid_map и обязательная запись ненулевого GUID при упаковке
CR2W в Classic. Отсутствующий/нулевой/неправильной длины ID теперь приводит
к отказу сборки вместо очередного пакета с пустыми идентификаторами.
XML/CSV сохраняют прежнюю упаковку. build_resources и генераторы контролей
передают карту из frozen cook.db. Next-Gen bundle не меняется.

fix7 построен из неизменяемого fix6 путём изменения только полей GUID в TOC:
345 из 352 записей (345 CR2W плюс семь XML/CSV). Все GUID сверены с dep.cache.
Имена, offsets/sizes/CRC, заголовок, длина bundle и всё после TOC сохранены.
SHA-256 общего хвоста: 8308f8ed41dd7f263fbf6f5c5ae0ce3b9168d0e961150c2d24e0cc454377c183.
Metadata, dep.cache, весь Flash-код, текстуры, WS и аудио побайтово прежние.
33 теста Classic прошли, включая отказ при отсутствии GUID, запись в TOC и
сохранность payload. Архивы проверены по составу, SHA файлов и ZIP CRC.

Генератор tools/universal/package_classic_guid_fix.py. Артефакты:
BundleGuidPatch.zip 258529554 байта, AllLanguages.zip 517198954 байта.
Подробности: classic081-guid-fix7/verification.json.
Это подтверждённая корректировка упаковки, не доказанное устранение
пользовательского зависания: игровая проверка ещё необходима.
