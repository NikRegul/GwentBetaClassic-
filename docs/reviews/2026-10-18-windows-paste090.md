# Windows → игра: вставка кода колоды BG1

Кандидат `release090-final4`, 18.10.2026. Основа — final3 со всеми исправлениями
баннеров, обучения, корон и центра счёта. В установленную игру не копировался;
игровая проверка остаётся открытой.

## Поведение

Скопировать полный код BG1 в Windows и открыть импорт колоды. Код считывается
при открытии; кнопка «Вставить» и Ctrl+V повторно читают Windows.
Вставка запрашивает проверку состава, но не создаёт карты, не импортирует
черновик и не сохраняет колоду автоматически.

Пустой, занятый или неподходящий буфер, отсутствующий/старый ASI и ошибка API
оставляют текст поля и прежнее подтверждение состава без изменений. Сообщение
об ошибке переведено на 13 языков. Устаревшее содержимое внутреннего буфера
Flash больше не подставляется вместо текста Windows.

Для функции нужны новые меню и обновлённый `GwentBetaClipboard.asi` из
`Optional-CopyButton/bin/...`. Папка сохраняет прежнее имя для совместимости,
но обслуживает оба направления. Если используется чужой ASI loader,
обновляется только плагин. Папка bin находится рядом с Mods в корне игры;
файлы ASI/DLL — рядом с нужным witcher3.exe согласно README архива.

## Нативная реализация

`BetaGwent/native/clipboard/bridge.cpp`: чтение CF_UNICODETEXT выполняется
оконным потоком моста, уже использовавшимся для копирования. Чтение не вызывает
EmptyClipboard/SetClipboardData. Принимается только ограниченная строка BG1:
25–40 ID, допустимая фракция, положительные числа без переполнения, максимум
320 символов. Пробелы и переносы по краям удаляются; внутренние — отвергаются.

Запрос живёт в куче с двумя ссылками и событием. Ожидание чтения ограничено
1000 мс, при задержанном владельце буфера допускается только один незавершённый
запрос. Данные не обращаются к стеку игрового потока после тайм-аута.

Передача в AS3 использует существующий проверенный Boolean ABI setData,
без создания строк или объектов чужого VM. `windows-paste-v1` проверяет
возможность; `windows-paste-begin-v1` сохраняет один снимок в TLS; четыре
Boolean-запроса `windows-paste-bit-v1` кодируют символ алфавита BG1.
Ноль завершает строку. Все запросы символов читают один снимок, без повторного
обращения к Windows; AS дополнительно проверяет границу, алфавит и формат.
Сохранены структурный поиск двух callback slots, атомарная установка,
восстановление защиты страниц, закрепление DLL и прежний путь копирования.

## Проверки и артефакты

- `clipboard090-r6b`: MSVC /W4 /WX, DLL, ASI и тестовый exe собраны.
- 341 нативная проверка: оба установленных exe имеют по одному совпадению
  каждой сигнатуры; чтение внешнего Unicode-текста с 25 и 40 картами,
  пробелами/переносами; снимок при изменении буфера; пустой/неверный/слишком
  большой/занятый буфер; очистка устаревшего снимка; обе стороны копирования
  и прежняя регрессия зависания загрузки.
- Интеграционные тесты используют отдельную невидимую оконную станцию Windows
  с собственным буфером. Пользовательский буфер не изменялся.
- 80 проверок реальных AS-методов: кнопка и Ctrl+V, одно чтение на вставку,
  отказ без замены поля, старый/отсутствующий модуль, ограничение повреждённых
  ответов, локализация и пять BOM/CRLF копий для обеих платформ. Все символы
  нового сообщения и его верхнего регистра есть в шрифтах каждого из 13 языков.
- Регрессии: импорт 55, копирование 38, загрузчик баннеров 196,
  обучение/короны/центр цифр 166. Все прошли.
- Собраны восемь меню; все три новые строки протокола найдены в настоящих
  ABC dumps каждого меню. Старые texture chunks и Symbol IDs сохранены.
- WitcherScript не менялся: SHA каждого исходника, подготовленного Classic
  manifest и сохранённой компиляции проверены перед повторным использованием.
  `release090-final4/compile-reuse.json` фиксирует основание.

Готовые архивы и SHA-256: `BetaGwent/build/release090-final4/package-candidate/archives-optional`.
Проверки пакетов записаны в `release090-final4/windows-paste-verification.json`.

Игровая приёмка: с новыми меню и ASI скопировать полный код в Windows,
открыть импорт, затем сменить код в Windows и проверить «Вставить»/Ctrl+V.
Проверить отсутствие замены поля при обычном тексте, затем обычные шаги
проверки, создания недостающих карт, импорта и сохранения. Повторить экспорт
в Windows и загрузку сейва после копирования на Classic 1.32 и Next-Gen.
