# Сверка внешних замечаний перед 0.7.1

Проверены текущие исходники, а не присланные фрагменты. Изменения точечные; исправления Убийцы/Фрингильи и восстановления брони от другого агента сохранены. Внешний список содержит повторы и предположения, поэтому его пометки «критично» не приняты автоматически.

## Подтвердилось и исправлено

| Замечание | Результат |
| --- | --- |
| `ApplyDeckSummon`, индекс `-3` | Было преобразование в 0. Теперь отрицательный индекс по умолчанию означает конец ряда; `-4` по-прежнему означает позицию после источника. Проверены -3, -4, 0, 1 и индекс за концом ряда. |
| `CompletePlay`, обречённые особые карты | Метка 512 теперь отправляет разрешившуюся особую карту в удалённые карты, без смерти/Завещания. Обычная особая карта остаётся в сбросе. Исключение для временно сохранённого источника реакции Нильфгаарда сохранено. |
| `AiCardTempo`, погодный профиль | `Gain` действительно возвращает полную оценку, поэтому складывать её со старой нельзя. Но профиль вызывался и для не поддерживаемых им карт, теряя их обычную оценку. Добавлен `weatherAI.Handles(d)`: специализированная оценка применяется только к обработанным картам. Проверены Гром Альзура, Паразит и Гром, а также прежние погодные сценарии. |
| `BestOwnRow`, устаревший `aiPlacing` | Убрана зависимость от предыдущей оценённой карты. Определение текущей карты передаётся явно через `BestDeployRow`; общие вызовы используют нейтральное определение. Сохранена общая оценка риска ряда. |
| `Epidemic`, отсутствие целей | Вместо 2147483647 — «Эпидемия: нет подходящих целей.». Уничтожение всех отрядов с одинаковой минимальной силой сохранено. Новая строка переведена на 13 языков. |

Также удалён перезаписываемый начальный вызов `BestOwnRow` в `OpponentStep`.

## Уточнено явно, без изменения правил

- `GetRequestViews`: в ветке создания все варианты публичны. Раньше нулевой снимок уже давал `revealed=true`; теперь это выражено явно через `pendingChoice || ...`. Скрытая рука соперника остаётся скрытой.
- `BeginNextRound`: передавался последний снимок обхода, а не «мусор». Обработчик события 15 (начало раунда) не использует его как карту-источник. Теперь передаётся отдельный пустой `roundCause`, чтобы будущие обработчики не получили постороннюю карту.
- Комментарий в `AiSimChoice` объясняет, почему стратегическая поправка считается по состоянию **до** действия; комментарий в `BanishConsumed` объясняет сохранение исходной зоны для анимации поглощения из стопки.

| `AiChaseActual` fallback не учитывает бюджет | Он остаётся **недостижимым**, не превращается в обещание победы. `BetaGwentAIChasePassReason` проверяет reachable/расход; продолжение при угрозе проигрыша всего матча сделано намеренно. |

| `InitializeWithDecks` не сбрасывает наблюдение | Сброс всех перечисленных полей уже присутствует; `ClearAiPreparation()` тоже вызывается. Число 14 — начальная эвристика темпа, не пропущенный сброс. |
