# Аудит склеенных строк и переключателя языка текста (137)

Только отчёт: код мода не менялся.

## Как проверялось
- `tools/languages137/audit_concat_find.py` находит строки AS/WS, где русский литерал склеивается с переменной: 214 строк, без тестов и логов — 206.
- `tools/languages137/audit_concat_sim.py` повторяет на Python алгоритм `BetaGwentTextLanguage.translate()`: точное совпадение, иначе жадная замена фрагментов по границам слов. Прогон по словарям `build/languages137/ui/<locale>.json` для 9 локалей.

## Итог
Фрагментный перевод держит почти всё: каждый литерал из 206 строк находится в словарях. Реальные пробелы — два фрагмента, плюс грамматика и тексты вне Flash.

### 2. Числа и падежи — косметика, но заметная
Русский шаблон «N карт» переводится одной формой:
- DE/FR/ES/IT/PT: «1 Karten», «1 cartes»;
- PL: «1 kart», «3 jednostek» вместо «1 karta», «3 jednostki».

Места:
- `"+N осколков"` (collectionProfile.ws, developmentBoardMenu.ws:364);
- `" карт"` (Board.as 1480, 2005, 3218, 3269);
- `"Добавьте ещё N карт"` (deckBuilder.ws:37);
- `"N отрядов · N особых"` (Board.as 1480, 2218).

CJK не затронуты.

Решение: вместо «текст + число + текст» — один ключ с подстановкой, например `"Карт: {n}"` / `"{n} карт"`, и формы во словаре: `{one,few,many}` для PL, `{one,other}` для остальных. Минимально хватит формы «Карт: 5» — она у всех языков без склонения.

### 3. Порядок слов при сборке из кусков
`(side==1?"Ваш ":"Вражеский ")+"осадный"+" ряд"` (Board.as:400) во FR даёт «Ennemie rangée de siège» — прилагательное и род не на месте. Решение: 6 готовых строк «Ваш ближний ряд» … «Вражеский осадный ряд», они уже есть в словаре как подписи рядов.

Остальное (DE/PL/JP/ZH) читается нормально. Пример: «Runde 2 beendet · die nächste beginnt automatisch», «第 2 小局结束 · 下一小局将自动开始».

### 4. Тексты вне Flash — переключатель их не видит
`translate()` работает только в полях меню. Три места показывают текст движком игры, поэтому язык там берётся из сборки (RU или EN), а не из настройки мода:
- **Альманах гвинта (книга в инвентаре)**: `GetGwentAlmanacContents` → `BetaGwentAlmanac()` (collectionQuest.ws:47–58);
- **уведомление о повреждённой резервной копии**: profileBackup.ws:134;
- capabilityProbe.ws:80 — отладочное, можно не трогать.

Решение: строки w3strings (по языку игры). Witcher 3 сама выбирает файл по языку интерфейса игры, для всех 13 языков Беты есть пара. Это не зависит от переключателя мода, но для книги и уведомления это естественно.

## Переключатель языка текста — что уже сделано и что поправить
Другой агент уже сделал переключатель на 13 языков:
- `BetaGwentTextLanguage` лениво грузит `swf/betagwenttext/<code>.swf`;
- `tools/ui/build_languages137.py` берёт мои словари и шрифты;
- выбор пишется в факт `bg_text_language`.

Замечания:
1. **Язык хранится в сохранении**, а не глобально. Загрузка старого сейва или новая игра возвращают язык по умолчанию. Если нужно «выбрал один раз — навсегда», выбор надо дублировать в настройки игры (`user.settings`). Для этого:
   - группа в `bin/config/r4game/user_config_matrix/pc/*.xml`;
   - запись `theGame.GetInGameConfigWrapper().SetVarValue(...)` + `theGame.SaveUserSettings()`;
   - при чтении приоритет у user.settings, факт — запасной вариант.
2. **Сбой загрузки языка.** `languageFailed` сбрасывает загрузчик, но `language` уже равен новому значению. В итоге подпись показывает новый язык, текст остаётся русским, а шрифт — от прошлого языка. Нужно: при сбое откатиться на прошлый язык или на EN (2) и записать `UI_ERROR`.
3. **Перебор по кругу.** Кнопка листает 13 языков (`language%13+1`): от RU до 繁體中文 — 12 нажатий. Лучше выпадающий список или хотя бы LB/RB назад/вперёд.
4. **CJK-шрифты.** Проба `fonts/fontlib-probe`: 1,1–1,7 МиБ на язык (2 начертания, сжатый SWF). Их нельзя держать во всех меню сразу — только загружать по выбору, как сейчас и сделано. Нужна проверка в игре на лимите меню при CJK.
