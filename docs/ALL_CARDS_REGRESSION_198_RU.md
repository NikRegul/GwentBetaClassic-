# Прогон карт и редких ситуаций

`check_all_cards198.cjs` исполняет 511 игровых определений общего движка, включая 21 лидера, 458 остальных коллекционных карт и 32 служебные/создаваемые карты. Это не число звуковых записей или шаблонов исходных данных беты.

Для каждого определения: обе стороны и четыре сцены — обычное заполненное поле, пустая колода, пустое поле, последняя карта. 4088 случаев на платформу. Лидеры вызываются через настоящий `UseLeader`, а режимы Первого света — через родительскую карту и выбор режима. Для Чучела без целей проверяется корректный отказ. Разрешаются все возникшие запросы, проверяются завершение цепочки, отсутствие fatal, корректные идентификаторы и конечные значения силы/брони. Успешный розыгрыш сам по себе не доказывает правильность всех численных эффектов: для этого сохраняются отдельные регрессии.

Ещё 24 случая проверяют ничью при разных коронах, повторный пас без повторной выдачи корон, переход в следующий раунд с пустыми колодами и нативную ветку выбора результата при закрытии NPC-боя. Classic не имеет флага PlayerForfeited: его адаптер передаёт PlayerLost. Вызовы внешнего игрового API в этом тесте заменены наблюдаемыми заглушками.

Подготовка использует настоящие входы нативных компиляторов обеих платформ:

```powershell
python -X utf8 tools/ai/prepare_platform_rules198.py <готовая-сборка> <готовая-сборка>/rules <новый-выход>
node tools/ai/check_all_cards198.cjs <новый-выход>/classic <новый-выход>/classic/coverage.json
node tools/ai/check_all_cards198.cjs <новый-выход>/nextgen <новый-выход>/nextgen/coverage.json
```

Обычная итоговая сборка запускает этот этап сама. В отчётах записываются SHA исходников и проверяющего скрипта. Прогон идёт в JS-переводе подготовленного WitcherScript. Он **не означает**, что каждую карту сыграли в установленной Classic1.32 и Next-Gen. Игровые анимации, контроллер, сериализация сохранений и полная нативная матрица требуют отдельной приёмки.
