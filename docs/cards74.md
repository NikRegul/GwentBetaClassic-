# Этап74 — Кагыр и исправление коллекции

Кагыр аэп Кеаллах162104 отсутствовал из-за ошибки: фильтр коллекции
принимал Tokens512 за признак создаваемой карты. В исходной сборке
0.9.24 это `ECardToken.Doomed` — «Обречённость». Он не исключает карту
из редактора. Availability1/Kind1/Tier1,2,4,8 остаются критериями коллекции.
Оригинальные файлы клиента, TW3 и depot не изменялись.

## Что исправлено

- Все14 коллекционных карт с Doomed возвращены в полный каталог479.
  Получение у них, как у остальных, пока «не назначен».
- Кагыр добавлен как золотой отряд Нильфгаарда силы1. Он предлагает
  воскресить одного лидера из своего сброса с размещением и повторным
  выполнением его способности. Лидер на поле или ещё не использованный
  лидер не подходит. Кагыр сохраняет «Обречённость».
- Добавлены Шани, Ключник и Кухарка: ритуал, также пропущенные фильтром.
  Шани выбирает не проклятый бронзовый/серебряный отряд в своём сбросе,
  добавляет2 брони перед его розыгрышем. Ключник играет бронзовый/серебряный
  отряд из чужого сброса на своей стороне. Кухарка выбирает до двух
  бронзовых отрядов с исходным KilledTrigger, затем разыгрывает их по очереди.
- Медик из Виковаро, Эйвар Хаттори, Паулье Дальберг, Призрак Сабрины уже
  имели обработчики, но были скрыты в редакторе. Теперь доступны для колод.
- Исправлены расчёт остатка, проверки полноты, каталог, арты и текущий план.
  Исторические отчёты сохранены с пометкой о неверных прежних числах.

Нильфгаард71 обычная карта+4 лидера, Север67+4, Чудовища74+5,
Скоя’таэли66+4. Редакторы с62 реализованными нейтральными:133/129/136/128.
347/458 обычных карт реализованы; осталось111: Скеллиге60 и нейтральные51.
Это исправление прежнего подсчёта, а не добавление карт из DIY2025.

## Проверить Кагыра

Файлы уже установлены в проект. Перезапустить REDkit, открыть тестовый сейв
и выполнить `bgboard_open()`. В редакторе выбрать Нильфгаард, золотые отряды,
найти «Кагыр аэп Кеаллах» и добавить его в свою колоду, освободив золотой слот.

Использовать лидера в первом раунде; после очистки поля он должен оказаться
в своём сбросе. В следующем раунде сыграть Кагыра, выбрать лидера и место
на поле, затем выполнить его способность. При пустом сбросе лидеров
Кагыр остаётся на поле без воскрешения — это ожидаемо.

Компиляция74a explicitSuccess/exit0/no Script errors,43 active/prepared/
authoritative/compiled sources совпадают. UI/native/bridge собраны,
520 арт-привязок; все реализованные карты имеют арт. Backup73 сохранён.
Runtime74 человеком пока не проверен; общий scheduler/RNG, фракционные
правила и большой ИИ остаются отдельными задачами. UI не использовался.
