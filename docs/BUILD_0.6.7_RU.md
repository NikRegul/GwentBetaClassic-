# Сборка 0.6.7 RU / Stage 143

[Изменения и приёмка](PRESENTATION143_RU.md). Сборка использует подготовленное локальное окружение Windows/REDkit и русскую озвучку Stage 141, 13 текстовых языков и ресурсы вступлений Stage 142.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-0.6.7.ps1
```

Проверяются замороженные исходники `BetaGwent/build/audit143/final-v2`, результаты 51 набора регрессий, нативной компиляции 70 скриптов и четырёх меню, исходные и подготовленные текстуры огня/молнии. Затем выполняются cook, строки, звук, зависимости, упаковка, метаданные и архив. Уже созданный архив не перезаписывается. Python берётся из PATH; другой интерпретатор можно передать через `-Python`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-0.6.7.ps1 -Step verify
```

Финальный отчёт — `docs/evidence/validation143.json`, журналы — `BetaGwent/build/stage143/logs`. Проверяются скрипты, скомпилированный blob, меню и вступления, торговые запасы, звук, bundle, ZIP/CRC/manifest/SHA-256 и неизменность архивов 0.6.3–0.6.6. Установка в игру и публикация не выполняются. Свежему клону требуются локальные ресурсы и настроенный toolchain; программные проверки не заменяют проверку в игре.
