# Размещение отрядов: этап58

Лидер и бронзовый отряд из «Рассвет → Сбор» теперь используют тот же выбор
места, что отряд из руки. Нажать живого союзника — вставить карту перед ним;
нажать пустое место своего ряда — добавить в конец. Голубая линия слева от
союзника показывает место вставки. Внизу поля во время выбора показаны арт,
название и текущая сила входящей карты. Рука временно скрыта, потому что
новый розыгрыш во время незавершённого запроса недоступен.

Сила берётся из текущего состояния экземпляра. Например, усиленный в колоде
Накер показывается с накопленным усилением, а не с базовой силой каталога.
Закрытая рука и порядок колоды соперника не передаются для этого предпросмотра.

Для связки гарпия → яйца → вран выбрать яйцо как место вставки врана:
яйцо окажется непосредственно справа от него. Это доступно и при выходе
врана через Сбор. Соперник использует прежнюю эвристику выбора союзника для
врана также при вложенном Сборе; дополнительных случайных выборов нет.

## Выполнение

Flash передаёт revision, requestId и стабильный ID союзника. Игровая логика
заново читает позицию союзника, проверяет свой активный отряд, положительную
силу, отсутствие ожидания смерти и вместимость ряда9. Нельзя передать
произвольный индекс, выбрать противника или использовать устаревший запрос.
При отказе запрос остаётся открытым, карта и ход не расходуются.

Общий InsertUnit сдвигает последующие индексы, сохраняя ID всех карт.
Корневой розыгрыш из руки и лидер занимают исходный ход; Сбор сохраняет
существующий playStack и не вызывает дополнительный ClaimInitialMove.
Завершение вложенной способности по-прежнему возвращает управление родителю;
ход заканчивает только корневая карта. Особые карты через колоду сохраняют
свой путь через Stack256 без вставки в ряд.

Выбор лидера можно отменить до размещения. После размещения Дагон переходит
к обязательному выбору погоды и ряда соперника, Скрытый — к своей способности.
Ранее подключённые анимации перемещения отражают сдвиги позиций союзников.
