## Общие правила, определяющие ожидания

- [MoveCardsNode.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/MoveCardsNode.cs): из выбранного списка перемещается доступный по `RemainingCapacity` префикс. Узел возвращает `true` и при отсутствии места. Последующий `FlowOut` не отменяется. Поэтому ограничение вместимости нельзя автоматически переносить в каждый запрос целей.
- [Location.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/Location.cs), `GetCards`: исходный порядок — индексы ряда; исключены `IsInExecutionStack` и `IsWaitingToDie`. Обычная выборка сама по себе не исключает засады: это задают `Ignore` или следующий фильтр.
- [ExecutionStack.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/ExecutionStack.cs), `HandlePush`: `SetInExecutionStack` выполняется до `AbilityManager.OnCardPlayed`. Это основание исключать владельца из обычного списка ряда во время способности, включая Нивеллена и Киарана.
- [AListForeachNode.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/AListForeachNode.cs): обход списка идёт по индексам. [GetAvailableLocationsNode.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/GetAvailableLocationsNode.cs) и [BoardManager.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/BoardManager.cs), `GetAvailableLocations`, заново исключают полные ряды в момент чтения.
- [ListExt.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/ListExt.cs): `GetRandom` не тратит RNG для пустого списка, но обращается к RNG при одном элементе; `Shuffle` делает выбор с границами N, N−1, …, 2. Проверка этих отдельных случаев не закрывает весь поток случайных операций карты.
- [FilterCardTokensNode.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/FilterCardTokensNode.cs), [FilterCardPowerNode.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/FilterCardPowerNode.cs) и [FilterPowerLevelNode.cs](../BetaGwent/build-inputs/reference/beta-original-csharp/GwentGameplay/FilterPowerLevelNode.cs): набор жетонов, вид силы и отбор всех равных сильнейших задаются конкретными полями графа. `Ignore=8` и `Ignore=264` имеют разный смысл.

Машиночитаемые утверждения с независимыми ожиданиями, ID узлов, тестами и оставшимися вопросами: [rules_audit095_branches.json](../data/beta924/design/rules_audit095_branches.json). Каждый адресный отчёт сохраняет SHA графов и C# классов. Список узлов в отчёте — ссылка на источник; сам по себе он не означает доказанность каждого узла.

## Что остаётся открытым

Матрица содержит все 511 карт и 494 графа. Теперь **55** карт имеют хотя бы частичную независимую сверку; это **не 55 полностью доказанных способностей**. Сохранены прежние закрытые проверки силы/лечения, пулов создания и ранее исправленных карт. Новый JSON сохраняет обязанности по каждому узлу и явные вопросы для каждой карты; статус `confirmed-discrepancy-fixed` относится к исправлению, а не к полной способности.

Продолжение группы размещения: оставшиеся графы `MoveCards`, создание и размещение жетонов, возвращение в руку/колоду, воскрешение, превращение, последовательность внешних событий.
