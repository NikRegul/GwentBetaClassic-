# Gwent Beta Classic 0.7.4b

Исправление подготовки drawBacks в Scaleform. В 0.7.4a колоды открываются, но «Начать бой» приводит к нативному падению при первой отрисовке поля.

По разбору дампов пользователь определил метод по четырём параметрам: method_info 756 (0x2f4), code_length 1172, max_stack 27, max_regs 22 для Stage 198; тот же код в Stage 197 имеет другой номер метода. Параметры тела drawBacks совпадают с сохранённым дампом ABC. Проблемный код добавлен на этапе 191: необязательный вложенный for each с break, короткие логические условия и создание снимка статуса в одном цикле рисования.

drawBacks восстановлен на основе рабочего Stage 190: прежняя геометрия, открытые карты, инспекция и добор. Поиск скрытой карты/предыдущего раскрытия вынесен в enemyHandView191 с небольшими последовательными проверками и return. Отрисовка статусов и сохранение снимка вынесены в drawEnemyHandStatuses191. Статусы руки соперника сохранены, в том числе скрытие раскрытой карты. Порядок слоёв и анимации добора сохранены. Передача звука и запуск вступления остаются как в 0.7.4a; эксперимент с их переносом отменён до сборки меню.

Сохранены все эффекты 0.7.4: три стрелы Йотуна, Казнь Хеймдалля, начало/тики Рагнарёка, пивная пена, статусы и броня, исправления НГ+ бочек. Сохранены уплотнённый атлас, предел меню 63 МиБ, редактор и открытие бочек. Только RU-пакет Next-Gen. 0.8 и обновление 1.32 отложены до проверки пользователя.

Проверка: «Сыграем в гвинт» → колоды → «Начать бой» → вступление → обмен карт → первый ход; затем эффекты Йотуна, Рагнарёка, огня/пива и раскрытия/скрытия карт соперника. Сравнение исполнения исходных функций до/после проверяет поведение, но успешную работу нативного оптимизатора подтверждает только игра.

Офлайн-проверки: 81 набор регрессий; 110 проверок нового обработчика, включая 102 сравнения полного рисования и снимков статусов с Stage 198. В скомпилированном меню колод drawBacks: 1172 → 921 байт, 22 → 17 локальных переменных, 2 → 1 перебор hasnext2. Помощники: 162 и 139 байт. Данные эффектов elements164 и остальные классы UI совпадают с 0.7.4a. Подробности: docs/evidence/drawbacks-abc200.json и drawbacks-preservation200.json.

Локальная сборка из текущих исходников. Новые изменения требуют собственной игровой проверки.
