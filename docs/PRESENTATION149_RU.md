# Gwent Beta Classic 0.6.8b — вариант с прежним лимитом GUI

Основан на проверенной сборке 0.6.8. Три атласа частиц (Казнь/Игни/Жальница, Ирден и электричество) уменьшены вдвое по каждой стороне. Размеры, координаты, количество кадров и время эффектов сохранены; детали частиц мягче. Иллюстрации карт, портреты лидеров, тексты, правила и ИИ прежние.

Порог GUI остаётся 56 МиБ. Нативные меню пересобраны из отдельной копии UI; исходные изображения пользователя не изменены. Компиляция 70 скриптов и 52 набора регрессий переиспользованы после сверки идентичности. Дополнительно проверены сетки частиц и масштабирование. Отсутствие чёрного экрана проверяется в игре.
