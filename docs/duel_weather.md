# Погода и Рассвет — этап42

Написано, скомпилировано и установлено в проект. Пользователь сообщил,
что41 работает; лог подтверждает Сбор обеих сторон/выход из колоды/второй
раунд/наложение Мороза. Новые Туман/Дождь и анимации42 ещё не наблюдались.

## Игровое поведение

- Обе колоды25 карт: по2 Мороза,2 Рассвета,1 Туману и1 Дождю.
- Мороз113302/token1:2 урона одной случайной слабейшей карте перед ходом
  владельца ряда. Незаблокированные Всадники132310 напротив добавляют по1.
- Туман113305/token2:2 урона одной случайной сильнейшей карте. HighestLevel
  выбирает все ties, обходя stable ascending power ordering в обратную сторону.
- Дождь113312/token4:1 урона двум разным случайным картам. Исходный граф
  исключает Ambush8, перемешивает весь оставшийся список, затем берёт range[0,2).
  При одном отряде наносится один удар; пустой ряд не расходует RNG.
- Урон учитывает броню. Дождь завершает изменение силы обеих целей прежде,
  чем очередь погибших отрядов отправляется в сброс.
- Приоритеты BeforeTurn: melee−5/ranged−10/siege−15. Новая погода заменяет
  прежний token ряда; повторная не складывается. Конец раунда очищает погоду.
- Мороз и Дождь: minimum0/max1, можно сыграть без цели. Туман: min1/max1,
  требуется вражеский ряд. Лимиты генерируются из исходных портов графа.
- Рассвет → Чистое небо: запомнить повреждённых союзников под любым из трёх
  hazards, очистить свои ряды, затем усилить запомненные карты на2.
- Рассвет → Сбор: случайный бронзовый отряд из своей колоды, выбор своего
  незаполненного ряда. Выход отряда и Рассвет составляют один ход.
- AI оценивает новые hazards, предыдущую погоду и варианты Рассвета. Политика
  собственная; исходный AI Beta не заявляется.

## Внешний вид

18 DIY illustration bindings в native atlas768×540. Чистое небо113401 не имеет
отдельного файла DIY: явно использована иллюстрация родительского113303.
Мороз голубой, Туман светлый, Дождь бирюзовый; подпись показывает урон,
для Дождя — ×2. На обеих досках лёгкие снег/дымка/полосы дождя с появлением
за0.45s. Визуальное время отдельно от игровых RNG/ходов. Не более24 частиц
на ряд; redraw10Hz при30fps, clipped bounds, mouse disabled. Эффекты находятся
над картами и под окном замены/выбора. Полноценная очередь анимаций впереди.

## Источники и границы

[Графы](D:/w3mod/docs/evidence/duel-weather-source.json):
ability/0,1,2 — location tokens;56,58,65 — сыгранные weather cards;
57/71 — Рассвет/Чистое небо;156 — Всадник.
[IL41](D:/w3mod/docs/evidence/duel-weather-helpers-il.txt),
[IL42](D:/w3mod/docs/evidence/duel-weather42-helpers-il.txt) подтверждают
HighestLevel reverse tie order, Shuffle full list, ETokenOp, Add/Set replacement:
BeforeApply вызывает removal complement, затем Add; Apply записывает Token.
Rain graphOperation0 и Frost/FogOperation2 здесь оба заменяют row token.

Это закрытый subset, не весь AbilityManager/ExecutionStack. Полная native
RNG arithmetic/consumption и event parity не приняты. Остальные hazards,
weather immunity/ambush lifecycle, deploy/deathwish interactions не заявляются.
Текущие бронзовые отряды колод — Бес и Всадник: у них нет вложенного deploy.
Для будущей карты с таким deploy Сбор пока явно останавливается.

## Следующий обычный просмотр

После перезапуска REDkit: `bgboard_open()`, сыграть обычную партию с Морозом/
Туманом/Дождём и Рассветом. Посмотреть замену погоды и движущиеся эффекты на
обеих досках. Логи DUEL_WEATHER_APPLY/TICK/CLEAR, DUEL_FIRST_LIGHT_CHOICE,
DUEL_RALLY_PLACE помогают разобрать результат. Import/menuResource не нужен;
новые console suites не требуются.
