# Сборка Gwent Beta Classic 0.9.2

Дважды нажмите **Build_0.9.2.cmd** в корне `D:\w3mod`. Он соберёт оба архива: Classic 1.32 и Next-Gen 5.0+. Окно останется открытым с результатом. Путь к результату выводится в консоль и сохраняется в `BetaGwent/build/release092-latest.json`.

Это запуск сборки из данного рабочего проекта, а не отдельный установщик со встроенными исходниками. Нужны сохранённые ресурсы проекта, Python 3.11+ с psutil, Node.js и настроенные нативные компиляторы. Готовые интерфейс и музыка берутся из проверенного пакета h и сверяются по хешам. Игровые скрипты берутся из текущих канонических исходников проекта и замораживаются в новой папке сборки.

По умолчанию выполняются все проверки, обе компиляции и проверка CRC/SHA-256 архивов. Все процессы одной сборки вместе используют не более четырёх выбранных логических CPU. Существующие результаты не перезаписываются.

Проверить наличие основных файлов без сборки и установки:

```bat
Build_0.9.2.cmd --check-only
```

Продолжить прерванную обычную сборку:

```bat
Build_0.9.2.cmd --resume
```

Если указанная сборка уже полностью проверена и игровые исходники, стенд и инструменты тестов не изменились, можно повторно упаковать её под номером 0.9.2. Отличаются только номер и документация; происхождение проверок фиксируется в validation-reuse.json. При несовпадении входов режим завершится ошибкой, не пропуская проверки молча:

```bat
Build_0.9.2.cmd --reuse-validated BetaGwent\build\release091i-final2
```

Обычный запуск не устанавливает мод. Для сборки и установки в обе настроенные игры с резервной копией:

```bat
Build_0.9.2.cmd --install
```

Игры должны быть закрыты. Пути установки: `D:\GOG Galaxy\Games\The Witcher 3 Wild Hunt` и `F:\Steam\steamapps\common\The Witcher 3`. Установщик сохраняет обе предыдущие версии в `D:\w3mod\tmp\install092-backup-…` до первой замены, проверяет файлы и восстанавливает заменённые папки при ошибке. Сохранения игры и остальные моды не изменяются. Для записи в игровые каталоги Windows может потребовать соответствующие права.

Проверенный текущий выпуск: `BetaGwent/build/release092-final1`. Архивы находятся в `archives`, материалы Nexus — в `nexus`, отчёт установки — в `install-stage/installed.json` после её завершения. Новые ночные эксперименты со слабыми колодами ведутся отдельно и в этот выпуск не включены.

Красивое описание Nexus на 13 языках можно заново подготовить командой:

```bat
python -X utf8 tools\features092\prepare_nexus092.py
```

Предпросмотр: `docs/releases/0.9.2/nexus/preview.html`. Готовый текст для вставки: `NEXUS_DESCRIPTION_0.9.2.bbcode.txt` рядом с ним. Публикация на Nexus автоматически не выполняется.
