# Редактор колоды и коллекция в оформлении беты (0.9.6)

Продолжение окон выбора, итогов, истории, меню боя, сброса/колоды и диалогов: [BETA_UI_WINDOWS_095_RU.md](BETA_UI_WINDOWS_095_RU.md). Крупный показ награды сохранён на отдельной вкладке итогов. Звуки этих окон подключены; полное совпадение Unity-анимаций и игровая приёмка остаются открытыми.

Источник раскладки: префаб `UIDBPrefab` (`docs/beta-ui/deckbuilder_base.tree.txt`), масштаб 1600×900 → 1920×1080.

Продолжение 28.10.2026: [приёмка текущих изменений 0.9.5](UI_ACCEPTANCE_095_20261028_RU.md), [актуальная очередь](PLAN_096_RU.md). Пользователь подтвердил появление звука с вручную установленными кэшами; это не полная пересборка меню.

- Шапка: фракционный баннер с именем колоды (клик/A — переименование); строка имени в левой панели убрана, лидер под статистикой, список карт с y 338.
- Справа сверху: только осколки и бочки (`symbol_scraps`, `symbol_barrels`). Клик/A по бочкам открывает Лавк (`requestEditorExit(true)` в редакторе, `OnBetaGwentKegOpen` в коллекции); без бочек пункт неактивен.
- Центр: `Filters.Center` — фракция/только фракция/нейтральные + 4 уровня, поиск под ними; `FilterDropdowns` — 2×3 квадрата (сброс, новые, сортировка, наличие, тип, позиция), клик циклически меняет значение. Ступки нет; на её месте список активных фильтров. Сетка 6×186, карта 128 px. Фильтр позиции (рукопашный/дальнобойный/осадный/подвижные/событие) убран как устаревший: в сетке пять квадратов, сохранённое значение сбрасывается.
- Справа: `CraftPanel` (только «СОЗДАТЬ: −N», «есть n / max»; без измельчения и трансмутации), затем имя и описание.
- Коллекция: та же центральная панель и правая панель; слева — фракции со счётчиками (клик — фильтр) и источник получения карты. Лидеры — через квадрат «Тип».
- Все новые элементы регистрируются в навигации контроллера со своими прямоугольниками.

Ресурсы: `tools/ui/extract_editor_chrome096.py` (по одному атласу за запуск) → `BetaGwent/ui/assets/editor096`; `tools/ui/add_editor_chrome096.py` (однократно) кладёт 15 клеток в свободные места расширенного Elements (ячейки 29–43). Размер атласа и меню не меняется (+0 байт), блоки вне новых клеток побайтно прежние. Classic получает нативные классы клеток через `editor_vfx094.prepare`. Без расширенного атласа (другие меню) квадраты и ресурсы рисуются запасным способом.

Оригинальный `Banner_*` (1713×307 на фракцию) в бюджет Classic не помещается; баннер собран из фракционного фона заголовка.

Проверки обновлены под новую сетку: `check_editor_fx094`, `check_editor_feedback094`, `check_editor178`. Резервные копии: `tmp/backup-editor-chrome096-20261027`. Игровая проверка не выполнялась.

## Анимации строк колоды

`UIDBSlotAdd` (новая строка, после прилёта карты), `UIDBCounter` (изменение числа копий), `UIDBSlotRemove` (ушла последняя копия) — `BetaGwentEditorSlot096` + `BetaGwentEditorSlotData096` (генерирует `tools/ui/add_editor_slotfx096.py` из `BetaGwent/build/deck-slot096-recipes-20261027-02`). 48 кадров, шейдер AdditiveAlpha: текстура хранит RGB·A², множитель RGB = цвет·Brightness·alpha. Flare00 общий с ValidVFX (ячейка 28), остальные текстуры уменьшены до 40–48 px и лежат в ячейках 44–53. Проверка: `check_editor_slot096`.

## Бой с контроллера

- Текстовая панель подсказок справа в режимах боя заменена кнопками-глифами беты (A/B/X/Y, LB/RB, LT/RT, Start) с подписями; для PlayStation рисуются ×○□△/L1/R1. Учитывается обмен A/B. Панель появляется только при удержании паса (прогресс). Проверка: `check_pad_legend096`.
- Подсказка «завершить выбор» показывает Start (этой кнопкой открываются кнопки выбора).
- Подписи ходов (цепочки, подписи у карты, причины «без цели») по умолчанию выключены: факты `bg_show_help`, `bg_show_chains` (1 — включено), переключатели в меню сохраняются. Старый `bg_hide_help` больше не читается.

## Удержание паса на монете

`BetaGwentPassCoin096` по `GwentUnity.CoinVisualsControl` (level8, `CoinRoot/.../TurnCoin`; IL разобран `il.py`-дампом Assembly-CSharp, кривые из сериализованного MonoBehaviour):
- `fill = m_FillProgressCurve(hold)` — линейно до 1 к 65% удержания; корень эффектов поворачивается на `355·fill`, поэтому вспышка/искры/туман идут по кругу 55 px от 12 часов по часовой стрелке. Mist и Sparks — в мировом пространстве (остаётся след), Flare — в локальном (едет на «голове»). Темпы, время жизни, размеры, цвета и кривые — из модулей ParticleSystem.
- Шейдер монеты `_Blend=fill`: R-канал CoinMask — угловой градиент в кольце 0.7–1.0 радиуса; кольцо заполняется по часовой стрелке.
- `CoinShake`: кривая `m_CoinShakeCurve` (с 61.5%), смещение 0.5 ед. и наклон 15°.
- EndGlow — один раз при 97%. Отпускание до конца мгновенно гасит эффекты, как `EmissionDisable`.
- Наведение: подсветка `PassCoinOver` + MistEdge и SideFragmentEmitter по своим дугам.
- Одинаково для мыши, P и удержания Y/△; при уменьшенных эффектах остаётся только заполнение кольца.
- Ограничения: исходные текстуры частиц и шейдер монеты нарисованы градиентами (в атласе Classic нет места), цвет кольца подобран. Проверка: `check_pass_coin096`.

## Подсказки контроллера: одна полоса глифов (096, второй шаг)

- Текстовый виджет подсказок контроллера на экранах беты больше не показывается (`hintVisible:skin!=3`). Вместо него `updatePadUi096` каждый кадр строит полосу глифов беты по текущему режиму, устройству и обмену A/B: в бою — две колонки справа (подписи колонки выровнены по самой широкой группе глифов), на остальных экранах — строка по центру нижнего края (просмотр карты, редактор, коллекция, ввод имени, обучение, выбор, итоги, сброс, галерея, меню боя, вступление).
- Подсказки для мыши («Зажмите, чтобы спасовать», «Удерживайте ПКМ», строка колеса в просмотре карты) скрываются при игре с геймпада; «Осмотреть» и «завершить выбор» меняют значок мыши на X / Start без перерисовки.
- Подсветка монеты при наведении берётся из положения курсора каждый кадр и не включается с геймпада (раньше залипала, если поле перерисовывалось под курсором).
- Исправлено зависание: созданная Коровья туша (Разносчик заразы из колоды) предлагалась на своей стороне — сторона размещения созданных жетонов берётся из списка шпионов (`isSpyCard`), а не только из каталога коллекции.
- Звук удержания паса (`CoinTurnIndicatorSoundHandler`, поля по IL): `StartPassing`=2977021572 (одиночный звук, −3 дБ), `PassingConfirmed`=3893297074 (звук подтверждения + стоп StartPassing), `OpponentShortCoinToss`=3801975717; `LocalPlayerShortCoinToss`=3996867905 в банках беты отсутствует. RTPC прогресса 952843278 в банках не используется (кривых нет), поэтому звук не модулируется. Мод: AS шлёт `OnBetaGwentAudioPassHold` (1 — удержание выше 10 %, 2 — пас подтверждён, 0 — отпускание), WS `audio.PassHold`.
- Остальные звуки интерфейса беты (редактор: карта в колоду / из колоды, перетаскивание, сохранение; переключатели; сетка карт; просмотр карты: открыть / закрыть / листать, создание; всплывающие окна; история; итоги партии; кнопки) — 44 события. Импорт: `python -X utf8 tools/ui/add_beta_ui_audio096.py` на Windows (wwiser + vgmstream + WwiseConsole, все пять проектов BetaGwent79, отчёт `docs/evidence/stage096-ui-audio.json`). Уже привязаны: удержание паса, карта в колоду / из колоды, переключатели и квадраты фильтров, открытие / закрытие / листание просмотра карты (`audio.Ui` 6–13). До пересборки банка эти события молчат.
