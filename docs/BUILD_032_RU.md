# Сборка Gwent Beta Classic 0.3.2

Рабочий каталог: `D:\w3mod`. Скрипт: `D:\w3mod\tools\Build-Stage111.ps1`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-Stage111.ps1 -Language both
```

Для одного языка укажите `-Language ru` или `-Language en`. Для повторного извлечения кадров Лавка добавьте:

```powershell
-KegVideo "C:\Users\NikR\Videos\Captures\Gwent 2026-10-08 00-12-24.mp4"
```

Нужны установленный REDkit 5.01 с depot `D:\w3mod\depot`, созданный проект `D:\w3mod\GwentB\myproject1`, Python с Pillow, numpy и av, Node.js, Apache Royale и Flex из `tools\vendor`, Microsoft JDK 11 и Wwise 2023.1 с лицензией. Лицензию Wcc принимает пользователь заранее. Лицензионный ключ Wwise в архив и Git не включается.

Для нативной сборки арабского файла описаний REDkit требует `D:\GOG Galaxy\Games\The Witcher 3 REDkit\r4data\tmp\arial.ttf`. Если файл отсутствует, скопируйте туда установленный системный `C:\Windows\Fonts\arial.ttf`. Шрифт нужен только компилятору; он не включается в мод или Git.

Авторский код не включает все исходные материалы игры. Для полной сборки нужны уже извлечённые оригинальные изображения, звук, атласы и ресурсы проекта. Публичный Git сам по себе не заменяет этот рабочий каталог.

Скрипт последовательно:

1. Обновляет атласы стойкости и открытия бочки, полный каталог и копирование состояния для ИИ.
2. Проверяет настройки паузы меню, восстанавливает базу упаковки, подготавливает звук и WitcherScript.
3. Компилирует RU-скрипты в новом каталоге и фиксирует хеши входных исходников.
4. Собирает четыре меню RU, проверяет связи AS/WS и нативные ресурсы, затем упаковывает RU.
5. Переводит исходники на EN, собирает четыре меню EN, отдельно компилирует EN-скрипты и упаковывает EN.
6. Восстанавливает RU-меню в проекте REDkit из проверенных файлов.

Параллельный запуск скрипта блокируется файлом `BetaGwent\build\stage111-build.lock`. При повторной сборке старый ZIP переносится в `BetaGwent\release\old`, а промежуточный каталог конкретного языка пересоздаётся. Опубликованные архивы прежних версий не перезаписываются.

Результаты: `D:\w3mod\BetaGwent\release\GwentBetaClassic-0.3.2-RU.zip` и `GwentBetaClassic-0.3.2-EN.zip`. Отчёты: `D:\w3mod\docs\evidence\stage111-*` и `D:\w3mod\BetaGwent\build\release111`.

Скрипт не устанавливает мод в основную игру и не публикует файлы. Компиляция, хеши и проверки упаковки не заменяют проверку загрузки, сохранений, ввода и графики в установленной игре.

Wcc после записи успешно скомпилированного blob может зависнуть при завершении. Обёртка завершает только свой процесс после сообщения об успехе и стабильного размера и SHA-256 файла; отчёт сохраняет реальный код процесса и `completedByOutput`. Ошибка компиляции, изменение входных исходников или тайм-аут останавливают сборку.
