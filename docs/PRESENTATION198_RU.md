# Gwent Beta Classic 0.7.4a

Исправление загрузки меню после 0.7.4. Пользователь сообщил о бесконечной загрузке сразу после «Сыграем в гвинт», до колод. В логе остаётся PROBE_GWENT_REQUEST; новый дамп падения не появился. Меню 0.7.4 весит 64.507 МиБ, предыдущий кандидат 63.377 МиБ загружал интерфейс. Порог около 64 МиБ — рабочая гипотеза, которую необходимо подтвердить в игре.

Атлас эффектов перепакован по отдельным ячейкам вместо целых семейных страниц: 2048×3968 → 2048×3136, 7.75 → 6.125 МиБ. Все 1112 ячеек, размеры и пиксели совпадают; 43 рецепта частиц не изменились. Сжатие, разрешение и качество текстур не понижались; эффекты не отключались. Для новых сборок установлен предел 63 МиБ с запасом. Добавлена ранняя строка MENU_CONFIG_BEGIN для диагностики открытия меню.

Сохранены все изменения 0.7.4: НГ+ бочки, три стрелы Йотуна, Казнь Хеймдалля, начало/огненные тики Рагнарёка, пивная пена, статусы и броня. Редактор, открытие бочек, принятая молния, погодные слои и растворение карт сохранены.

Требует игровой проверки: сначала открытие колод у NPC, затем запуск боя и вступление лидеров. Прежнее падение при вступлении и новое зависание до колод — разные наблюдаемые точки. Исчезновение загрузки само по себе не подтверждает устранение прежнего падения.

Локальная сборка из текущих исходников. Новые изменения требуют собственной игровой проверки.
