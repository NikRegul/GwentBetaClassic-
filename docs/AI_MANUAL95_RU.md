# Как вручную менять ИИ Gwent Beta Classic

Основной файл стратегии:
**D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelArchetypeAI.ws**.
Меняйте исходники в BetaGwent/development. Копии в GwentB/myproject1/workspace и
BetaGwent/build/board-patch создаются автоматически и будут перезаписаны.

## Самая простая настройка лидеров

Файл: **D:\w3mod\data\beta924\ai\tuning95.json**.
После правки выполните `python -X utf8 tools/build_ai_tuning95.py` из D:\w3mod.
Он создаёт duelAITuning.ws; сгенерированный WS вручную менять не нужно.

- `leaderReserveByRound`: штраф за расход лидера в раундах 1, 2, 3.
  Сейчас [12, 8, 0]. Больше значение — ИИ дольше бережёт лидера.
- `leaderMinimumAbilityGain`: минимальная польза способности сверх тела лидера.
  Сейчас 3. Это ограничитель обычного использования, а не прибавка к счёту.
- `leaderMinimumAbilityGainByTemplate`: исключения по ID карты. У Кальвейта
  (200164) стоит 8: слабое содержимое верхних трёх карт не оправдывает ранний ход.
- `leaderOpeningMinimumAbilityGain`: дополнительный порог в начале первого
  раунда. Сейчас 10; действует при руке не меньше `leaderOpeningHandSize` (8).
- `ordinaryPool`: оставьте `active_archetypes`. Используются 40 активных
  адаптированных колод. Перемешанный пул проходит все 40 перед новым циклом;
  на границе циклов одна и та же колода подряд не выбирается. Пул живёт в
  менеджере текущей игровой сессии; после перезапуска создаётся заново.

Исключения: лидер может закрыть отставание после паса без расхода карты руки,
может пригодиться при пустой руке или в решающем раунде. Полезные лидеры,
которые заранее подготавливают комбинацию, также учитываются отдельно.
Поэтому повышение порога не означает полный запрет лидера до третьего раунда.

## Стратегия конкретных карт и архетипов

Файл: **D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelArchetypeAI.ws**.

- `Priority(d)` — порядок розыгрыша. Положительное значение повышает приоритет;
  отрицательное помогает сохранить карту. Результат ограничен от −18 до +18.
- `Mulligan(card)` — какие карты заменять; выше значение — предпочтительнее замена.
- `Reserve(d)` — какие карты сберегать для следующих раундов.
- `DiscardValue(target)` — выбор карты для сброса, включая возвращающиеся отряды.
- `PileGain`, `CopyValue`, `PublicDeployGain` — реальная польза воскрешения,
  копий и усиления Импера по уже открытым шпионам.
- `PlacementAnchor` и `Row` — вставка возле нужного отряда и выбор ряда.
- `LeaderGain`, `LeaderPriority` — дополнительная оценка и подготовка лидера.
- `DryPass` — отдача пустого второго раунда после победы в первом при
  сохранённом преимуществе по картам; это осознанный пас, а не ошибка пустой руки.

Например, существующая проверка `id==200046 && situation.roundNumber==1 && horizon>=2`
добавляет приоритет раннему усилению армии. Меняйте условия и величину внутри
Priority. Для конкретного профиля добавьте проверку `profile==...`; номер есть
в rules.json. Не добавляйте стратегические бонусы в текущую силу карты!
Текст в deck_rules сам по себе не исполняется как программа: новые исключения
и порядок действий нужно реализовать в этих функциях либо таблицах генератора.

## Общая оценка, цели и пас

**D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelSession.ws**:

- `OpponentStep` сравнивает варианты и выбирает ход.
- `AiCardTempo` оценивает очки; `immediate=true` используется для догоняния
  после паса. Ожидаемые будущие срабатывания сюда добавлять нельзя.
- `AiManagedDeployValue` оценивает сложные способности. Кальвейт смотрит только
  три реально верхние карты своей колоды, а не лучший отряд всей колоды.
- `AiAbilityChoiceValue` и блок `MonsterRequest` выбирают карту/цель способности.
- `AiTimingReserve` помогает не тратить реактивные карты ради одного тела.

**D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelAIPass.ws**:

- `BetaGwentAIChasePassReason` — стоит ли догонять после паса игрока, сколько
  карт уже потрачено и сколько останется на следующий раунд.
- `BetaGwentAIEarlyPass` — можно ли заставить игрока потратить несколько ответов.
- `BetaGwentAIConcedeOptionalRound` — когда сохранить руку вместо дорогой погони.

**D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelWeatherAI.ws**
содержит отдельную стратегию Мороза: муллиган, расстановка, перемещение и контроль.

## Составы, комбинации и движки

**D:\w3mod\deck_rules.txt** — пользовательские описания и исходные списки.
**D:\w3mod\tools\build_ai_rules.py** — их импорт, явные aliases/substitutions,
массив configs (семейство и базовый пресет), combo_names, engines, finishers,
resurrectors. Вес combo_names влияет на порядок подготовки и активации связки.
**D:\w3mod\data\beta924\ai\rules.json** — отчёт адаптации, 46 профилей,
40 активных, ID карт/пресетов, изменения составов. Это генерируемый отчёт.
**D:\w3mod\data\beta924\duel\presets.json** — фактические готовые составы.
**D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelAICatalog.ws**
и duelCatalog.ws — сгенерированные таблицы, их правки будут затёрты генератором.

Не запускайте импорт просто для изменения лидерского порога: он заново
формирует составы из deck_rules и может затереть ручные изменения presets.json.
Для изменения списка осознанно обновите deck_rules и генератор, затем выполните
build_ai_rules.py → build_duel_catalog.py. Текущий импорт ожидает 46 блоков;
для нового блока дополните configs. Сохранённые/квестовые ID 1–53 не перенумеровывайте.
Не переносите способности DIY в строгую Beta 0.9.24 под видом замены карты.

## Применение и сборка

Редактирование этих файлов не меняет уже установленный ZIP. Нужна новая
компиляция WitcherScript и упаковка. Пример следующей локальной версии:

```powershell
Set-Location D:\w3mod
# Только если меняли tuning95.json:
python -X utf8 tools/build_ai_tuning95.py
python -X utf8 tools/ui/prepare_board_scripts.py
python -X utf8 tools/recon/run_redkit_compile.py --out BetaGwent/build/manual-ai-001 --patch BetaGwent/build/board-patch --timeout 120 --terms-already-accepted
python -X utf8 tools/build_presentation94.py --stage 98 --language ru
python -X utf8 tools/package_presentation94.py --stage 98 --version 0.2.4-ai.1 --language ru --compiled BetaGwent/build/manual-ai-001
```

`--terms-already-accepted` применим здесь потому, что ты уже лично принял
условия Wcc. Используйте новые каталоги компиляции/этапа и новую версию ZIP;
старые архивы не перезаписываются. В REDkit после замены скриптов/ресурсов
полностью перезапустите редактор, чтобы сбросить кэш. Для обычной игры закройте
её и установите новый Mods/modBetaGwent0924; сохранения предварительно скопируйте.

Необязательные быстрые проверки: tools/core-check/check_pass_policy.py и
check_ai_rules.py. Первая запускает реальные чистые функции решения в C#,
вторая проверяет легальность составов и базовые политики; они не заменяют бой.

## Что смотреть в логе

**D:\GOG Galaxy\Games\The Witcher 3 REDkit\bin\editor.log**.
`DUEL_AI_POOL` — выбранный пресет и оставшиеся колоды цикла.
`DUEL_AI_ARCHETYPE` — профиль; `DUEL_AI_TACTIC` — оценка карты;
`DUEL_AI_LEADER` — ID, польза, тело, резерв и причина;
`DUEL_AI_CHASE` / `DUEL_AI_PASS` — стоимость догоняния и причина паса.
Для спорного хода запишите раунд, счёт, размеры рук и открытые карты.
Текущий ИИ — эвристический: полного поиска на 25–30 секунд пока нет.
