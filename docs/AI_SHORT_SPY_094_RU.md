# Исправление короткой руки со шпионом для 0.9.4

В `AiSpyConcessionWindow` перенесено ровно одно исправление из проверенного кандидата `BetaGwent/build/ai-improvement-20261026/short-spy-candidate-01/rules` (fingerprint `61f5dae6202a648e2cbb3908cffeea2fd9577bd428296653335ee485cb79986e`). Исходник `duelSession.ws` после переноса побайтово совпадает с кандидатом: SHA-256 `70eafc4f46e76a41f54c706369437d80b29c3f5b7a925b699979e08b4488c7cb`.

Ошибка: в уже развитом первом раунде ИИ с одной-двумя картами и видимым отставанием по числу карт отвергал полезного шпиона с добором перед сдачей раунда. Теперь этот вариант допускается без обязательного перехвата необязательного раунда. Сохраняются ограничения: первый раунд без корон, противник ещё не спасовал, потрачены минимум три собственные карты, нет преимущества по очкам и скрытой ловушки. В оценке используются открытые сведения противника и прогноз по неупорядоченной собственной колоде. Ограничения скрытой информации Hard не меняются; у «Классической» доступ шире.

Проверка `tools/ai/check_short_spy094c.cjs` воспроизводит позиции t16 и t18 одной исторической партии из турнира. Они не считаются независимыми матчами. Проверены 24 сочетания позиции, сложности 3/4, ослабления 0/40/70 и пошаговой подготовки. Кандидат прошёл 1540 проверок, включая сохранение руки и лидера, защитные условия, независимость от реальных скрытых карт противника и не более одного симулированного действия за callback. Исходная shipping-версия провалила 48 проверок этого же теста: это ожидаемый отрицательный контроль ошибки, а не игровые поражения. Результаты сохранены в `BetaGwent/build/ai-short-spy-integration-20261026-01/`. Повторная генерация `duelClone.ws` не изменила файл.

Историческая общая регрессия кандидата: 94 группы без ошибок. A/A: 368 игр, 92 зеркальных блока, ровно 50%, технических ошибок нет. Development: 368 игр, 181 победа / 181 поражение / 6 ничьих, технических ошибок нет, результат 50%. `accepted=false`, `confirmedBetter=false`; holdout по заранее заданному правилу не запускался. Общий прирост силы не доказан. В 0.9.4 это включается как подтверждённое исправление конкретного поведения. Замороженные результаты турнира и сравнений сохранены без изменений.

Кандидат отдельно прошёл нативные компиляторы NextGen и Classic в `BetaGwent/build/ai-short-spy-native-20261026-01/` и `BetaGwent/toolchains/classic-runtime/runs/ai-short-spy-native-20261026-01/`. На момент переноса исторический `whole-js-ws.json` ещё имел `complete=false`; он не считается завершённой приёмкой. Итоговая 0.9.4 с изменениями сохранений должна пройти собственную проверку замороженных входов, полную регрессию, паритет и нативную сборку.
