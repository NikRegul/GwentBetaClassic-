## Изменения

- В SoundLoadBank/SoundIsBankLoaded/SoundUnloadBank применяется единое имя
  **betagwent79.bnk** в нижнем регистре, как у штатных банков.
- В созданном пользователем workspace/gameplay/globals/soundbanks_always_load.csv
  изменено только это имя. Другие строки, формат и нулевое заполнение сохранены;
  исходная версия находится в BetaGwent/build/audio79-before-canonical-name.csv.
- В штатную папку поиска установлен дополнительный файл:
  `D:\GOG Galaxy\Games\The Witcher 3 REDkit\r4data\soundbanks\Pc\betagwent79.bnk`.
  Содержимое совпадает с успешно собранным79b:8 162 985байт,200 встроенных
  медиа, версия150, SHA256
  `8d97fc643b671d6610a436d20d41335cdb26c808db381d1379ee93fca1c916e8`.
  Существующие739 банков проверены до/после и не изменились. Init не устанавливался.
  Это отдельный файл для запуска звука в редакторе; существующие ресурсы
  REDkit, установленная игра, depot и оригинальная Beta не патчились.
- Добавлен installer с планом по умолчанию и явным --apply. Он создаёт файл
  исключительно через xb, проверяет SHA и отказывается заменять чужой банк.
  Установка вне workspace выполнена через разрешённый механизм escalation.
- Скрипты переложены в проект и скомпилированы Wcc79d. UI/native79c с34
  функциями и исправления способностей сохранены.

Точный вывод «workspace не перечисляется» не доказан одним числом739:
штатный каталог содержал739 файлов, но счётчик загрузчика исключает Init.
Само по себе совпадение чисел не является доказательством причины. Исправление
приводит имя к каноническому виду и обеспечивает присутствие файла в
известном штатном пути; вклад каждого изменения в итог подтвердит запуск.
