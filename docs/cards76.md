## Один общий проход проверки позже

1. Полностью перезапустить REDkit, открыть проект и `bgboard_open()`.
   Проверить выбор Скеллиге, три новые сборки и полный каталог с рисунками.
2. Сыграть один бой Скеллиге: сброс/воскрешение, счётчики, превращение,
   дополнительные отряды и переход в следующий раунд.
3. После этого посмотреть нейтральные выборы и таймеры в своих колодах:
   Агуара, Лавк, Гюнтер, Волкобой, Цири. Для Лавка стартовая колода
   должна быть без дублей; для Цири: новы — ровно две копии каждой
   присутствующей бронзовой карты (например, допустимая колода 26 карт).

Общая точность приоритетов/scheduler, RNG, фракционные правила,
ИИ, ownership/NPC/награды, сохранение/загрузка 8 слотов остаются отдельной
работой. Наличие обработчика каждой карты не заменяет приёмку в бою.
UI не управлялся. Installed TW3/REDkit, оригинальный клиент и depot не патчились.
