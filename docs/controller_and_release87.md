# Этап87 — контроллер и первый установочный пакет

Дата:2026-10-05. Работали через файлы и CLI, без управления интерфейсом.
Русский тестовый ZIP: `BetaGwent/release/BetaGwent0924-0.1.0-alpha-RU.zip`.

## Изменения управления

Фокус отделён для руки, точной вставки, целей и просмотра отрядов на поле.
LB/RB меняют ряд при вставке, сохраняя ближайшую позицию по горизонтали.
L3 открывает навигацию по картам поля; B/L3 возвращают к руке. В редакторе
View переключает коллекцию/состав, LT/RT меняют число копий, LB/RB листают
активный список, Start сохраняет легальную колоду. Мелкие дублирующие кнопки
± больше не мешают переходам по карточкам. Подсказки учитывают текущий
экран, Xbox/PlayStation и SwapAcceptCancel. При удержании паса виден прогресс;
доступность паса фиксируется также в момент нажатия. A/B пропускают анимацию.

Собраны три movie с44 связями каждый. Установлены в рабочий workspace.
58 WS источников не изменялись и соответствуют успешному Wcc86a.
Анимации, полный текст I/ПКМ, экран имени и лицензированный звук этапа86
сохранены. Новая игровая приёмка контроллера ещё не выполнена.

## Подготовка релиза

Рабочий проект не переименован. Отдельная копия заморожена в
`BetaGwent/build/release87/project/BetaGwent0924`; для CLI `workspaceDir`
указывает корень проекта, содержащий `workspace`, а не саму эту папку.
Исходный manifest —73 файла. Метаданные тестовой копии заполнены,
ep1/bob не исключаются. Входы сверяются перед каждым шагом.

Native cook:8 ресурсов, включая3 movie и меню. Ещё4 XML/CSV упакованы
как исходные текстовые ресурсы. В bundle12 файлов; metadata.store содержит12
записей. Dependency cache создан из cook.db. Локализация содержит396
строк и396 ключей в каждом языковом файле нового формата164. Английский
слот пока содержит русский fallback. По составу ID/ключей сверено с SQLite.

Для звука требуется `cooksounds -r4remastersounds -platform=windows`, плоская
папка с нашим `.bnk`/`.txt` и отдельный `outsplitfile`. Дополнительный seed
создан только в тестовой копии; при отсутствии chunk используетсяcontent0.
Кэш от первоначального прогона в дополнительной папкеCookedPC исключён из
архива, чтобы не распространять две копии одного банка.
Итоговый `soundspc.cache` содержит ровно наш полный банк1418 медиа/1420
событий; байты встроенного банка совпадают с исходной сборкой Wwise.
Штатный Init.bnk и лицензия не распространяются.

В пакет включён `content/precompiled.rsblob` из успешного Wcc86a.
ZIP проверен по CRC и SHA-256 каждого файла. README и общий проход включены.
Установка на F: не выполнялась. Сборка и упаковка не означают, что версия
уже прошла запуск/бой/сохранение в обычной игре.
