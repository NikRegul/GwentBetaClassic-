Мечта не взрывается от выбора режима и не взрывает сама себя. AfterPlayed
подключён к фактическому началу розыгрыша, перед собственной Played-ветвью
особой, согласно PlayCardAction.AfterApplyTriggers. Вложенные особые тоже
проходят этот путь. Списки рядов фиксируются в начале хода, а не при наложении
Мечты; это существенно для вложенных розыгрышей. Пассивная способность
активна, пока на поле остаётся хотя бы одна Мечта. Запомненные LocationList
исходный граф заново не фильтрует: сохранена эта особенность. Снятие Мечты
не стирает другой эффект, который успел заменить её в запомненном ряду.

Контактные эффекты выполняются отдельными passive frames через существующий
координатор действий. Сдвиг индексов соседних карт при вставке сам по себе
контакт не создаёт; событие получает перемещаемая карта. Урон всей группы
ставится в очередь до обработки смертей. После смертельного контакта отряд
не выполняет Deploy. Погода, работающая только при контакте/особой карте,
не выполняет ошибочный BeforeTurn-выбор и не расходует его случайные числа.
Кровавая луна/Волчья яма проверяют Ambush при разрешении события. Новый hook
TokensRemoved поддерживает снятие Ambush; текущий путь сброса превращения
подключён, остальные будущие способности должны использовать этот hook.

На поле добавлены подписи с величиной эффекта, лунные кольца, шипы ловушки
и тлеющие искры Мечты. Анимация использует только время интерфейса и не
вмешивается в gameplay RNG. Полная луна распознаётся существующими
RemoveBoons/Рассветом; чистое небо снимает бедствия, сохраняя блага.

## Один просмотр позже

1. Полностью перезапустить REDkit для новых скриптов/native ресурса. Начать
   новую DEV-партию через обычный редактор/поле; menuResource не менять.
2. Добавить Лунный свет и Мечту дракона в свою колоду. Полная луна должна
   дать+2 случайному зверю/вампиру своего ряда в начале хода. Кровавая луна
   должна дать−2 существующим отрядам врага и следующему входящему отряду.
3. Наложить Мечту, дождаться следующего хода, сыграть другую особую:−4 всем
   открытым отрядам ряда и снятие Мечты. Сам розыгрыш Мечты не взрывает её.
   Отдельные console suites не нужны. Волчью яму проверим с колодами
   Скоя’таэлей; сейчас она есть в общем каталоге, но не в Monsters-редакторе.

## Следующий шаг

Некромантия и оставшиеся20 особых. Для создания/случайного выбора не урезать
исходный пул: добавлять связанные отряды с их реальными способностями.
Далее фракционные отряды/лидеры/колоды, затем архетипы и поиск ИИ25–30с.
