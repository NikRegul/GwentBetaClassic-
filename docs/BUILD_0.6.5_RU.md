# Сборка 0.6.5 RU / Stage 141

Новая версия добавляет звук муллигана и оригинальный рёв Королевы главоглазов во вступлении и при розыгрыше. Содержит ИИ и анимации 0.6.4; четыре нативных меню переиспользуются побайтно с проверкой исходников и ресурсов. Обычные premium-иллюстрации не входят в пакет.

Входы зафиксированы в `BetaGwent/build/audit141/candidate`, fingerprint `fc12ea3eef91c4ab45f8c3c042745c05e415b63dd493f37096386d9fa8b93bee`. От 0.6.4 отличаются три WS-файла: обработчик меню, звуковой контроллер и доступ к счётчику состоявшихся замен. Правила карт и политика ИИ сохранены.

Для подготовки чистого нового каталога сборки:

```powershell
python -X utf8 tools/ui/build_voice141.py
python -X utf8 tools/ai/snapshot.py BetaGwent/build/audit141/candidate
python -X utf8 tools/check_work141.py
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-0.6.5.ps1 -Language ru
```

PowerShell-скрипт автоматически находит Python из локального окружения Codex, затем использует Python из PATH. Другой интерпретатор можно передать через `-Python 'C:\path\python.exe'`. По умолчанию выбран RU; `-Language all` собирает все пять голосовых пакетов. В режиме `full` готовые архивы проверяются, недостающие пакеты собираются. Каталог запуска после выполнения восстанавливается.

Подготовленные входы и существующие архивы не перезаписываются. Для проверки уже собранного архива:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-0.6.5.ps1 -Step verify -Language ru
```

Банки собираются WwiseConsole в `BetaGwent/build/audio141`, исходные банки из 0.6.3/0.6.4 не меняются. Скрипты компилируются REDkit; звуковой кэш готовится нативным `cooksounds`. Проверяются ZIP, manifest, SHA-256, исходники компиляции, нативные меню и побайтное включение нового банка в кэш. Установка в игру и публикация не выполняются. Другие готовые голосовые архивы пока остаются на 0.6.3.
