# Лидер и фракция выбираются при создании колоды

В редакторе кнопки фракций вызывали `OnBetaGwentDeckEditorLeader`: даже повторный выбор текущей фракции мог заменить лидера на первого доступного. Выбор другой фракции также удалял из черновика несовместимые карты. По запросу пользователя смена лидера после создания колоды полностью убрана.

В обоих вариантах оформления редактора удалены переключатели лидера и интерактивные кнопки фракций. Сохраняются текущая эмблема и просмотр карты лидера. Его выбор по-прежнему доступен в отдельном окне создания новой колоды до команды `OnBetaGwentDeckCreate`. Пояснение переведено на все 13 языков; нужные символы проверяются по настоящим поставляемым шрифтам.

Нативный обработчик старого события оставлен для совместимости: он отклоняет команду и повторно публикует текущий редактор, не меняя лидера, фракцию, состав или историю отмены. Импорт в уже открытую колоду разрешает только её текущего лидера и фракцию; несовпадение отклоняется до работы с коллекцией и создания недостающих карт. Импорт новой колоды из списка колод сохраняет выбор лидера из кода импорта.

Регрессия `tools/ui/check_editor_leader_lock094.cjs` исполняет настоящие AS/WS тела функций: пользовательские и стартовые колоды, тот же/другой лидер/фракция, состав с повторяющимися картами, история отмены, старые события, импорт и создание. На прежнем коде — 24 нарушения, после исправления — 61 проверка без ошибок для каждого платформенного Board. Тест включён в обычную сборку для обеих платформ. Прежние проверки редактора, подтверждений и создания также проходят.

Выходы текущей проверки: `BetaGwent/build/editor-leader-lock094-20261026-01`. Основные пять Board и Classic overlay сохраняют UTF-8 BOM/CRLF. Готовые архивы 0.9.4-2 и замороженные входы испытаний ИИ не изменены. Компиляция и технические проверки не заменяют отдельную игровую приёмку нового поведения.
