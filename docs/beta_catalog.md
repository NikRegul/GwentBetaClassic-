## Идентификаторы и сохранность

Template ID уникален в этих698 записях. NId способности **не уникален глобально**:
134 значения используются повторно. Каждая из567 записей сохранена отдельно;
recordKey=ability/sourceIndex действует только вместе с hash архива. Это
не stable ID между версиями клиента. Id узлов, переменных и connections
проверяются **внутри одной записи**; flatten по NId уничтожил бы данные.

9713 connections разрешаются в локальные поля nodes. SrcId/DstId относятся
к connector/variable field IDs, не прямо к node IDs; каталог сохраняет обе
стороны и их node/field/type. Порядок nodes, children и connections сохранён.
Все ненулевые CardAbility.Template/LinkedTemplateId/nested TemplateId references
разрешились. TemplateId0 сохраняется как исходное значение.

Typed template scalars отделены от raw attributes/tree. Polymorphic nodes и
variables сохраняют Type/GArg/Id/VarId/raw values. Каталог не приписывает
исполняемую семантику неизвестному типу; все183 пока помечены unsupported.
Tree round trip сравнивает tags, attributes, text и child order; это логическая
сохранность XML, не сохранение исходных пробелов и порядка attributes в байтах.

## Маски категорий и semantic tags

[Метаданные BitArray](D:/w3mod/docs/evidence/beta-bitarray-metadata.txt) подтверждают
**UInt64[]**, не uint32[].381 words превышают UInt32. В JSON word хранится
decimal string + low32/high32: восстановление `low32 + (high32 << 32)`
проверено для всех4189 words. Это также защищает большие значения от потери
точности в JavaScript JSON consumers.

Categories у697 шаблонов содержит3 words; у Template152214 —4, последний0.
Этот четвёртый word сохранён, несмотря на нулевое значение. SemanticTags
содержит3 words у всех698 templates. Сами words не являются category IDs;
decoded membership и WitcherScript mask operations ещё нужно реализовать.

## Воспроизведение и следующая работа

```powershell
python D:\w3mod\tools\import_beta924.py
python D:\w3mod\tools\import_beta924.py --verify
python D:\w3mod\tools\check_beta924_catalog.py
```

Первый запуск создаёт каталог; последующий требует одинаковые данные и
не перезаписывает отличающиеся файлы. `--verify` строит каталог в памяти
и сравнивает generated bytes без записи. Проверен byte-identical повторный
результат. Независимый checker сравнил698 templates/567 abilities и9713 связи
с original XML, восстановил маски и отклонил overflow/negative/sparse words.

Следующий M5 шаг: semantic connector/variable typing, triggers/flow entry,
IR handler coverage для согласованного small canonical slice, generated WS
definitions и interpreted effects. Classification collectible/token/leader,
Availability/legality и legal decks пока не завершена;698 templates не означает
698 collectible cards. Установленные игровые14 scripts не менялись этим шагом.
