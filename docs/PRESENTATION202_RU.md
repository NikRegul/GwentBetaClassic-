# Gwent Beta Classic 0.8.0

Общая ветка для Next-Gen и Classic 1.32. Для каждой платформы предусмотрены пять пакетов озвучки: RU, EN, DE, IT, PT-BR; в каждом все 13 языков текста.

Сохраняет исправления 0.7.4b: запуск боя после разделения drawBacks, загрузку меню с уплотнённым атласом, НГ+ бочки, три стрелы Йотуна, Казнь Хеймдалля, начало/тики Рагнарёка, огонь/пиво, статусы, таймер и броню. Пользователь подтвердил запуск боя в 0.7.4b. Редактор, бочки, принятая молния, погодные слои и растворение карт сохранены.

Classic собирается из того же замороженного снимка, с собственными адаптерами скриптов, мостом ввода и форматами ресурсов/звука 1.32. Успешные компиляция и проверка файлов не заменяют игровую приёмку: проверить полный цикл партии, эффекты, покупки, озвучку и сохранения на обеих платформах. Использовать только один пакет, соответствующий версии игры.

Локальная сборка из текущих исходников. Новые изменения требуют собственной игровой проверки.
