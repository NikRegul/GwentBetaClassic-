Целевая версия: строгая Beta0.9.24.3.432. Источники — исходные графы69,

## Морвудд132205 и Двимеритовые кандалы113319

Морвудд — серебряный отряд силы6. Необязательный выбор0..1 цели;
Кандалы — бронзовая особая карта, обязательный выбор1..1 при наличии целей.
Обе выбирают активную цель любой стороны/редкости, Type4, Tier15, Ignore256.
Gold не имеет общей невосприимчивости в этой версии. Пустой valid list
возвращает null action в оригинале, поэтому способность завершается без выбора.

Последовательность: queued ChangeTokens(Toggle3,Lock4) → Apply → фильтр стороны
соперника → изменение силы. На своей цели только переключается блокировка.
На чужой Морвудд ставит текущую силу вfloor(float(current)*0.5), игнорируя
и сохраняя броню. Например5→2, а не5→3. Кандалы наносят4 обычного урона
через броню. Уже заблокированная цель разблокируется; вторичный эффект на
чужой цели всё равно выполняется. Морвудд допускает отказ, Кандалы с непустым
списком требуют цель.

CardTokens.Toggle — XOR. В отличие от Add(Lock), он не вызывает
HandleLockAdded и не снимает автоматически Resilience/Ambush/Disloyal.
В данном закрытом наборе Ambush/Disloyal не используются. Не заявляется
полноценный режим скрытых засад для будущих карт.

Написанные пассивные реакции Туманника/Неккера, бонус Всадника и Killed
проверяют Lock. После разблокировки они снова доступны. Уже выполненный
deploy не откатывается. В сбросе Reset(true,false) сохраняет Lock и постоянные
bits1792, вместе mask1796; при выходе из сброса Lock удаляется по OnCardMoved.
Завещание заблокированной карты не запускается.

UI получает tokens из authoritative snapshot через pushCardStatus. Замок
показывается на карте и в выборе собственного сброса; hover поясняет эффект.
Промежуточные кадры также содержат свой tokens snapshot. Скрытая рука AI
не получает публичных названий/статусов. Переключение использует существующую
presentation queue и подсветку источника/цели.

## Компрессия200053 → Нефритовая статуэтка200307

Компрессия — серебряная особая карта. Граф325 выбирает1 цель при наличии
valid list: активная7, обе стороны3, Type12(Unit4|Leader8), Tier6(Bronze2|Silver4),
Ignore264(NotTargetable256|Ambush8). Золотые цели исключены. В текущем наборе
нет бронзового/серебряного лидера, поэтому в игре предлагаются только отряды.
Пустое поле завершает способность без цели; отдельный отказ с целями запрещён.

Queued Transform меняет definition существующей карты, сохраняя instance ID,
владельца/controller, сторону, ряд, индекс и playability. Это не Destroy/Spawn:
нет Killed, старого Завещания, нового ID, deploy или дополнительного хода.
Прежние способности исчезают вместе со старой definition. Статуэтка —
серебряный отряд2, armor0, Doomed512, без графа способности; в обычную колоду
не включается (Availability0). При смерти/очистке уходит вVoid, а не в сброс.

ResetMode255 восстанавливает новую template base power/armor, обнуляет permanent
power, убирает прежний Lock и остальные временные tokens, оставляет template
persistent tokens новой definition. В закрытом наборе нет timer/category/
promotion/leader-state effects для этих целей; полный универсальный Reset/
OnDefinitionChanged lifecycle пока не перенесён. Повторная Компрессия уже
существующей Статуэтки — no-op согласно SetDefinition: не сбрасывает её силу
или tokens повторно. Событие полного AfterTransformed scheduler пока не реализовано.

При изменении template той же карты UI плавно заменяет иллюстрацию на месте,
показывает новое имя, силу и серебряную рамку. Doomed обозначается знаком×.
Арты Компрессии и Статуэтки используют один исходный ArtId2000530, как Templates.
Анимации UI не расходуют игровой RNG.

## Колоды и установленный набор

В обеих25-карточных колодах по одному Морвудду и Компрессии, по две Кандалы;
по три Неккера и одному Гулю. По одному Туманнику/Гнильцу и два Дао остаются.
Проверены исходная доступность, faction1/2, copy limits и Gold/Silver limits.
Всего32 definitions/art bindings, включая choice/token templates.
Atlas768×1080 DXT5; четыре текстуры DIY досок сохраняются побайтно.

AI — собственная эвристика: учитывает снижение текущей силы, броню,
ценность отключения/возвращения написанных пассивов/Завещаний и превращение.
Она не использует RNG для lookahead и не считается оригинальным AI.
Generic ability interpreter и полный action-passive coordinator остаются впереди.

## Отложенный просмотр в обычной игре

Проверки сейчас не требуются. Позже перезапустить REDkit, открыть тестовый сейв
и bgboard_open(). Заодно с картами45–48 посмотреть:

1. Морвудд на чужой нечётной силе и на своём заблокированном Неккере.
2. Кандалы: замок до урона, броня, повторное переключение; заблокированный
   Неккер/Дао/Гнилец не выполняет Завещание.
3. Компрессия на бронзовом или серебряном отряде: сила2, новая иллюстрация,
   то же место, старого Завещания нет. Gold не предлагается.
4. Статуэтка исчезает при смерти/очистке; повторная Компрессия не сбрасывает
   уже существующую Статуэтку. Обычная партия завершается как раньше.

Import/menuResource менять не надо, новых console suites нет. Компиляция
и file-only проверки установки не заменяют runtime acceptance; последний
принятый пользователем этап44,45–50 отложены.
