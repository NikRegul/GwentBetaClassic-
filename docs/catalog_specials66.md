## Полный каталог

В выборе колод появилась кнопка **«Все карты»**. Отдельный просмотр465
исходных кандидатов:444 обычных и21 лидер. Он не зависит от реализации,
получения или доступности карты редактору. Поиск по названию/описанию/ID;
фильтры фракции, редкости, типа и реализации; страницы по12 карт.
Нажатие показывает иллюстрацию, силу, редкость, фракцию и полное описание.
Длинный текст прокручивается колесом или стрелками. Назад/Escape возвращает
к выбранным колодам без изменения их состава или лидера. Во время ввода
поиска игровые горячие клавиши не действуют.

Везде **«Способ получения: не назначен.»**, как указал пользователь.
Торговцы/квесты/NPC-награды и saved коллекция владения ещё не подключены:
метаданные владения неизвестны, а не искусственно объявлены полученными.
Просмотр не добавляет карты в колоду и не открывает недоделанные эффекты.
Редактор по-прежнему использует реализованные карты своей фракции/нейтральные.

463/465 иллюстраций имеют существующие привязки в DIY: точный templateId,
явная привязка исходной иллюстрации или уникальное точное английское имя
из GwentMap. Две отсутствуют:201627 «Выходной день Лавка» и152318
«Друммонд: щитоносец»; вместо чужого арта показывается отсутствие картинки.
С учётом6 внутренних изображений атлас содержит469 tiles,3072×3600 DXT5.
Четыре прежние текстуры досок сохранены побайтно. Наличие арта не означает,
что эффект карты реализован. Дополнительные ограничения лидеров/режимов
проверяются перед включением в игру; каталог показывает исходных кандидатов.

## Новые эффекты

| Карта | Редкость | Конкретный перенос |
|---|---|---|
| Возрождение | Золото | Выбор и повторный розыгрыш золотого отряда из своего сброса |
| Королевский указ | Золото | Выбор золотого отряда/артефакта из своей колоды, розыгрыш, затем усиление2 |
| Альзур: Двойной крест | Серебро | Самый сильный бронзовый/серебряный отряд своей колоды, случайный при равенстве, розыгрыш, затем усиление2 |
| Приказ о выступлении | Серебро | Самый слабый бронзовый/серебряный отряд своей колоды, случайный при равенстве, розыгрыш, затем усиление2 |
| Последнее желание | Серебро | Перемешивание всего допустимого списка своей колоды, первые2, выбор одной карты для розыгрыша |
| Разведка | Бронза | Перемешивание всех бронзовых отрядов своей колоды, первые2, выбор одного для розыгрыша |
| Дар природы | Серебро, Скоя’таэли | Выбор бронзовой/серебряной особой своей колоды и её вложенный розыгрыш |
| Подкрепление | Серебро, Север | Выбор бронзового/серебряного солдата/машины/офицера/поддержки из своей колоды и розыгрыш |
| Ворота Нильфгаарда | Серебро, Нильфгаард | Выбор бронзового/серебряного офицера из своей колоды, розыгрыш, затем усиление1 |

Запросы берут type/tier/ignore/location/minimum/boost из закреплённых графов.
Стек использует настоящий instance ID выбранной карты: она уходит из колоды
или сброса, а не копируется. Для отряда выбирается свой ряд/сосед-вставка;
для особой сразу запускается её собственный запрос. Дочерние способности,
цели и смерти завершаются до усиления родительской картой и передачи хода.
При пустом списке/заполненном поле партия продолжает ход без зависания;
опциональные исходные выборы разрешают завершить без розыгрыша.
Передача чужих скрытых колод в меню не добавлена: публикуются только
кандидаты текущего собственного запроса. Общий original network/request
viewer parity и произвольные графы этим этапом не подтверждены.

Три новые фракционные особые видны в полном каталоге, имеют обработчики,
но создание колод других фракций пока закрыто: их лидеры/отряды ещё впереди.
Шесть нейтральных сразу расширяют текущий Monsters-редактор до68 карт.
Усиление после вложенного розыгрыша применяется к выжившему активному отряду;
особые случаи уничтожения/смены определения/позиции дочерней карты требуют
будущей сверки с оригинальным runtime, а не считаются исчерпывающе проверенными.

## Установка и один следующий просмотр

Версия66 собрана и переложена в GwentB/myproject1/workspace. Wcc66c явно
подтвердил Success без Script errors; AS3/GFx/receiver и ресурс проверены.
В игре66 ещё не наблюдалась. Отдельных новых console suites нет.

При следующем удобном запуске перезапустить REDkit и открыть `bgboard_open()`:

1. «Все карты»: поиск/фракции/редкости, карта ещё не реализована, надпись
   «Способ получения: не назначен», выход обратно с прежними колодами.
2. В своей колоде добавить несколько новых нейтральных: «Королевский указ»,
   «Последнее желание», «Разведка», «Двойной крест» или «Приказ о выступлении».
   Сыграть обычную партию; выбранный отряд ставится в указанный ряд, его
   способность/цели завершаются, затем приходит усиление; счёт колоды уменьшается.
3. По возможности «Возрождение» на золотой отряд в сбросе. Он возвращается
   на поле и снова использует свою способность. Без золотого сброса эффекта нет.

Сохранение/загрузка8 custom слотов в обычном тестовом сейве остаётся отдельной
неподтверждённой проверкой. Пользовательское создание/игра своей колодой уже
принято и не требует повторения базовых тестов. Логи: DUEL_PILE_CHOICE,
DUEL_NESTED_PLAY, DUEL_PILE_RETURN, PLAY_PUSH/POP и BOARD_ARTWORK_FAILURE.

после этого архетипы и поиск ИИ. Получение через мир TW3 назначать позже.
