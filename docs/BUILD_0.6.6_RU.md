# Сборка 0.6.6 RU / Stage 142

Пакет объединяет специальные эффекты и погоду, вступления лидеров, одновременные усиления, историю и подсказки целей, бочки у корчмарей и исправления ИИ. [Состав и игровая проверка](PRESENTATION142_RU.md), [каталог исследованных эффектов](SPECIAL_VFX_0.6.6_RU.md).

Сборочный вход рассчитан на подготовленное локальное окружение Windows с REDkit, оригинальными ресурсами, словарями и русским звуковым банком Stage 141. Свежего клона недостаточно. Этот выпуск содержит один русский голосовой пакет с 13 языками текста. Остальные готовые голосовые архивы остаются на 0.6.3.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-0.6.6.ps1
```

Скрипт использует Python из PATH; другой интерпретатор можно указать через `-Python`. Он проверяет замороженный снимок `BetaGwent/build/audit142/final`, результаты 50 наборов регрессий, компиляции 70 WitcherScript-файлов и четырёх нативных меню. Подготовленные исходники, меню, 40 страниц вступлений и русский банк должны совпадать с отчётами. Затем выполняются подготовка, cook, строки, звук, зависимости, упаковка, метаданные и создание архива.

Готовый архив не перезаписывается. Для повторной проверки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-0.6.6.ps1 -Step verify
```

Проверяются скрипты, скомпилированный blob, меню и страницы вступлений, торговые XML, звуковой кэш, состав bundle, ZIP/CRC, manifest и SHA-256 каждого файла. Старые архивы 0.6.3–0.6.5 сверяются с исходными хешами. Результат — `docs/evidence/validation142.json`, журнал этапов — `BetaGwent/build/stage142/logs`.

Установка в игру и публикация не выполняются. Программные проверки не заменяют приёмку новых эффектов, звука, вступлений и торговли в обычной игре.
