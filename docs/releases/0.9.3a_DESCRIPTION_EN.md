# Gwent Beta Classic 0.9.3a

Complete package for Classic 1.32 or Next-Gen 5.0+, including 0.9.3 content and ordinary AI fixes: winning passes, exhausted opposing hands, drawing fallbacks, consistent continuation scores and the actual card budget when substituting a hand card for a leader.

Ordinary difficulties keep their hidden-information restrictions. The separate Classic difficulty uses ported original Beta logic, deck-specific source profiles and access to the opponent's actual hand and deck. Choose difficulty before the match beside the language controls.

Preserves 76 ordinary opponent decks and 33 thematic quest presets, accepted effects, covers, music and controls. Correctness checks do not establish an overall strength improvement. The new package does not replace inputs of the already running tournament.

Choose the archive matching your game version and follow the included manual installation and script-mod compatibility guidance. No automatic installation or publication.
