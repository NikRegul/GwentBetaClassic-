# Gwent Beta Classic 0.9.0 — Встроенная очистка перед удалением мода

Очиститель включён в основной мод 0.9.0; отдельный архив устанавливать не нужно. Сделайте резервную копию сейва, завершите партию, выйдите из боя и закройте меню. Пока основной мод установлен, bg_clean_preview() покажет инструкцию без изменения данных. Для подтверждения введите:

```text
bg_clean_confirm('DELETE_BETA_GWENT')
```

Удаляются коллекция беты, колоды, осколки, бочки, настройки, известные наградные записи, оба банка резервных фактов и предметы betagwent_* из текущего инвентаря игрока. Сохраняемый флаг блокирует повторную выдачу стартовых колод и восстановление профиля даже после перезагрузки с установленным модом. Сохранитесь В НОВЫЙ СЛОТ, выйдите из игры, уберите папки мода (для Classic — также его DLC), обновите затронутые объединения Script Merger, загрузите новый слот и сохранитесь ещё раз. Для отмены загрузите исходную резервную копию. При удалении мода уберите и файлы Optional-CopyButton, если ставили их: bin\…\plugins\GwentBetaClipboard.asi и dinput8.dll из этого мода (не чужой).

Если часть стопок предметов беты удалить не удалось, вместо сообщения об успехе появится «Beta Gwent cleanup is INCOMPLETE» с их количеством. Не удаляйте мод: выбросьте или продайте эти предметы и снова выполните bg_clean_confirm('DELETE_BETA_GWENT'), пока не появится сообщение об успешной очистке.

Завершённые квесты, достижения и потраченные кроны не откатываются. Команда не обходит выгруженных торговцев, тайник и контейнеры мира: сначала заберите оттуда предметы беты. Для старых наградных фактов может потребоваться приложенный сканер save_fact_index.py и bg_clean_keys('…') после подтверждения очистки. Подробности — BetaGwentDocs/CLEANUP_RU.md. Это очистка профиля, без обещания физического удаления каждой исторической записи произвольного сейва.
