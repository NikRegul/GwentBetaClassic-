# Gwent Beta Classic 0.9.1h

ИИ оценивает, какие комбинации останутся в руке после хода. Если ход уничтожает последнюю действующую основу для оставшихся карт, он получает дополнительную стоимость при выборе. Запасная карта для той же комбинации уменьшает эту стоимость. Одноразовая подготовка, например усиление Драигом, не считается постоянной зависимостью.

Для нескольких перспективных ходов ИИ разыгрывает настоящую способность на копии позиции, проверяет три перестановки собственной оставшейся колоды и ограниченный ответ соперника. Прогноз использует открытые карты и разрешённую уровню сложности информацию; максимальная сложность учитывает первоначальный состав колоды. Модель не получает скрытую руку игрока. Возможная Казнь добавляет ограниченную оценку риска, а не объявляет поражение доказанным.

Сохранение комбинаций применяется на всех уровнях сложности в раундах, где можно сберечь ресурсы. В решающем раунде и при угрозе проигрыша матча этот новый резерв не удерживает карты. Расчёт разбит на небольшие шаги для игрового интерфейса.

Это ограниченное улучшение оценки ходов; полного дерева партии на несколько раундов здесь ещё нет. Составы колод, начальные очки, принятые эффекты, интерфейс и музыка сохранены из g.

Включены 70 целевых проверок новых правил и общий набор из 51 регрессионной группы. Итоговые результаты сборки и короткого сравнения с g находятся рядом с архивами. Статистическое преимущество над g короткий прогон не гарантирует. Компиляция проверяется для Classic 1.32 и NextGen 5.0+; ручная проверка игры после установки не выполнена.
