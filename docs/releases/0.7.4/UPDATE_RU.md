# Gwent Beta Classic 0.7.4

- Бочки определены и для НГ+. Неудачное добавление больше не фиксируется как выполненное; старые затронутые запасы корчмарей восстанавливаются один раз. Проданные после исправления бочки не появляются при каждом открытии магазина. Нулевая старая НГ+ лавка получит пять бочек при первом посещении; отличить старую ошибку от ранее распроданного запаса в сохранении невозможно.
- Йотун выпускает три отдельных физических снаряда по трём выбранным картам.
- Хеймдалль, призванный смертью Камби, сохраняется как источник уничтожения: на каждой жертве применяется принятый эффект Казни. Сам Хеймдалль остаётся на поле.
- Рагх-Нар-Рог: добавлено начало с метеоритом по исходной траектории, ударом и синхронным появлением готовых выжженных слоёв на трёх рядах. Его тики используют исходное огненное попадание. Слои погоды сохранены.
- Пивной тик Golden Froth использует исходную пену с обычным смешиванием вместо зелёного усиления. Открытие бочек не менялось.
- Включён первый блок статусов: появление/снятие стойкости, шпиона и вскрытия; тик таймера; получение и полное разрушение брони. Числа меняются при попадании, закрытая рука не раскрывается.
- Для проверки падения при начале боя уменьшена сложность инициализации таблиц статусов, часть отрисовки вынесена из большой функции, отменена принудительная глобальная сборка памяти при выгрузке портретов. Оба дампа 15 октября имеют одинаковое падение в Scaleform; точная причина без символов не доказана. Исправление краша требует подтверждения запуском боя.

Редактор, раскладка интерфейса, открытие бочек, принятая молния и растворение карт сохранены по просьбе пользователя. Перенос новых эффектов двумерный: оригинальные процедурные шейдеры и повороты 3D полностью не эмулируются.

Проверить в игре: старт боя (в том числе Филавандрель/Королева главоглазов), возврат в редактор и повторный старт; НГ+ корчмарь → покупка → повторное открытие; три цели Йотуна; Камби → Хеймдалль на обеих сторонах; начало и тики Рагнарёка, пивные тики; статусы и броня при обычном/ускоренном/уменьшенном движении. Компиляция и регрессии не подтверждают отсутствие краша или итоговый вид в Scaleform. После игровой приёмки этот объём можно учитывать для 0.8.
