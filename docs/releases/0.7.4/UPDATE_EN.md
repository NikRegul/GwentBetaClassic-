# Gwent Beta Classic 0.7.4

NG+ keg item definitions and one-time recovery of affected innkeeper stock; retryable item creation. Separate projectiles for all three Jotunn targets. Hemdall retains the Scorch visual source for every swept victim after Kambi dies. Source Ragnarok meteor trajectory/impact with simultaneous arrival of the existing three scorched rows; original fire hit on weather ticks. Golden Froth ticks now use the original alpha-blended foam. Includes resilience/spying/reveal status transitions, timer ticks, armor acquisition/break effects.

Crash candidate: lazy status initialization, smaller card rendering function, no forced cross-movie garbage collection while retiring leader portraits. Two matching native Scaleform dumps were inspected; the precise root cause and in-game fix are not yet confirmed.

Existing deck editor, keg opening, weather layers, accepted lightning and card dissolve are preserved. New effects use a 2D adaptation; procedural shaders and full 3D motion are not emulated. Native build and regression success still require gameplay acceptance, especially starting/restarting a duel, NG+ innkeeper purchase/revisit, three-target Jotunn, Kambi/Hemdall, Ragnarok, Froth and status/armor effects at each presentation speed.
