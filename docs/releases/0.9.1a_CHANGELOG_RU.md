# Gwent Beta Classic 0.9.1a — исправления ИИ

20 октября 2026. Исправление поверх 0.9.1: интерфейс, колоды, звук и арт без изменений, меняются только скрипты ИИ. Изменения входят в оба пакета: Classic 1.32 и Next-Gen 5.0+. Полный список изменений 0.9.1: [0.9.1_CHANGELOG_RU.md](0.9.1_CHANGELOG_RU.md).

## ИИ — Рой главоглазов

- Мируна больше не выходит при пустом поле соперника, если очаровывать некого. Исключение — связка с Пугачом: ИИ выкладывает Мируну, а следующим ходом Пугача в ряд напротив неё, и очарование возвращает Пугача.
- Когда цель уже есть, Мируна ставится в ряд напротив неё. Учитывается, что в её ряду должно хватить места для очарованного отряда.
- Если Мируна ждёт напротив пустого ряда, ИИ разыгрывает Пугача, а не другую карту (раньше это мог быть, например, Лютик). Прогноз шпиона теперь учитывает, что Мируна вернёт Пугача.
- В решающем раунде Вран-воин и другие поглотители едят своего Накера на поле, если в колоде осталась его копия: Завещание призывает её. В ранних раундах Накеры по-прежнему придерживаются для завершения. Ошибка воспроизведена по игровому логу: Вран съел Молодого главоглаза силой 3 вместо Накера, и раунд был проигран.

Все случаи покрыты регрессиями (check_miruna_timing091, check_nekker_food091) на нескольких уровнях сложности.
