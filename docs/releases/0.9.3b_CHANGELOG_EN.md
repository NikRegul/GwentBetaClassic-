# Gwent Beta Classic 0.9.3b

Lock/resilience fix for Classic 1.32 and Next-Gen 5.0+, including the complete 0.9.3a package.

- Adding Lock now clears existing Resilience, Ambush and Disloyal, matching the original Beta Add(Lock) behavior. Locked Yarpen Zigrin, Mahakam Defender and Barbegazi no longer carry into the next round through their old Resilience status.
- Unlocking does not restore removed statuses. Resilience granted separately after the lock still works.
- Revealing an ambush through Lock still does not execute its reveal ability. Independent statuses are preserved.
- Corrected an old regression assertion that incorrectly required keeping Resilience and Disloyal when locked. Added real lock-card and round-transition cases for both sides and every row.
- Difficulty selection is visible in deck setup and the deck editor. All three controls beside the language settings fit above the deck panel, which no longer covers the difficulty button. Applies to both interface variants and retains mouse/controller controls.

Preserves 0.9.3a AI fixes, original Classic difficulty with 24 profiles/109 bindings, approved decks, interface, VFX, music and covers. Saved 0.9.3/0.9.3a releases and the running tournament inputs remain unchanged. That tournament uses the old 0.9.3 lock behavior and is not a test of fixed 0.9.3b.

One shared JS/WS rules engine applies the fix to the player and both AI policies. No automatic installation; technical checks and compilation do not replace native gameplay acceptance.
