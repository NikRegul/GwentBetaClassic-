# Gwent Beta Classic 0.9.3

Самостоятельная бета Gwent в мире The Witcher 3: 479 коллекционных карт, 21 лидер, пять фракций, 13 языков текста и пять озвучек.

Версия 0.9.3 добавляет сложность «Классическая»: отдельного соперника на перенесённой логике оригинального ИИ беты, который видит вашу руку и остаток колоды. Для готовых соперников исходный профиль подбирается по составу и лидеру. Выберите режим до начала партии рядом с языками. Три прежние сложности сохраняются.

У обычных противников теперь 76 составов, включая 30 подлинных колод беты под исходными названиями. Для 33 квестовых персонажей подготовлены тематические колоды. Сохранены коллекция, редактор с восемью собственными слотами, импорт BG1, награды, бочки, принятые эффекты и управление геймпадом.

Выберите архив Classic 1.32 либо Next-Gen 5.0+. Обе папки DLC в архиве Classic необходимы. Необязательный modBetaGwentMenuMusic добавляет тему главного меню беты в конструктор. Сохраните остальные моды и при необходимости обновите затронутые слияния Script Merger. Установка и публикация не выполняются автоматически.

Подробные изменения и пределы проверок — в changelog 0.9.3. Игровая приёмка на установленной версии остаётся отдельным шагом.
