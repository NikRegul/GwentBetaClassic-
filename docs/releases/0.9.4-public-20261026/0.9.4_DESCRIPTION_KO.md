# Gwent Beta Classic 0.9.4

**더 다양한 덱. 더 나은 판단. 베타 시절의 궨트.**

오픈 베타의 궨트를The Witcher 3에서 만나보세요. 익숙한 카드, 완전한 덱 편집기, 세계 곳곳의 인물과 대결할 수 있습니다. 공개0.9.3은0.9.1 이후 변경과 최근 플레이 로그의 수정을 통합합니다.

## 0.9.4 변경 사항

- Next-Gen 5.x는 모드가 게롤트에 추가한 필드 중 처음 45개만 저장하며, 이 한도는 설치된 모든 모드가 함께 씁니다. 게임 팩트는 16비트 숫자만 보관합니다. Beta Gwent는 더 많은 필드를 사용했기 때문에 다른 모드와 함께 쓰면 불러온 뒤 덱, 통, 조각이 사라질 수 있었습니다. 이제 전체 프로필은 네 개의 필드로 된 단일 저장소에 보관되며, 팩트 백업은 16비트에 맞는 조각으로 나뉘어 기록됩니다.

- 복구 절차도 강화했습니다. 프로필은 첫 변경 전에 불러오며, 손상된 원본과 격리된 덱을 복구용으로 보존합니다. 알 수 없는 미래 형식은 읽기 전용입니다. 형식 2는 형식 1을 읽고, 기록을 받아들이기 전에 숫자 데이터와 함께 텍스트 길이와 무결성을 검증합니다. 저장과 사용 가능한 백업 모두에 없는 데이터는 복원할 수 없습니다.

- 기존 저장은 처음 불러올 때 자동으로 옮겨집니다.

- 토너먼트 이후 짧은 라운드에서 첩자를 다루는 AI 판단을 수정했습니다. 개발 표본은 368경기, 50%, 오류 0건입니다. 별도 보류 표본은 실행하지 않았으며 전반적인 실력 향상은 입증되지 않았습니다. 어려움은 계속 플레이어에게 보이는 정보로 제한되며, 클래식은 숨겨진 정보에 더 넓게 접근합니다.

Next-Gen 5.0+와 Classic 1.32용입니다. 1.32에서는 기존 필드도 새 저장소와 함께 계속 저장됩니다. 0.9.4로 저장한 뒤 0.9.3으로 되돌리는 것은 지원하지 않습니다. 자동 테스트와 네이티브 컴파일은 게임 안에서 저장, 종료, 불러오기를 확인하는 일을 대신하지 않습니다.

## 주요 기능

- 승인된 원본 베타 덱30개를 기존46개에 추가했습니다. 일반 구성76개와 퀘스트 인물 설정33개, 중복 없는 구성92개입니다. 원본 덱 이름을 유지합니다. 유사 덱15개는 보류하고 구성 조건에 어긋난28개는 제외했습니다.

- 클래식은 베타 AI를 이식한 네 번째 난이도입니다. 원본 프로필24개를 덱 설정109개에 배정했으며, 대전 전 언어 설정 옆에서 선택합니다. 플레이어의 손과 덱을 볼 수 있습니다. 일반 어려움은 기존 정보 제한을 유지합니다.

- 어려움은 지도자 이후 연계, 짧은 결정 라운드의 카드 순서, 라운드를 양보하기 전 드로우, 유용한 패스를 개선했습니다. 강화는 메노와 전력 초기화, 피해는 안 크라이트 대검사의 회복을 고려합니다. 공개 덱은 상대 비공개 카드와 자신의 공개 시너지를 비교합니다. 숨겨진 매복이 있으면 실제 비밀 카드를 읽지 않고 공개 정보상 가능한 함정을 예산 안에서 검토합니다. 두 함정의 타이머 순서와 남은 복사본 수를 올바르게 고려합니다. 단계당 모의 행동1회를 유지하며, 전반적인 강도 향상이 입증된 것은 아닙니다.

- 제시된 카드는 전용 창에서 고릅니다. 칸타렐라는 손에 남길 카드와 덱 맨 아래로 돌려보낼 카드를 명확히 보여줍니다. 숨겨진 카드는 뒷면을 유지합니다. 내부 프로필 대신 상대 이름을 표시하고 불필요한 덱 제목과 지도자 아래 빈 공간을 없앴습니다. 백색 서리 컨트롤러 포커스, 난이도 표시, 자동 패스, 상대 패스 후 낭비되는 날씨도 수정했습니다. 카드 선택 창에 결과 설명을 추가했습니다. 우달리크는 선택한 카드가 손으로, 나머지가 묘지로 갑니다. 카드의 행방이 중요한 다른 선택에도 같은 설명을 붙였고, 그 밖의 선택에는 능력 설명을 표시합니다.

- 텍스트13개 언어와 독립적인 러시아어·영어·독일어·이탈리아어·브라질 포르투갈어 음성. 음성을 바꿔도 러시아어가 유지되던 문제를 수정했습니다. Auto는 게임의 음성 언어를 따릅니다.

추가 수정: 사이클롭스는 소비한 유닛의 전력과 충분한 턴이 남을 때 안 크라이트 대검사의 완전 회복을 고려합니다. 케이런/미루나와 독/엘프 세이버 대상 처리를 수정했습니다. Classic 1.32 RNG는 잘못된 나머지 연산을 피합니다. 손상된 사용자 덱은 검증된 백업에서 복구하며 남은 덱과 원본 손상 데이터를 보존합니다. 알 수 없는 저장 형식은 백업을 덮어쓰지 않습니다. 게임 내 저장/불러오기 검증은 별도로 필요합니다. 같은 저장 피해 수정이 미치광이 루고스에게도 적용됩니다.

## 호환성과 검증

Classic 1.32 및Next-Gen 5.0+용입니다. 승인된 그림, VFX, 음악을 유지합니다. 자동 테스트와 네이티브 컴파일은 게임 내 UI·음성·RNG 검증을 대신하지 않습니다. 과거 성능 비교는 각 고정 버전의 결과이며 이 빌드의 보편적 우위를 주장하지 않습니다.
