# Дополнение к игровой проверке 0.9.5

Проверить на Classic 1.32 и Next-Gen 5.0+ после установки нового архива.
Автоматические отчёты не заменяют эти наблюдения в игре.

- [ ] Hard, Итлинна / Эльфский наёмник: при муллигане подходящая особая возвращается в колоду, если иначе не хватит целей. Ласточка не считается целью Итлинны. Достаточный запас не заставляет возвращать все особые.
- [ ] Последняя особая без полезного продолжения: ИИ не дарит противнику усиление и не уничтожает свой отряд Казнью только из-за запрета пасовать в решающем раунде. Полезная комбинация усиления врага с Казнью остаётся доступна.
- [ ] Бран с Серис, кораблём и воскрешениями: использует подготовку до расходования возможностей воскрешения. Нет сброса Серис ради самого сброса, когда воспользоваться ей уже нельзя.
- [ ] После Казни двух всадников: Эмиссар → выбранный отряд → размещение → отмена направленной цели. Тот же отряд снова ожидает размещения без эффекта гибели/изгнания; родительская карта остаётся сыгранной. Повторная отмена не теряет и не дублирует карту.
- [ ] После подтверждения первой цели отмена закрыта; урон и реакции применяются один раз.

Полный список изменений после 0.9.4 находится в сообщениях Nexus и changelog.
