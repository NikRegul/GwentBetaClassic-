[size=4][color=#e0b354][b]Обмен колодами[/b][/color][/size]

[list]
[*]Импорт и экспорт через буфер обмена в формате BG1. Код не зависит от языка, сохраняет фракцию, лидера и состав, пригоден для обмена между игроками.
[*]Импорт доступен из списка колод и редактора; экспорт — в редакторе. «Копировать» записывает код прямо в буфер Windows (нужна необязательная папка Optional-CopyButton, см. ниже).
[*]Добавлено обратное направление Windows → игра: импорт читает код при открытии, по кнопке «Вставить» и Ctrl+V. Нужна обновлённая GwentBetaClipboard.asi из Optional-CopyButton. Занятый буфер или неверный код сохраняют введённый текст.
[*]Кнопки импорта и экспорта появляются только при установленной Optional-CopyButton; без неё обе скрыты.
[*]Неверная строка не меняет колоды, коллекцию или баланс. Проверяются карты, фракция, лидер, размер и ограничения состава.
[*]Недостающие карты, включая лидера, показываются картами с количеством копий: создайте каждую отдельно или все сразу за общую стоимость. Импорт недоступен, пока чего-то не хватает; незавершённый выбор платной бочки блокирует создание.
[*]Импорт создаёт черновик. Сохранение выполняется обычной кнопкой; занятые пользовательские слоты автоматически не перезаписываются.
[/list]

[size=4][color=#e0b354][b]Изенгрим: Изгой[/b][/color][/size]

Изенгрим: Изгой сравнивает реальную ценность веток особой карты и создания эльфа, в том числе после Королевского указа. ИИ не выбирает Чучело без допустимого союзного бронзового или серебряного отряда. Создание оценивается по случайной тройке предложений, без знания будущего результата генератора.

[size=4][color=#e0b354][b]Встроенная очистка перед удалением мода[/b][/color][/size]

Очиститель включён в основной мод 0.9.0; отдельный архив устанавливать не нужно. Сделайте резервную копию сейва, завершите партию, выйдите из боя и закройте меню. Пока основной мод установлен, bg_clean_preview() покажет инструкцию без изменения данных. Для подтверждения введите:

[code]
bg_clean_confirm('DELETE_BETA_GWENT')
[/code]

Удаляются коллекция беты, колоды, осколки, бочки, настройки, известные наградные записи, оба банка резервных фактов и предметы betagwent_* из текущего инвентаря игрока. Сохраняемый флаг блокирует повторную выдачу стартовых колод и восстановление профиля даже после перезагрузки с установленным модом. Сохранитесь В НОВЫЙ СЛОТ, выйдите из игры, уберите папки мода (для Classic — также его DLC), обновите затронутые объединения Script Merger, загрузите новый слот и сохранитесь ещё раз. Для отмены загрузите исходную резервную копию. Если часть предметов беты удалить не удалось, вместо успеха будет сообщение INCOMPLETE: выбросьте или продайте их и повторите команду. При удалении мода уберите и файлы Optional-CopyButton, если ставили их: bin\…\plugins\GwentBetaClipboard.asi и dinput8.dll из этого мода (не чужой).

Завершённые квесты, достижения и потраченные кроны не откатываются. Команда не обходит выгруженных торговцев, тайник и контейнеры мира: сначала заберите оттуда предметы беты. Для старых наградных фактов может потребоваться приложенный сканер save_fact_index.py и bg_clean_keys('…') после подтверждения очистки. Подробности — BetaGwentDocs/CLEANUP_RU.md. Это очистка профиля, без обещания физического удаления каждой исторической записи произвольного сейва.

[size=4][color=#e0b354][b]BG1[/b][/color][/size]

Экспорт показывает код колоды BG1, не зависящий от языка. «Копировать» помещает его в буфер Windows. Чтобы вставить код в игру, скопируйте его целиком в Windows и откройте импорт: код читается при открытии, а «Вставить» или Ctrl+V читают его снова. Вставка проверяет код; импорт и сохранение остаются отдельными действиями. Неверный код или занятый буфер не меняют введённый текст.

Обеим кнопкам нужна необязательная папка Optional-CopyButton из архива: скопируйте её папку bin в каталог игры (dinput8.dll и plugins/GwentBetaClipboard.asi рядом с witcher3.exe). Замените старую GwentBetaClipboard.asi: прежние версии только копировали из игры. Сам мод работает и без неё. Если у другого мода уже есть свой dinput8.dll, оставьте его и загрузите GwentBetaClipboard.asi через его ASI-загрузчик. Без этих файлов кнопки импорта и экспорта скрыты. С ними код можно также ввести вручную.

Недостающие карты, включая лидера, показываются картами: создайте каждую отдельно или все сразу за общую стоимость в осколках. Импорт недоступен, пока чего-то не хватает. Импорт создаёт черновик: сохраните его кнопкой «Сохранить колоду». Импорт из списка колод использует свободный пользовательский слот и не перезаписывает занятые. В тренировке используется прежняя коллекция без ограничений.
