# Gwent Beta Classic 0.9.3b

Полная версия 0.9.3a с исправлением блокировки: она снимает существующую «Стойкость», поэтому заблокированный Ярпен Зигрин больше не переносится в следующий раунд по старому статусу. Снятие блокировки не возвращает «Стойкость»; её можно отдельно наложить заново.

Также исправлена видимость выбора сложности: кнопка находится в шапке рядом с языками на экране колоды и в редакторе, над панелью состава.

Архивы для Classic 1.32 и Next-Gen 5.0+ включают прежние улучшения ИИ, режим «Классическая», 30 одобренных колод беты и тематические квестовые составы. Обычный ИИ сохраняет ограничения информации; «Классическая» видит настоящую руку и колоду соперника. Управление, языки, изображения, эффекты и звук сохранены.

Правило исправлено одинаково для всех сторон. Установка и публикация не выполняются автоматически. Текущая турнирная сетка остаётся на прежних замороженных правилах 0.9.3.
