## Обмен колодами

В выборе колод доступен «Импорт колоды». В редакторе доступны импорт и экспорт.
Экспорт проверяет состав, сортирует ID и копирует строку в буфер обмена; поле
строки остаётся доступным для ручного копирования, если API буфера недоступен.
Импорт предварительно читает буфер и позволяет вставить/изменить строку.

Формат: `BG1:<маска фракции>:<ID лидера>:<ID карты>,<ID карты>,...`.
Допустимые фракции: 2, 4, 8, 16, 32. Лидер передаётся отдельно от 25–40 карт.
Каждая копия карты перечисляется отдельно. Используются исходные числовые ID
беты; имя колоды, язык интерфейса и номер слота в строку не входят.
Одинаковые составы дают одинаковую строку независимо от порядка карт.
Максимальная длина ввода — 320 символов. Версия формата явно задана `BG1`.

Сначала проверяется вся строка: версия, числа, разделители, существование карт,
фракция, лидер, размер, копии, лимиты золота и серебра. Проверяется ограничение
фракции квеста и наличие свободного слота. Некорректный ввод не меняет черновик,
сохранённую колоду, коллекцию или баланс.

В обычной игре показываются все недостающие карты, включая лидера, количество
копий и суммарная стоимость в осколках. Список можно прокручивать. Кнопка
«Создать недостающие» требует предварительного просмотра той же строки.
Недостаток средств и незавершённый выбор оплаченной бочки блокируют создание
до списания средств. Создание использует обычные цены и лимиты коллекции,
обновляет прогресс и резервную копию профиля. В тренировке используется
существующая неограниченная коллекция, поэтому создание не требуется.

Успешный импорт собирает черновик; текущий слот и название сохраняются.
Сохранённая колода меняется только после «Сохранить колоду». Из выбора колод
импорт занимает свободный пользовательский слот; занятые слоты не перезаписываются
автоматически. Повторный или запоздалый ответ проверяется по ревизии меню.

## Консоль

Результаты выводятся уведомлением и в канал журнала `BetaGwent`.
Выдача ресурсов работает при загруженном сохранении и закрытых меню.
Для магазина, напротив, требуется открытый магазин.

| Команда | Действие |
|---|---|
| `bg_kegs(10)` | +10 неоткрытых бочек в счётчик мода. |
| `bg_scraps(1000)` | +1000 осколков. |
| `bg_card(132102,1)` | Карта/лидер по ID, с соблюдением лимита копий. |
| `bg_find('Имлерих')` | Поиск по части названия без учёта регистра; название и ID. |
| `bg_faction('monsters')` | Карты и лидеры выбранной фракции до лимита. |
| `bg_leaders()` | Все недостающие лидеры. |
| `bg_allcards` | Существующая выдача всей коллекции до лимита. |
| `bg_status()` | Коллекция, копии, бочки, осколки, незавершённый выбор и НГ+. |
| `bg_help()` | Команды, параметры и поддерживаемые фракции. |
| `bg_shopcheck()` | НГ+, категория определения бочки, фактический запас, флаги выдачи. |
| `bg_shoprefill(5)` | Довести запас текущего корчмаря до 5, без повторной добавки сверх цели. |

Фракции: `neutral`, `monsters`, `nilfgaard`, `north`, `scoiatael`, `skellige`.
Для бочек/осколков один вызов принимает 1–1000000, общий счётчик ограничен
2000000000 для защиты от переполнения. Для карты — количество 1–1000,
фактическая выдача всегда ограничена обычным лимитом 3/1/1.
Для запаса корчмаря — цель 1–99. Ноль и отрицательные значения отвергаются.
Повторная выдача карт сверх лимита не превращается в осколки.
Неизвестная схема коллекции не сбрасывается. Выдачи сразу включаются в
резервирование профиля; постоянное сохранение выполняется обычным сохранением игры.

Проверка магазина не создаёт пробный предмет. Она показывает результат запроса
метаданных определения и отдельно подтверждает наличие настоящего предмета
в запасе. При нулевом запасе создание не считается проверенным. Пополнение
проверяет фактическое количество после AddAnItem; при отказе/неполной выдаче
флаги успешного пополнения не устанавливаются. Бочки в инвентарь Геральта
не добавляются. Запас продавца сохраняется штатным сохранением NPC.

## Выравнивание языковых кнопок

В универсальном UI переключатели текста и озвучки расположены вертикально
над левой панелью: X=56, Y=24/78, размер каждой 364×42, интервал 12 пикселей.
Левый и правый края общие; до панели остаётся 16 пикселей. Кнопки не касаются
рамки заголовка. Сохраняется существующее уменьшение шрифта для длинной подписи.
Текст и озвучка по-прежнему переключаются независимо, Auto/fallback сохранены.
Правки Board повторены в пяти копиях; UTF-8 BOM и CRLF сохранены.

## Проверки и дальнейшая приёмка

* 1145 проверок реального WitcherScript, включая 46 составов из каталога,
  неверный ввод, лимиты, создание с точной стоимостью, нехватку средств,
  оплаченный выбор бочки, неизвестную схему, повторную выдачу, переполнение,
  отказ/неполную выдачу предмета, обычный магазин и НГ+ на API-имитации.
* 62 проверки реальных AS-методов: буфер и отказ буфера на имитации,
  подтверждение создания, ревизии, независимые языки, геометрия и пять копий.
* Нативная компиляция Next-Gen WS кандидата успешна; четыре AS-меню
  с проверкой всех привязок собраны. Текстуры сохранены побайтово.
* После удаления авторской части меню: максимум 62.885 МиБ; меню бочек
  58.101 МиБ. Соблюдён текущий запас до 63 МиБ.
* Исходники Classic понижаются в отдельные 80 файлов. Новые используемые
  API проверены по исходникам 1.32. Пробная компиляция Classic-исходников
  компилятором REDkit Next-Gen не прошла из-за несовместимого синтаксиса
  штатных Classic-скриптов (`set`/`map`); это не подтверждение компиляции 1.32.
  Нативный компилятор 1.32 и игра в этой задаче не запускались.

Отчёты: `docs/evidence/features082-ws.json`, `features082-ui.json`,
`features082.json`. Компиляция: `BetaGwent/build/features082/universal-compile`;
меню: `menus-final`, готовые ресурсы без авторской части: `cooked-menus`.

Перед stable проверить в игре на обеих платформах:

1. Экспорт → вставка в сторонний текстовый редактор → импорт обратно; строка
   другого игрока; ручная вставка; длинный и неверный ввод; отмена.
2. Импорт всех имеющихся карт и колоды с недостающими; прокрутка списка;
   создание при достаточном/недостаточном балансе; оплаченный выбор бочки;
   восемь занятых слотов; сохранение/загрузка импортированной колоды.
3. Все команды, ошибочные параметры, повторная выдача, сохранение/загрузка.
4. Обычное прохождение и НГ+: корчмарь → диагностика → пополнение → покупка
   → повторное открытие → сохранение/загрузка. Проверить реальную покупку,
   а не только `bg_kegs`.
5. Обе языковые кнопки: RU/EN, длинные названия, Auto/fallback, контроллер,
   просмотр колод и редактор. Новые диалоги обмена пока имеют русский текст;
   расширение словарей интерфейса остаётся перед публикацией multilingual stable.

Повтор проверок:
`python tools/features082/check_features.py`, `node tools/features082/check_ui.js`.
Подготовка свежего кандидата: `python tools/features082/prepare_candidate.py`
(сохраняет существующий результат и требует свободного каталога вывода).

## Дополнение 18 октября: переход с Redux

Пользователь подтвердил исчезновение тела Геральта при переходе с Redux.
Из сохранённого манифеста старого патча восстановлен исходный список 400
имён карт Redux/Redo Expansion с происхождением и хешами документов:
`data/beta924/compatibility/redux_inventory.json`.

`python tools/features082/prepare_redux_inventory.py` подготавливает отдельный
кандидат `BetaGwent/build/features082/redux-inventory`. Для обычной игры и НГ+
генерируются только 203 отсутствующих определения, 197 штатных не заменяются.
XML побайтово совпал с ранее упакованными определениями (SHA256
7f639d4d2787c6c5a742c69c394276d18793e86e7ee52543bce61d93e2c17ba0).
Скрытые остатки имеют нулевую цену, не занимают слотов экипировки и не содержат
действий; в коллекцию Beta Gwent они не конвертируются. Проверка без изменения
кандидата: `python tools/features082/prepare_redux_inventory.py --verify`.

Этот слой нужен при загрузке сохранения, до десериализации инвентаря.
Скрипт не редактирует сохранения и не устанавливает файлы в игру. Включение
в новые платформенные bundle выполнено в RC1; проверка загрузки остаётся перед stable.
Если потерянный инвентарь уже записан в сохранение, определения не восстановят
его содержимое: для проверки требуется сохранение до потери. Полёт карт в
сброс реализован в новом RC1; первый кандидат от 16 октября его не содержал.
