[size=5][b]Gwent Beta Classic 0.7.3[/b][/size]

[size=4][b]English[/b][/size]

[b]New animations[/b]
This version adds a lot of card and effect animations from the Beta. Not all of them look great yet, but I'm already close to the size limit the game engine allows for the interface, so some of them are simplified. I'll keep polishing them in future updates.

[b]Micro-freezes[/b]
Sometimes the game may freeze for a moment during the opponent's turn. No need to panic — crying is allowed. The game's script engine doesn't let the AI think in a separate thread, so now and then it needs a moment to think. It isn't always noticeable, but it's there. I'll fix it in future versions; so far nothing good has come out of my attempts.

[b]What's next[/b]
The next updates will focus on bug fixes, AI improvements and polishing the animations.

[b]Why five packages?[/b]
Most of the archive size is voice audio. Every package differs only in the voice language: EN, RU, DE, IT, PT-BR.
Install only one package.

[b]Text language[/b]
Every package includes all 13 text translations. You can switch the text language in-game at any time — in the deck menu or during a match in the match menu.

[b]Installing after Redux[/b]
You can install the mod after Redux as well — your Beta decks will be granted.
The inventory loss issue was fixed by CDPR themselves in game version 5.01.

[b]Found a problem? Please post it here.[/b]
I'll be glad of any help with fixing issues — bug reports, logs, translation feedback, anything.

[b]How to enable the log[/b]
[list=1]
[*]Add the launch option [b]-debugscripts[/b] to The Witcher 3 (Steam: Properties → General → Launch Options).
[*]Start the game and reproduce the problem.
[*]Close the game.
[*]Copy the log file (it is overwritten on every launch):
[code]Documents\The Witcher 3\scriptslog.txt[/code]
[*]If the game crashed, also attach the latest .dmp file from:
[code]%LOCALAPPDATA%\CrashDumps[/code]
[*]Attach the files and mention: mod version and package language, text language, game version, other mods, and what you were doing.
[/list]

[size=4][b]Русский[/b][/size]

[b]Новые анимации[/b]
В этой версии добавлено много анимаций карт и эффектов из беты. Не все из них пока выглядят хорошо, но я и так подхожу к лимиту по размеру интерфейса, который позволяет движок игры, поэтому часть из них упрощена. Буду дорабатывать их в следующих обновлениях.

[b]Микрофризы[/b]
Иногда во время хода соперника игра может ненадолго подвиснуть. Бояться не надо, надо плакать. Скриптовый движок игры не позволяет ИИ думать в отдельном потоке, поэтому иногда он может немного подтупить. Это не всегда заметно, но это есть. В будущих версиях поправлю, пока что ничего толкового с этим сделать не вышло.

[b]Что дальше[/b]
Следующие обновления будут в основном исправлять ошибки, улучшать ИИ и дорабатывать анимации.

[b]Почему пакетов пять?[/b]
Основной вес архива — озвучка. Пакеты отличаются только языком голосов: EN, RU, DE, IT, PT-BR.
Устанавливайте только один пакет.

[b]Язык текста[/b]
В любом пакете есть все 13 текстовых переводов. Язык текста можно переключить прямо в игре — в меню колод или во время боя в меню партии.

[b]Установка после Redux[/b]
Мод можно ставить и после Redux — колоды беты будут выданы.
Ошибку с пропажей инвентаря устранили сами CDPR в версии игры 5.01.

[b]Есть проблема? Пишите сюда.[/b]
Буду рад любой помощи в исправлении — отчётам об ошибках, логам, замечаниям по переводу.

[b]Как включить лог[/b]
[list=1]
[*]Добавьте параметр запуска [b]-debugscripts[/b] для The Witcher 3 (Steam: Свойства → Общие → Параметры запуска).
[*]Запустите игру и повторите ошибку.
[*]Закройте игру.
[*]Скопируйте файл лога (он перезаписывается при каждом запуске):
[code]Документы\The Witcher 3\scriptslog.txt[/code]
[*]Если игра вылетела, приложите также последний файл .dmp из:
[code]%LOCALAPPDATA%\CrashDumps[/code]
[*]Приложите файлы и укажите: версию мода и язык пакета, язык текста, версию игры, другие моды и что вы делали.
[/list]
