# Gwent Beta Classic 0.9.5

## 0.9.5 更新内容

- 卡组编辑器：移除领袖下方说明和卡牌列表前的多余间隔。计数器及背景与列表对齐，含旗帜的预览放入右侧凹槽。不再重复显示通用对手称呼，真实姓名保持不变。

- 困难：取消放弃出牌所需的固定26点领先。对于已进行较久、可以让出的回合，决策会考虑公开信息下的回应强度、手牌差和再打一张牌的成本，以保留最后的手牌。

- AI通过真实清场流程预测下一回合的初始场面，包括坚韧、莫克瓦格归来、削弱和封锁。如果空过会使自己落后，可以保留手牌并让出先手；资源充足时仍可施压。不读取隐藏卡牌或未来抽牌。

- 0.9.5重新构建：修正Olaf的野兽打出记录、Xavier Moran按卡牌模板战力获得的增益、Ciri: Dash的坚韧，以及Morkvarg在复归前于墓地削弱的顺序。恢复预览卡牌尺寸，调整计数面板边距，并加入达到25张牌时的原版特效。

- 继续修正规则：Cursed Knight会完全重置另一张同名卡；Hubert Rejk只吸收牌库中已增益卡牌的增益，不会治疗受伤卡牌。非战场区域中当前与基础战力均为零时，会放逐且不触发遗愿；Morkvarg在墓地削弱至零时同样放逐。

- Olgierd只在被消灭后于回合结束时返回；从手牌丢弃不会触发返回，离开墓地会清除被消灭标记。

- 全部511张牌的主要分支均已独立检查，所有能力组合仍待验证。修正可选选择、洗牌、卡牌顺序及Francesca、Lugos、Agitator、False Ciri和Wolfsbane。处理九项遗留问题：Bloody Flail无目标仍生成单位，False Ciri保留行内位置，Emhyr在回合结束时收回卡牌，Monster Nest在部署前增益；修正Dimun的随机流程与Ge’els的回牌顺序，移除Yennefer的空等待。已确认模板池顺序，并在每个选项位置验证Shupe两种形态的全部五种模式；15点伤害可选择双方单位。

- 新版测试版风格卡组与收藏菜单：阵营及卡组名称标题、六列卡牌、方形筛选与搜索、右侧制作面板。新增卡组行和数量动画、手柄按钮提示及硬币上的长按放弃出牌进度。

- 更新选牌与换牌窗口、含卡牌和碎片奖励的结算页、历史记录、对战菜单、牌库及墓地查看、导入与确认对话框。保留独立关键词说明，对齐手柄提示并接入窗口音效。这是功能适配；精确外观、原版动画及游戏内验收仍未完成。

- 在能力首次产生效果前，可用右键、Esc 或手柄返回键取消选目标。蟹蜘蛛女王在首次吞噬前返回领袖栏。由其他卡牌打出的单位返回摆放选择，不撤销父卡牌。牌库/墓地选牌不可取消。修复图集边框和连续滚动；奖励与进度使用所得卡牌的阵营，包括中立。AI 天气预测只消耗一次护甲，并考虑较弱相邻单位的死亡。

- 修复王冠彩色伪影、羊皮纸接缝及切换鼠标/手柄时的按钮文字居中。移除说明中的滚轮提示，恢复护甲破裂音效。使者有可用卡牌时必须打出。定向能力在首次行动前保持未确认状态，萝卜等反应等待目标确认。哈拉尔德计算整行伤害及对手跳过后的霜冻；空手且非必争局仍会输时保留领袖。

0.9.4/0.9.4a存档格式不变。不宣称整体强度提升。自动验证不能代替Classic 1.32和Next-Gen 5.0+的游戏内测试。

**更多牌组，更周全的出牌，重温公测昆特牌。**

将公测时期的昆特牌带回The Witcher 3：熟悉的卡牌、完整牌组编辑器，以及遍布游戏世界的对手。公开版0.9.3汇总了0.9.1以来的变更和近期对局日志中发现的问题修复。

## 0.9.4a 更新内容

- 卡组编辑器：添加和移除卡牌时会播放从测试版文件移植的特效 UIDBCardAdd 和 UIDBCardRemove。特效显示在收藏中的卡牌上，减弱特效时不显示。

- 领袖和阵营现在只在创建卡组时选择。此前编辑器中的阵营按钮可能更换领袖并从卡组中移除卡牌。导入到已打开的卡组时，只接受其领袖和阵营的代码。

- 编辑器的筛选和搜索从第一张卡牌开始显示结果，游戏迟到的响应不会再打乱编辑器。

- 手柄：选择目标时会像使用鼠标一样再次显示瞄准箭头。

- 幽灵鲸现在会像测试版一样在回合结束时总是移到另一排，不会留在原排。若其他排都没有空位，它会留在原地并仍造成伤害。

- AI：困难模式会把谢尔顿·斯卡格斯放在真正能分散单位并获得增益的排。经典模式在有好招时不会再因计算未完成而放弃跟牌。

- AI会在对手放弃出牌后继续计算当前回合结束时触发的船只效果，并在排末放置卡牌时保留选定的排。

- 卡组计数器会标示金卡、银卡超限，以及卡组25至40张的上下限。

0.9.4 的存档可直接使用，存储格式没有变化。自动测试和两种编译器不能代替游戏内的确认。

## 0.9.4 更新内容

- Next-Gen 5.x 只保存模组为杰洛特添加的前 45 个字段，且该上限由所有已安装的模组共享。游戏事实只保存 16 位数值。Beta Gwent 使用的字段更多，因此与其他模组同时使用时，读档后卡组、酒桶和碎片可能消失。现在整个档案存放在由四个字段组成的单一存储中，事实中的备份也拆分为可容纳于 16 位的部分写入。

- 恢复流程也得到加强：首次修改前先读取档案；损坏的原始数据和隔离的卡组会保留用于恢复，未知的未来格式则设为只读。格式 2 可读取格式 1，并在接受记录前同时验证数值数据以及文本的长度和完整性。若数据既不在存档中，也不在可用备份中，则无法恢复。

- 现有存档会在首次读取时自动迁移。

- 锦标赛后修正了 AI 在短局中涉及间谍的一项决策。开发样本为 368 场、50%、零错误。尚未运行留出的测试样本，整体实力提升尚未得到证实。困难模式仍受玩家可见信息的限制；经典模式可访问更多隐藏信息。

适用于 Next-Gen 5.0+ 和 Classic 1.32。在 1.32 上，旧字段仍会与新存储一同保存。使用 0.9.4 保存后，不支持退回 0.9.3。自动测试和原生编译不能代替在游戏中进行“保存、退出、读取”的确认。

## 主要特色

- 新增30套获准导入的原版公测牌组，加上现有46套，共76套常规配置与33套任务角色主题预设，去重后92种构成。保留原始牌组名称。15套相似牌组暂缓，28套不符合构筑条件的牌组排除。

- “经典”是移植原版公测AI的第四档难度，24个原始配置对应109套预设，可在对局前的语言设置旁选择。此AI能够查看玩家手牌和牌库；普通困难AI保留原有的信息限制。

- 困难AI改进了领袖后的后续行动、短决胜局的出牌顺序、让局前的过牌与有效放弃跟牌。增益会考虑门诺和战力重置，伤害会考虑奎特家族巨剑士的恢复。揭示牌组会比较对手隐藏手牌与己方揭示联动的收益。 存在隐藏伏击时，响应树会在预算内考虑公开信息允许的陷阱，不读取实际隐藏牌。修复了两个陷阱的计时器顺序及剩余副本数量计算。保留每步最多模拟一个行动；这并不证明整体强度提升。

- 候选卡牌现在以独立窗口展示。坎塔蕾拉清楚标明保留哪张、哪张放回牌库底。隐藏牌保持牌背显示。以对手姓名替代内部配置名，移除多余的“你的牌组”标题和领袖下方空白。修复白霜的手柄焦点、难度按钮显示、空手自动放弃跟牌，以及对手放弃后浪费天气牌的问题。 选牌窗口现在会说明结果：乌达瑞克选中的牌加入手牌，另一张进入墓场。其他需要说明卡牌去向的选择也有类似提示，其余选择显示卡牌能力文本。

- 支持13种文本语言，语音可独立选择俄语、英语、德语、意大利语和巴西葡萄牙语。修复切换语音后仍播放俄语台词的问题。Auto跟随游戏语音语言。

新增修复：独眼巨人会考虑吞噬单位提供的伤害，并在剩余回合足够时计入奎特家族巨剑士的完整恢复。修复Kayran/Miruna以及毒和精灵军刀的目标处理。Classic 1.32随机数避开有缺陷的取余运算。损坏的自定义牌组从校验过的备份恢复，并保留尚存牌组及原始损坏数据。未知存档格式不会覆盖备份。仍需在游戏内验证保存和读取。 同样的存储伤害修复也适用于疯子卢戈。

## 兼容性与验证

适用于Classic 1.32与Next-Gen 5.0+。保留已确认的美术、特效和音乐。自动测试及原生编译不能替代游戏内界面、语音和RNG验收。历史强度比较仅对应各自冻结版本，不宣称本版在所有牌组上都更强。
