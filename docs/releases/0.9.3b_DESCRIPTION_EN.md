# Gwent Beta Classic 0.9.3b

Complete 0.9.3a content with corrected Lock behavior: it removes existing Resilience, so locked Yarpen Zigrin no longer carries into the next round through the old status. Unlocking does not restore Resilience; a separate later grant still works.

Also fixes difficulty-button visibility in deck setup and the deck editor: the control fits beside the language settings above the deck panel.

Classic 1.32 and Next-Gen 5.0+ packages retain the prior AI improvements, Classic difficulty, 30 approved Beta decks and thematic quest presets. Ordinary AI keeps its information restrictions; Classic can inspect the opponent's actual hand and deck. Controls, languages, art, effects and audio are preserved.

The rule applies identically to all sides. No automatic installation or publication. The running tournament remains on its old frozen 0.9.3 rules.
