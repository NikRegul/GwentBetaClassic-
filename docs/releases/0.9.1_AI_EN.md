# 0.9.1 — AI and bug fixes

This candidate builds on 0.9.0 final17, preserving the profile fixes, Classic shops/texts, TestMenu keg rewards, native art fragments, Classic reward randomness, accepted combat effects and clipboard bridge. Further bug fixes belong to the same 0.9.1 line and require their own checks.

The AI plans hand preservation, second-round pressure and attempts to draw costly replies. It reconsiders after public actions. An affordable win and match survival override resource preservation. Existing target selection, consume/Deathwish, discard/resurrection and pass catch-up logic are tested alongside the planner.

Bran's self-wound/Greatswords roster replaces Triss: Telekinesis with Wild Boar of the Sea (Морской Вепрь). Its own list had no bronze special targets for Triss; the replacement supports wounds and neighbours independently of the opposing deck. Triss's card rules are preserved. Additional roster updates are listed in 0.9.1_CHANGELOG_EN.md. Poor AI results with Consume Nekkers, Arachas Swarm and Adda indicate an AI strategy investigation, not proof that those human-played archetypes are weak.

Maximum (high) difficulty receives the player's starting deck list at match initialization. This is an explicit information advantage. The current hand, deck order and actual remaining draw pile remain hidden. Only publicly seen copies are subtracted from the starting list; the uncertain pool includes both hand and deck. Easy and normal do not use the exact starting list. Raising difficulty during a match that started on a lower setting never reconstructs the list from hidden cards.

After an opponent passes, AI retains combo reserves even when it must win round two. Brewess: Ritual, Nekkers and a Slyzard with a Nekker follow-up give way to a cheap card that already wins. Necessary catch-up and round-three plays remain available. The Eggs/Consume gameplay-log regression checks actual decisions and ability resolution.

Run `Build-0.9.1.cmd`. The builder freezes sources, runs regression and archetype scenarios plus 5,632 seeded tactical positions at four search budgets, compiles both game targets and verifies every packaged file. A default run creates a dated output directory recorded in `BetaGwent/build/release091-latest.json`. Use `--resume` for its unchanged frozen inputs, or specify an explicit `--out`. This task's new candidate is `BetaGwent/build/release091-candidate12/archives`. The builder does not install the mod or publish a release. Native gameplay, save/load and visual acceptance remain separate checks; compilation alone does not close them.

Additional reviewed roster, gamepad and Classic loading changes are included in both 0.9.1 packages as applicable. See 0.9.1_CHANGELOG_EN.md for the complete release delta.
