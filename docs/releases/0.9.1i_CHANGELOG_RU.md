# Gwent Beta Classic 0.9.1i

ИИ проверяет продолжение после разных ответов игрока: собственная карта → возможный ответ → следующая собственная карта. Для каждого ответа выбирается отдельное продолжение. При полностью раскрытой руке учитывается худший из рассмотренных ответов; для неизвестной руки используются ограниченные публичные гипотезы. Эти гипотезы не выдаются за знание настоящей руки.

Точный розыгрыш перспективных карт и ограниченный анализ продолжений теперь доступны также на лёгкой и средней сложности. Уровни различаются глубиной и шириной анализа. Первоначальный состав противника по-прежнему доступен только максимальной сложности; скрытая рука и будущий порядок добора не раскрываются.

Добавлен поиск до конца небольшого открытого финала с простыми отрядами и Казнью: до шести доступных карт, без активных лидеров, погоды и неподдерживаемых способностей. Противник может играть или пасовать. Неполный поиск при исчерпании бюджета не считается доказательством победы или поражения. Уже выигрышный пас имеет приоритет перед лишним розыгрышем.

Поиск выполняется небольшими шагами, не более одного пробного розыгрыша за вызов. Сохранены правила экономии ресурсов из h. Составы колод, начальные очки, визуальные эффекты и музыка не изменены. В конструкторе звучит тема главного меню из беты, в матчах остаётся прежняя музыка The Witcher 3.

Новые проверки сверяют открытые финалы с независимым арифметическим решателем, проверяют отдельные ответы/продолжения, пределы бюджета, скрытую информацию, сохранность реального состояния и RNG, одинаковую работу пошагового и синхронного вызова. Подробности итоговых прогонов и компиляций находятся рядом с архивами. Проверки стенда и компиляция не заменяют ручную проверку нативной игры.

Это развитие тактического планирования. Полного дерева нескольких раундов, совместных гипотез неизвестной руки/колоды и перебора всех целей способностей ещё нет. Короткие сравнения с h не являются полным новым рейтингом колод.
