# 0.8.2-rc2 — кнопки обмена в редакторе

18 октября 2026. Исправление по игровой проверке пользователя на 5.0+:
нажатие «Импорт колоды»/«Экспорт колоды» в редакторе ничего не открывало.

Причина: `beginDeckEditor` выставляет `editingDeck=true`, `selectingDecks=false`.
В `openDeckExchange` ошибочно требовался `selectingDecks=true` даже для редактора.
Обработчик сразу возвращал управление, не создавая окно и не отправляя событие
WitcherScript. Это объясняет отсутствие событий обмена в скриптовом логе.
В найденном `Documents/The Witcher 3/scriptslog.txt` при начале проверки было
0 байт (время изменения 01:23:08); ошибки из него извлечь невозможно.

Теперь импорт открывается из списка колод и из редактора; экспорт — из
редактора. Проверки готовности интерфейса, повторного окна и доступности
экспорта сохраняются. Исправление повторено в пяти копиях UI обеих платформ,
UTF-8 BOM и CRLF сохранены. Все остальные AS-исходники совпадают с RC1.
WitcherScript, скомпилированный blob, звук и определения предметов не менялись.

Проверка `tools/features082/check_exchange_open.js` выполняет реальные методы
рисования кнопок и открытия окна. Воспроизводит отказ RC1, вызывает обработчик
нажатия каждой кнопки в редакторе, проверяет создание окна/поля, фокус ввода,
чтение буфера и отправку события экспорта с правильной ревизией. Также проверяет
импорт из списка и отклонение недопустимых состояний. Пройдено 30 проверок
для двух платформ; прежние 62 проверки обмена и буфера также прошли.

Пересобраны восемь меню с 60 Flash-привязками каждое. При упаковке проверяются
все payload/metadata и CRC архивов тем же аудитом, что для RC1. Данные боя
не перекомпилируются: используются побайтово те же уже проверенные скрипты.

Архивы:

- `BetaGwent/release/GwentBetaClassic-0.8.2-rc2-5.0+-AllLanguages.zip`
- `BetaGwent/release/GwentBetaClassic-0.8.2-rc2-1.32-AllLanguages.zip`

Сборка и отчёты: `BetaGwent/build/release082-rc2`.
Подготовка: `tools/features082/prepare_exchange_fix.py`.
Упаковка: `tools/features082/build_exchange_fix.py`.
Аудит: `python tools/features082/verify_release.py BetaGwent/build/release082-rc2`.
Установка 5.0+: `tools/features082/install_exchange_fix.py`, только поверх
проверенного RC1 и при закрытой игре, с резервной копией заменяемых файлов
в `BetaGwent/build/release082-rc2/installed-before-nextgen`.
Фактический результат установки записывается в `install-nextgen.json`.

Установка выполнена в `F:/Steam/steamapps/common/The Witcher 3` при закрытой
игре. Заменены только `content/blob0.bundle`, `content/metadata.store` и
`info.json`; SHA256 после копирования совпали со сборкой. Скриптовый blob,
звук и dep.cache сохранили хеши RC1. Резервная копия создана по указанному
выше пути. Оба архива прошли полный аудит; лимиты ресурсов соблюдены.

Для приёмки: заново запустить игру, открыть редактор и нажать «Экспорт колоды»,
затем «Импорт колоды». Проверить появление окна и копирование/вставку строки.
Полная игровая приёмка RC1 и локализация новых сообщений по-прежнему остаются
перед stable; этот кандидат исправляет конкретный отказ открытия окон.
