# Регрессии Gwent Beta Classic 0.8.2

## Порядок и фиксация результата

Каждый игровой сценарий выполняется отдельно на 1.32 и 5.0+. Пустой результат означает, что сценарий ещё не выполнялся: успешная компиляция или проверка JS не подменяет игровую отметку. Используйте `RESULTS.csv`: PASS / FAIL / BLOCKED / NOT_RUN, версия игры, разрешение, ввод, текст/озвучка, сохранение, фактический результат и ссылка на свидетельство.

Начинать с SMK, PAD, EX, VS, FX, SAVE; затем LOC, CON и AI. Для короткого прохода: SMK-01–03, PAD-01–02, EX-01–04, VS-01–03, FX-01–03, SAVE-01. После найденной ошибки повторить её сценарий и соседние по затронутой системе.

Работать на копии сохранения. Для изменяющих коллекцию/валюту команд и тестов создания карт используйте отдельный тестовый слот. Перед сценариями EX и CON записывать состав сохранённой колоды, черновик, слоты, число копий карт, осколки, бочки и незавершённый выбор. Это исходное состояние **S0**. Для неверного кода и отмены сравнивать эти поля с S0.

Наборы: **A** — все карты выбранной колоды уже есть; **B** — отсутствует несколько карт, включая лидера; **C** — все восемь пользовательских слотов заняты; **D** — есть оплаченный незавершённый выбор бочки; **R** — копия сохранения Redux до исчезновения инвентаря/тела. Сейвы не входят в комплект: указать их реальные имена в CSV.

`BG1_FIXTURES.json` содержит 46 кодов реальных колод каталога, пять выбранных примеров разных фракций и некорректные строки. `BG1_VALID.txt` удобен для копирования; пояснения не являются частью кода. Генератор проверяет коды настоящим парсером из зафиксированных исходников, не меняя коллекцию в игре.

## Регрессии решений ИИ

Эти точные позиции задаются существующими фикстурами в JS, исполняющими переведённый настоящий WitcherScript. Для ручного игрового повтора нужен соответствующий сейв; не ждать случайного совпадения ситуации. Базовый уровень — как в фикстуре (`Host.strength=4`), seed и начальные состояния фиксированы. Уровни интерфейса проверять отдельными сериями, не приписывая им тот же обязательный выбор. Отсутствие ошибки не означает обязательную победу ИИ.

| ID | Позиция и действие | Ожидаемый результат / точная фикстура |
|---|---|---|
| AI-01 | Раунд 3: у ИИ 12 силы, у игрока 6, единственная карта ИИ — Казнь. Запросить ход. | Пасс, свой сильнейший отряд не сгорает. `tools/ai/check_losing131.js`, первая позиция. |
| AI-02 | Обратная позиция: у ИИ 6, у игрока 12; та же Казнь. | Казнь сыграна и уничтожает врага; нет незавершённого запроса. Тот же файл, вторая позиция. |
| AI-03 | Два своих отряда по 11, чужой 10; выбор особой карты через Последнее желание. | Вложенный выбор не считает собственную Казнь положительным уроном: выбран безопасный Лютик. `check_miruna_aglais_scorch180.js`. |

## Минимальный отчёт об ошибке

ID сценария; версия/архив и версия игры; язык текста/голосов; ввод и разрешение; имя исходного сейва; шаги; ожидание и факт. Для ИИ дополнительно: seed, ходящий игрок, раунд/короны, счёт, руки, открытое поле со статусами, выбранный ход и более полезная альтернатива с причиной. Приложить видео для таймингов или снимок для вёрстки; при наличии — свежий лог. Одна ошибка — одна запись.
