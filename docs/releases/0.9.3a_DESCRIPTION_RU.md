# Gwent Beta Classic 0.9.3a

Полная сборка для Classic 1.32 или Next-Gen 5.0+, включающая содержимое 0.9.3 и исправления собственного ИИ: победный пас, исчерпанную руку соперника, сохранение ничьей, согласованную оценку продолжений и соблюдение бюджета при замене хода лидером на карту из руки.

Обычные сложности сохраняют ограничения на закрытую информацию. Отдельная «Классическая» использует перенесённую логику беты, назначенные колодам исходные профили и видит настоящую руку и колоду соперника. Сложность выбирается до партии рядом с языками.

Сохранены 76 обычных составов противников и 33 тематических квестовых варианта, принятые эффекты, обложки, музыка и управление. Проверки корректности не являются доказательством общего усиления; новая версия не подменяет входы уже запущенного турнира.

Выберите архив для своей версии игры. Требуются обычная ручная установка и проверка совместимости с другими скриптовыми модами по приложенному руководству. Автоматическая установка и публикация не выполнялись.
