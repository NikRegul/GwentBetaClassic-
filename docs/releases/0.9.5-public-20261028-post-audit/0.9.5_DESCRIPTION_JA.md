# Gwent Beta Classic 0.9.5

## 0.9.5の変更点

- デッキエディター：リーダー下の説明とカード一覧までの余白を削除しました。枚数表示と背景を一覧に整列し、旗を含むプレビューを右側のくぼみに収めました。汎用の対戦相手名の重複をなくし、実際の名前は維持します。

- ハード：パスに必要だった固定26点差を廃止しました。任意に譲れるラウンドが進んだ時は、公開情報から見た応答の強さ、手札枚数差、さらに1枚使う費用を考慮し、最後のカードを温存します。

- AIは実際の盤面整理処理で次ラウンドの初期盤面を予測します。耐性、モークヴァーグの復帰、弱体化、封印を反映します。空パスで不利になる時は手札を残して先手を譲ることも、十分な資源で攻めることも可能です。隠れたカードや将来のドローは読みません。

- 0.9.5再ビルド：Olafの野獣履歴、Xavier Moranの元のカード定義の戦力による強化、Ciri: Dashの耐性、Morkvargが復帰前に墓地で弱体化する順序を修正しました。プレビューのカードサイズとカウンターの余白を調整し、25枚到達時の元のエフェクトを追加しました。

- ベータのルールを追加修正：Cursed Knightは別の同名カードを完全にリセットし、Hubert Rejkはデッキの強化分だけを吸収し、負傷カードを回復しません。非アクティブ領域で現在戦力と基本戦力がともに0になると、遺言なしで消滅します。墓地で0になったMorkvargにも適用されます。

- Olgierdは倒された場合のみターン終了時に戻ります。手札から捨てても戻らず、墓地を離れると撃破フラグが解除されます。

- ベータ風のデッキ・コレクション画面：勢力とデッキ名の見出し、6列のカード、四角いフィルターと検索、右側の作成パネル。行と枚数のアニメーション、コントローラーのボタン表示、コイン上のパス長押し表示も追加しました。

- カードの選択・交換、カードと紙片の報酬を表示する結果画面、履歴、対戦メニュー、デッキ・墓地の閲覧、インポート・確認ダイアログを更新しました。独立したキーワード解説、整列したコントローラー表示、ウィンドウの効果音を含みます。機能面の移植であり、正確な外観、元のアニメーション、ゲーム内での確認は未完了です。

0.9.4/0.9.4aのセーブ形式は変わりません。全体的な強さの向上は主張しません。自動検証だけでなくClassic 1.32とNext-Gen 5.0+のゲーム内確認が必要です。

**多彩なデッキ。考え抜かれた一手。ベータ時代のグウェント。**

オープンベータのグウェントをThe Witcher 3へ。おなじみのカード、デッキ編集、各地の人物との対戦を楽しめます。公開版0.9.3は0.9.1以降の変更と最新プレイログに基づく修正をまとめた版です。

## 0.9.4aの変更点

- デッキエディター：カードの追加・削除時に、ベータのファイルから移植したエフェクトUIDBCardAddとUIDBCardRemoveが再生されます。エフェクトはコレクションのカード上に表示され、エフェクトを控えめにする設定では表示されません。

- リーダーと勢力はデッキ作成時にのみ選択するようになりました。以前はエディターの勢力ボタンでリーダーが置き換わり、デッキからカードが外れることがありました。開いているデッキへのインポートは、そのデッキのリーダーと勢力のコードのみ受け付けます。

- エディターのフィルターと検索は最初のカードから結果を表示し、ゲームからの遅れた応答でエディターが乱れることはなくなりました。

- ゲームパッド：対象を選ぶとき、マウスと同じく照準の矢印が再び表示されます。

- 霊鯨はベータと同様に、ターン終了時に必ず別の列へ移動し、元の列にとどまらなくなりました。ほかの列に空きがない場合はその場にとどまり、ダメージは与えます。

- AI：ハードはシェルドン・スカッグスを、実際にユニットを散らしてブーストを得られる列に配置します。クラシックは、有利な手があるのに計算が未完了のためパスすることがなくなりました。

- AIは相手のパス後も現在のターン終了時に発動する船の効果を考慮し、列の端に配置する際も選択した列を維持します。

- デッキのカウンターはゴールドとシルバーの上限超過、および25～40枚というデッキ枚数の両方の境界を示します。

0.9.4のセーブはそのまま使えます。保存形式は変わっていません。自動テストと両方のコンパイラーは、ゲーム内での確認の代わりにはなりません。

## 0.9.4の変更点

- Next-Gen 5.xは、MODがゲラルトに追加したフィールドのうち最初の45個しか保存せず、この上限はインストールされた全MODで共有されます。また、ゲームのファクトは16ビットの数値しか保持しません。Beta Gwentはより多くのフィールドを使っていたため、他のMODと併用するとロード後にデッキ、樽、スクラップが消えることがありました。現在はプロフィール全体を4つのフィールドからなる単一の保存領域に格納し、ファクトのバックアップも16ビットに収まる部分に分けて書き込みます。

- 復元処理も強化しました。プロフィールは最初の変更前に読み込まれ、破損した元データと隔離されたデッキは復元用に保持されます。未知の将来形式は読み取り専用です。形式2は形式1を読み込み、記録を受け入れる前に数値データとともにテキストの長さと整合性を検証します。セーブにも利用可能なバックアップにも存在しないデータは復元できません。

- 既存のセーブは初回ロード時に自動で移行されます。

- 大会後、短いラウンドでスパイを使う際のAIの判断を修正しました。開発用サンプルは368試合、50%、エラー0件です。保留テスト用サンプルは実行しておらず、総合的な強さの向上は確認されていません。ハードは引き続きプレイヤーに見える情報に制限され、クラシックはより広く隠し情報へアクセスします。

Next-Gen 5.0+とClassic 1.32に対応。1.32では従来のフィールドも新しい保存領域と並んで保存されます。0.9.4で保存した後に0.9.3へ戻すことはサポートされません。自動テストとネイティブコンパイルは、ゲーム内での「保存・終了・ロード」の確認の代わりにはなりません。

## 主な機能

- 承認済みの元ベータデッキ30種を既存46種へ追加。通常構成76種、クエスト人物用33設定、重複を除く構成は92種です。元のデッキ名を保持。類似15種は保留、構築条件を満たさない28種は除外しました。

- 「クラシック」はベータ版AIを移植した4つ目の難易度です。24種の元プロフィールを109のデッキ設定に割り当て、対戦前の言語設定横で選べます。このAIはプレイヤーの手札とデッキを参照します。通常のハードは従来の情報制限を維持します。

- ハードは指導者後の展開、短い決着ラウンドのカード順、ラウンドを譲る前のドロー、有効なパスを改善。強化ではメンノや戦力リセット、ダメージではアンクライトの大剣使いの回復を考慮します。公開デッキは相手の非公開手札と自分の公開シナジーを比較します。 非公開の待ち伏せがある場合、相手の秘密カードを読まず、公開情報で可能な罠を予算内で検討します。罠が2枚ある際のカウント順と残り枚数の扱いを修正しました。1ステップ1行動のシミュレーションを維持します。全体的な強さの向上を示すものではありません。

- 提示カードを専用画面で選択。カンタレラでは残すカードとデッキ最下部へ戻すカードが明確になります。非公開カードは裏向きのままです。内部プロフィール名を対戦相手名へ変更し、不要なデッキ見出しと指導者下の空白を削除。白き霜のコントローラー選択、難易度表示、自動パス、相手パス後の無駄な天候も修正しました。 カード選択画面に結果の説明を追加。ウダルリックでは選んだカードが手札に、もう1枚が墓場に送られます。カードの行き先が重要な他の選択にも同様の説明を付け、それ以外では能力テキストを表示します。

- テキスト13言語と独立したロシア語・英語・ドイツ語・イタリア語・ブラジルポルトガル語音声。音声を変更してもロシア語のままになる不具合を修正。Autoはゲーム音声言語に従います。

追加修正：サイクロプスは捕食したユニットの戦力と、十分なターンが残る場合のアンクライト大剣使いの完全回復を考慮します。ケイラン／ミルナと毒／エルフのサーベルの対象処理を修正。Classic 1.32のRNGは不正な剰余演算を回避します。破損したカスタムデッキは検証済みバックアップから復元し、残存デッキと元の破損データを保持します。不明な保存形式はバックアップを上書きしません。ゲーム内でのセーブとロードの確認は別途必要です。 同じ保存ダメージの修正はルゴス狂人にも適用されます。

## 互換性と検証

Classic 1.32とNext-Gen 5.0+向け。承認済みイラスト、VFX、音楽を保持。自動テストとネイティブコンパイルはゲーム内UI・音声・RNGの動作確認を代替しません。過去の強さ比較は各固定版の結果であり、本版の普遍的優位性は主張しません。
