# Gwent Beta Classic 0.9.3

**更多牌组，更周全的出牌，重温公测昆特牌。**

将公测时期的昆特牌带回The Witcher 3：熟悉的卡牌、完整牌组编辑器，以及遍布游戏世界的对手。公开版0.9.3汇总了0.9.1以来的变更和近期对局日志中发现的问题修复。

## 主要特色

- 新增30套获准导入的原版公测牌组，加上现有46套，共76套常规配置与33套任务角色主题预设，去重后92种构成。保留原始牌组名称。15套相似牌组暂缓，28套不符合构筑条件的牌组排除。

- “经典”是移植原版公测AI的第四档难度，24个原始配置对应109套预设，可在对局前的语言设置旁选择。此AI能够查看玩家手牌和牌库；普通困难AI保留原有的信息限制。

- 困难AI改进了领袖后的后续行动、短决胜局的出牌顺序、让局前的过牌与有效放弃跟牌。增益会考虑门诺和战力重置，伤害会考虑奎特家族巨剑士的恢复。揭示牌组会比较对手隐藏手牌与己方揭示联动的收益。 存在隐藏伏击时，响应树会在预算内考虑公开信息允许的陷阱，不读取实际隐藏牌。修复了两个陷阱的计时器顺序及剩余副本数量计算。保留每步最多模拟一个行动；这并不证明整体强度提升。

- 候选卡牌现在以独立窗口展示。坎塔蕾拉清楚标明保留哪张、哪张放回牌库底。隐藏牌保持牌背显示。以对手姓名替代内部配置名，移除多余的“你的牌组”标题和领袖下方空白。修复白霜的手柄焦点、难度按钮显示、空手自动放弃跟牌，以及对手放弃后浪费天气牌的问题。 选牌窗口现在会说明结果：乌达瑞克选中的牌加入手牌，另一张进入墓场。其他需要说明卡牌去向的选择也有类似提示，其余选择显示卡牌能力文本。

- 支持13种文本语言，语音可独立选择俄语、英语、德语、意大利语和巴西葡萄牙语。修复切换语音后仍播放俄语台词的问题。Auto跟随游戏语音语言。

新增修复：独眼巨人会考虑吞噬单位提供的伤害，并在剩余回合足够时计入奎特家族巨剑士的完整恢复。修复Kayran/Miruna以及毒和精灵军刀的目标处理。Classic 1.32随机数避开有缺陷的取余运算。损坏的自定义牌组从校验过的备份恢复，并保留尚存牌组及原始损坏数据。未知存档格式不会覆盖备份。仍需在游戏内验证保存和读取。 同样的存储伤害修复也适用于疯子卢戈。

## 兼容性与验证

适用于Classic 1.32与Next-Gen 5.0+。保留已确认的美术、特效和音乐。自动测试及原生编译不能替代游戏内界面、语音和RNG验收。历史强度比较仅对应各自冻结版本，不宣称本版在所有牌组上都更强。
