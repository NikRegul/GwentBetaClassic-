# Gwent Beta Classic 0.9.5 — 0.9.5 更新内容

- 卡组编辑器：移除领袖下方说明和卡牌列表前的多余间隔。计数器及背景与列表对齐，含旗帜的预览放入右侧凹槽。不再重复显示通用对手称呼，真实姓名保持不变。

- 困难：取消放弃出牌所需的固定26点领先。对于已进行较久、可以让出的回合，决策会考虑公开信息下的回应强度、手牌差和再打一张牌的成本，以保留最后的手牌。

- AI通过真实清场流程预测下一回合的初始场面，包括坚韧、莫克瓦格归来、削弱和封锁。如果空过会使自己落后，可以保留手牌并让出先手；资源充足时仍可施压。不读取隐藏卡牌或未来抽牌。

- 0.9.5重新构建：修正Olaf的野兽打出记录、Xavier Moran按卡牌模板战力获得的增益、Ciri: Dash的坚韧，以及Morkvarg在复归前于墓地削弱的顺序。恢复预览卡牌尺寸，调整计数面板边距，并加入达到25张牌时的原版特效。

- 继续修正规则：Cursed Knight会完全重置另一张同名卡；Hubert Rejk只吸收牌库中已增益卡牌的增益，不会治疗受伤卡牌。非战场区域中当前与基础战力均为零时，会放逐且不触发遗愿；Morkvarg在墓地削弱至零时同样放逐。

- Olgierd只在被消灭后于回合结束时返回；从手牌丢弃不会触发返回，离开墓地会清除被消灭标记。

- 新版测试版风格卡组与收藏菜单：阵营及卡组名称标题、六列卡牌、方形筛选与搜索、右侧制作面板。新增卡组行和数量动画、手柄按钮提示及硬币上的长按放弃出牌进度。

0.9.4/0.9.4a存档格式不变。不宣称整体强度提升。自动验证不能代替Classic 1.32和Next-Gen 5.0+的游戏内测试。

## Gwent Beta Classic 0.9.4a — 0.9.4a 更新内容

- 卡组编辑器：添加和移除卡牌时会播放从测试版文件移植的特效 UIDBCardAdd 和 UIDBCardRemove。特效显示在收藏中的卡牌上，减弱特效时不显示。

- 领袖和阵营现在只在创建卡组时选择。此前编辑器中的阵营按钮可能更换领袖并从卡组中移除卡牌。导入到已打开的卡组时，只接受其领袖和阵营的代码。

- 编辑器的筛选和搜索从第一张卡牌开始显示结果，游戏迟到的响应不会再打乱编辑器。

- 手柄：选择目标时会像使用鼠标一样再次显示瞄准箭头。

- 幽灵鲸现在会像测试版一样在回合结束时总是移到另一排，不会留在原排。若其他排都没有空位，它会留在原地并仍造成伤害。

- AI：困难模式会把谢尔顿·斯卡格斯放在真正能分散单位并获得增益的排。经典模式在有好招时不会再因计算未完成而放弃跟牌。

- AI会在对手放弃出牌后继续计算当前回合结束时触发的船只效果，并在排末放置卡牌时保留选定的排。

- 卡组计数器会标示金卡、银卡超限，以及卡组25至40张的上下限。

0.9.4 的存档可直接使用，存储格式没有变化。自动测试和两种编译器不能代替游戏内的确认。

## 0.9.4 更新内容

- Next-Gen 5.x 只保存模组为杰洛特添加的前 45 个字段，且该上限由所有已安装的模组共享。游戏事实只保存 16 位数值。Beta Gwent 使用的字段更多，因此与其他模组同时使用时，读档后卡组、酒桶和碎片可能消失。现在整个档案存放在由四个字段组成的单一存储中，事实中的备份也拆分为可容纳于 16 位的部分写入。

- 恢复流程也得到加强：首次修改前先读取档案；损坏的原始数据和隔离的卡组会保留用于恢复，未知的未来格式则设为只读。格式 2 可读取格式 1，并在接受记录前同时验证数值数据以及文本的长度和完整性。若数据既不在存档中，也不在可用备份中，则无法恢复。

- 现有存档会在首次读取时自动迁移。

- 锦标赛后修正了 AI 在短局中涉及间谍的一项决策。开发样本为 368 场、50%、零错误。尚未运行留出的测试样本，整体实力提升尚未得到证实。困难模式仍受玩家可见信息的限制；经典模式可访问更多隐藏信息。

适用于 Next-Gen 5.0+ 和 Classic 1.32。在 1.32 上，旧字段仍会与新存储一同保存。使用 0.9.4 保存后，不支持退回 0.9.3。自动测试和原生编译不能代替在游戏中进行“保存、退出、读取”的确认。
