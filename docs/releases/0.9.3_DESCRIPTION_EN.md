# Gwent Beta Classic 0.9.3

Standalone Gwent Beta inside The Witcher 3: 479 collectible cards, 21 leaders, five factions, 13 text languages and five voice languages.

Version 0.9.3 adds Classic: a separate opponent using ported original Beta AI logic, with access to your actual hand and remaining deck. Ready opponents use original profiles selected for their deck composition and leader. Select it beside the language controls before starting a match. The previous three difficulties remain available.

Ordinary opponents now draw from 76 compositions, including 30 original Beta decks under their source names. Thirty-three quest characters receive thematic decks. Collection, eight custom deck slots, BG1 sharing, rewards, kegs, accepted effects and controller support are preserved.

Choose the Classic 1.32 or Next-Gen 5.0+ archive. Classic requires both included DLC folders. The optional modBetaGwentMenuMusic adds the original Beta menu theme to the deck builder. Preserve other mods and refresh affected Script Merger merges if needed. Installation and publication are not automatic.

See the 0.9.3 changelog for changes and verification limits. Acceptance in the installed game remains a separate step.
