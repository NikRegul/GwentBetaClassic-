# Gwent Beta Classic 0.9.0 — Built-in cleanup before uninstalling

Cleanup is included in the main 0.9.0 mod. No separate cleaner download is needed. Back up your save, finish Gwent, leave combat and close all menus. With the main mod still installed, bg_clean_preview() shows instructions without changing data. Explicitly confirm with:

```text
bg_clean_confirm('DELETE_BETA_GWENT')
```

This clears the Beta collection, decks, scraps, kegs, settings, known reward ledgers, both backup banks and betagwent_* items in the player's current inventory. A saved uninstall flag prevents starter grants and backup restoration, including after reloading with the mod still installed. Save to a NEW slot, exit the game, remove this mod's folders (including its Classic DLC), rebuild affected Script Merger merges, load the new slot and save again. To cancel, load your original backup. When uninstalling, also delete the Optional-CopyButton files if you installed them: bin\…\plugins\GwentBetaClipboard.asi and the dinput8.dll from this mod (not another mod's).

If some Beta item stacks cannot be removed, the game shows "Beta Gwent cleanup is INCOMPLETE" with their number instead of the success message. Do not uninstall yet: drop or sell those items and run bg_clean_confirm('DELETE_BETA_GWENT') again until the success message appears.

Completed quests, achievements and spent crowns are not rolled back. The command does not traverse unloaded merchants, stash or world containers; retrieve Beta items first. Orphaned reward facts can require the included read-only save_fact_index.py and bg_clean_keys('…') after confirmation. See BetaGwentDocs/CLEANUP_EN.md. This is profile cleanup, not a certification that every historical byte of an arbitrary save has been erased.
