# Beta Gwent 0.8.2 — отдельный очиститель профиля

Временный мод удаляет коллекцию Beta Gwent, пользовательские и стартовые колоды, осколки, бочки, настройки, ротацию соперников, незавершённый выбор бочки, отметки новых карт, известные наградные записи и оба банка резервных фактов. Очищаются 38 сохранённых полей игрока. Физические предметы с именами `betagwent_…` удаляются из текущего инвентаря игрока. Повторная очистка допустима. При установке или загрузке ничего автоматически не удаляется.

Очиститель не переигрывает историю прохождения: завершённые квесты, достижения, полученные награды и потраченные кроны сохраняются. Штатные факты гвинта и предметы Redux не удаляются. Если вы собираетесь продолжать Redux, верните его определения перед загрузкой своего сохранения.

## Подготовка

1. Сделайте отдельную копию нужного сохранения и оставьте её вне папки, которую можете перезаписать. Проверяйте этот инструмент на копии. В обычном моде 0.8.2 очистка не запускается.
2. Закончите партию/открытие бочки, выйдите из боя, закройте меню, сохранитесь в отдельный слот и полностью закройте игру.
3. Уберите основную папку Beta Gwent из `Mods`: `modBetaGwentClassic132` для 1.32 или `modBetaGwent0924` для Next-Gen. Не ставьте два набора скриптов одновременно. Уберите старую объединённую версию скриптов через Script Merger и объедините остальные моды заново при необходимости.
4. Установите обе папки из подходящего архива очистителя: `modBetaGwentCleaner082` и `modBetaGwentCleanerItems082` в `Mods`. Вторая содержит только инертные определения предметов: они нужны, чтобы загрузка оставшихся предметов мода/Redux не происходила с неизвестными именами. Меню, коллекцию и торговлю она не включает. DLC основной Classic-сборки на этапе очистки можно убрать; очиститель не использует его графику.
5. Консоль игры должна быть включена заранее. Загрузите подготовленный слот, вне боя и меню.

## Команды и сохранение результата

`bg_clean_preview()` выводит справку и ничего не меняет.

Для удаления прогресса введите:

```text
bg_clean_confirm('DELETE_BETA_GWENT')
```

Команда с любой другой строкой не выполняет очистку. После сообщения об окончании сохраните игру В НОВЫЙ СЛОТ, полностью выйдите из неё, уберите `modBetaGwentCleaner082`, обновите объединения Script Merger, загрузите новый слот и ещё раз штатно сохраните игру. Этот второй проход без игровых скриптов мода позволяет движку записать сохранение без его добавленных полей, включая поля NPC, которые очиститель не объявляет.

Не открывайте исходное сохранение после удаления очистителя, ожидая, что оно тоже очищено: изменения относятся только к новому сохранённому слоту. Возврат основного мода после очистки создаст новую коллекцию, а не вернёт прежнюю из известных зеркал.

## Старые наградные факты, которых уже нет в текущем профиле

Движок даёт удалить факт по точному имени, но не предоставляет скрипту список всех имён. У профиля, который уже восстанавливался из зеркала, могут остаться отдельные `bg_bkn_<id>` от прежних NPC. Очиститель удаляет известные ID до сброса массивов; для остальных приложен дополнительный сканер.

Сканер требует Python 3 и работает только на чтение. Он распаковывает поддерживаемый PC-контейнер SNFH/FZLC в памяти, ищет имена в пространстве мода и пишет отдельный список команд. Сам `.sav` не редактирует, не перепаковывает и не отправляет в сеть. Сначала сканируйте копию исходного сохранения, соответствующую загруженному слоту:

```text
python save_fact_index.py "D:\SaveBackup\ManualSave.sav" --out "D:\SaveBackup\beta-clean-commands.txt"
```

Выполните полученные строки `bg_clean_keys('…')` с установленным очистителем после основной команды и до сохранения нового слота. Обработчик принимает только проверенные имена настроек 0.8.2 и собственные префиксы резервных банков/наград; произвольные факты других модов с общим началом `bg_` или `betagwent_` отвергаются. Не переносите команды из чужого сохранения. Неверный/неподдерживаемый контейнер вызывает отказ; сканер не пытается починить файл. В `.txt.json` записывается SHA-256 прочитанного сохранения и найденные имена. Повторный запуск используйте с новым именем выходного файла.

Поддержка чтения контейнера сверена с [описанием исходного читателя W3SavegameEditor](https://github.com/Atvaark/W3SavegameEditor/tree/master/W3SavegameEditor.Core/ChunkedLz4); реализация сканера самостоятельная, сторонние библиотеки не нужны. Поиск строк даёт кандидаты имён, а не доказательство удаления всех исторических объектов сохранения.

## Границы очистки и пакет определений предметов

Этот выпуск проверяет очистку данных профиля 0.8.2. Он **не сертифицирован как физическое удаление каждой записи мода из произвольного сохранения**. Предметы в тайнике, выгруженных торговцах и контейнерах мира команда текущего инвентаря игрока не обходит. Сначала заберите такие предметы в инвентарь игрока и очистите их; нельзя обещать, что неизвестные старые записи мира удалены. Не удаляйте `modBetaGwentCleanerItems082`, пока такие предметы или старые предметы Redux ещё нуждаются в его определениях. Сам этот пакет не добавляет новых сохраняемых полей и не восстанавливает прогресс.

Полное удаление пакета определений допустимо после проверки отсутствия соответствующих предметов либо при возвращении исходного поставщика их определений. Если нужен гарантированный разбор всех объектов конкретного `.sav`, потребуется отдельная проверка этого сохранения; текущий сканер не заменяет её. Все исходные сохранения остаются резервными копиями, автоматически они не изменяются.

## Что проверено

Оба варианта компилируются нативными компиляторами соответствующей игры. Тесты исполняют код очистителя на изолированном профиле: подтверждение, оба зеркальных банка, старый формат, награды, настройки, все 38 полей, фильтр предметов, сохранение штатных фактов, ограничение импортируемых имён и повторный вызов. Отдельно проверяется чтение LZ4 и отказ на повреждённых данных. Загрузка и повторное сохранение реального игрового `.sav` этим выпуском ещё не подтверждены.
