# Исправление 0.9.3b

Исправлен перенос заблокированного Ярпена Зигрина в следующий раунд. Блокировка снимает текущую «Стойкость», а разблокировка не возвращает её автоматически. Исправление общее для всех стойких отрядов и обеих сторон; новая «Стойкость», отдельно наложенная после блокировки, работает.

Выбор сложности теперь виден в шапке экрана колоды и редактора: панель состава больше не закрывает кнопку.

Сохранено всё содержимое 0.9.3a. Готовые старые архивы и текущий турнир не меняются. Для игры выберите полный архив своей платформы и следуйте приложенному руководству. Автоматическая установка и публикация не выполнялись.
