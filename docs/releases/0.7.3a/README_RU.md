# Gwent Beta Classic 0.7.3a

Для The Witcher 3 PC Next-Gen 5.01. Пять полных пакетов озвучки: RU, EN, DE, IT, PT-BR. Каждый содержит 13 переключаемых языков текста. REDkit и Wwise для игры не нужны.

0.7.3a исправляет оценку Владыки Ундвика и многодействийной погони ИИ, распределяет поисковые расчёты между кадрами и восстанавливает эффект и оригинальный звук выкладки золотых отрядов. Сохраняет текущие возможности 0.7.3: 479 коллекционных карт, 21 лидер, пять фракций, 46 архетипов, коллекцию, создание карт, бочки и сохранённые колоды.

## Установка

1. Закройте игру и сохраните резервную копию сейвов.
2. Удалите прежнюю папку `Mods/modBetaGwent0924`.
3. Распакуйте `Mods` из выбранного архива в каталог игры. Итоговый путь: `Mods/modBetaGwent0924/content`.
4. Устанавливайте только один полный голосовой пакет. Устаревший `modBetaGwentReduxCompat` удалите, если он оставался от старой версии.

Язык текста меняется в меню мода независимо от озвучки. Для смены голосов установите другой пакет. Голос тролля в DE/IT сохраняет русский резервный вариант.

Мышь: удерживайте ПКМ во время показа действий для временного ускорения. Контроллер: A ускоряет, повторное A пропускает; LB/RB переключают вкладки настроек. Подробности — `CONTROLS_RU.md`, изменения и игровые проверки — `UPDATE.md`.

Новые эффекты, звук и плавность передачи хода требуют проверки в обычной игре. Полное исчезновение микрофризов до такой проверки не подтверждено. Другие моды гвинта, меню и торговли могут конфликтовать. При сообщении об ошибке приложите журнал, карты, последовательность действий и настройки темпа/эффектов.
