# Gwent Beta Classic 0.7.3a

For The Witcher 3 PC Next-Gen 5.01. Five complete voice packages: RU, EN, DE, IT and PT-BR. Every package includes 13 selectable text languages. REDkit and Wwise are not required to play.

0.7.3a fixes Lord of Undvik target valuation and optional-round chase budgeting, spreads AI search over UI frames, and restores the gold unit landing effect and original sound. It retains the current 0.7.3 features: 479 collectible cards, 21 leaders, five factions, 46 AI archetypes, collection, crafting, kegs and saved decks.

## Installation

1. Close the game and back up your saves.
2. Remove the previous `Mods/modBetaGwent0924` folder.
3. Extract `Mods` from your chosen package into the game directory. The resulting path is `Mods/modBetaGwent0924/content`.
4. Install only one complete voice package. Remove the obsolete `modBetaGwentReduxCompat` if present.

Text language is independent of voices and can be changed in the mod menu. Install another package to change voices. DE/IT retain the Russian keg-troll fallback.

Hold RMB during replay for temporary acceleration. Controller A accelerates; a second A skips. LB/RB switch settings tabs. See `CONTROLS_EN.md` for controls and `UPDATE.md` for changes and game checks.

The new effects, audio and AI turn smoothness still need an in-game check. Complete elimination of hitches has not been confirmed. Other Gwent, menu or merchant mods may conflict. For a bug, include the log, cards, action sequence, presentation speed and effect settings.
