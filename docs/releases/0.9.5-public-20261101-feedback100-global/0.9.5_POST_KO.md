# Gwent Beta Classic 0.9.5

- 덱 편집기: 지도자 아래 설명과 카드 목록 앞 빈 공간을 없앴습니다. 카운터와 배경을 목록에 맞추고 깃발을 포함한 미리보기를 오른쪽 홈 안에 배치했습니다. 일반 상대 이름의 중복을 없애고 실제 이름은 유지했습니다.

- 어려움: 패스에 필요했던 고정 26점 차 기준을 없앴습니다. 양보할 수 있는 라운드가 진행되면 공개 정보의 대응 템포, 손패 수 차이, 한 장 더 내는 비용을 고려해 마지막 카드들을 보존합니다.

- AI는 실제 전장 정리로 다음 라운드의 시작 전장을 예측합니다. 회복력, 모크바그의 귀환, 약화와 봉쇄가 반영됩니다. 아무 카드 없이 패스하면 뒤처지는 경우 손패를 보존하고 선공을 넘길 수 있으며 자원이 충분하면 압박할 수 있습니다. 숨겨진 카드나 미래의 드로우는 읽지 않습니다.

- 0.9.5 재빌드: Olaf의 야수 기록, Xavier Moran의 카드 원형 전력 보너스, Ciri: Dash의 회복력, Morkvarg가 복귀 전에 무덤에서 약화되는 순서를 수정했습니다. 미리보기 카드 크기와 카운터 여백을 조정하고 25장 도달 시 원래 효과를 추가했습니다.

- 베타 규칙 추가 수정: Cursed Knight는 다른 동일 카드의 상태를 완전히 초기화하고, Hubert Rejk는 덱 카드의 증폭만 흡수하며 손상된 카드를 치유하지 않습니다. 비활성 구역에서 현재 및 기본 전력이 모두 0이면 유언 없이 추방됩니다. 무덤에서 0이 된 Morkvarg에도 적용됩니다.

- Olgierd는 파괴된 경우에만 턴 종료 시 돌아옵니다. 손에서 버리는 것으로는 발동하지 않으며 무덤을 떠나면 파괴 표시가 해제됩니다.

- 511장 모두의 주요 분기를 독립 검증했으며 모든 능력 조합의 증명은 아직 남아 있습니다. 선택 생략, 섞기, 카드 순서, Francesca, Lugos, Agitator, False Ciri, Wolfsbane를 수정했습니다. 보류된 9항목도 처리하여 Bloody Flail은 대상 없이도 생성하고, False Ciri는 열 위치를 유지하며, Emhyr는 턴 종료 시 반환하고, Monster Nest는 배치 전에 증폭합니다. Dimun의 난수와 Ge’els의 반환 순서를 수정하고 Yennefer의 빈 대기를 제거했습니다. 템플릿 순서와 Shupe 두 형태의 5가지 모드를 모든 제시 위치에서 검증했습니다. 15 피해는 양쪽 진영을 대상으로 할 수 있습니다.

- 베타 스타일 덱 및 수집품 메뉴: 진영과 덱 이름 머리글, 6열 카드, 사각 필터와 검색, 오른쪽 제작 패널. 덱 행과 장수 애니메이션, 컨트롤러 버튼 안내, 동전의 패스 길게 누르기 표시를 추가했습니다.

- 카드 선택과 교체, 카드 및 조각 보상을 표시하는 결과 화면, 기록, 대전 메뉴, 덱 및 무덤 보기, 가져오기 및 확인 창을 업데이트했습니다. 별도 키워드 설명, 정렬된 컨트롤러 안내, 창 효과음을 포함합니다. 기능 중심 이식이며 정확한 외형, 원본 애니메이션 및 게임 내 검증은 아직 완료되지 않았습니다.

- 능력의 첫 효과가 적용되기 전에는 우클릭, Esc 또는 게임패드 뒤로로 대상 선택을 취소할 수 있습니다. 아라카스 여왕은 첫 섭취 전에 지도자 칸으로 돌아갑니다. 다른 카드로 낸 유닛은 부모 카드를 되돌리지 않고 배치 선택으로 돌아갑니다. 덱/무덤 카드 선택은 취소할 수 없습니다. 아틀라스 테두리와 연속 스크롤을 수정했습니다. 보상과 진행도는 중립을 포함해 받은 카드의 진영을 표시합니다. AI 날씨 예측은 방어력을 한 번만 소모하고 더 약한 이웃의 죽음을 고려합니다.

- 왕관 색상 노이즈, 양피지 이음새, 마우스/컨트롤러 전환 시 버튼 글자 정렬을 수정했습니다. 설명의 휠 안내를 제거하고 방어구 파괴음을 복원했습니다. 사절은 선택 가능한 카드가 있으면 반드시 내야 합니다. 대상 확정 전에는 로취와 다른 반응이 발동하지 않습니다. 하랄드는 열 전체 피해와 상대 패스 후 서리를 계산하며, 손패가 없고 포기 가능한 라운드에서 여전히 이길 수 없으면 지도자를 보존합니다.

- 엘프 용병, 정찰, 카드 생성 등 카드를 내도록 하는 선택에서는 사용 가능한 카드를 반드시 선택합니다. 선택 생략 기본값이 이를 덮어쓰던 문제를 수정했습니다. 속도와 효과 상세 설정은 저장된 프로필에서 복원되고 별도 명령으로 갱신되어 메뉴에 즉시 반영됩니다. 왕관과 버튼 가운데 정렬 수정도 같은 압축 파일에 포함됩니다. 공통 프로필 초기화는 난이도, AI 대기, 선택 덱, 수집품, 조각, 미완료 술통에도 적용됩니다. 알 수 없는 형식을 포함해 읽기가 저장 데이터를 덮어쓰지 않습니다.

0.9.4/0.9.4a 저장 형식은 그대로입니다. 전반적인 강도 향상을 주장하지 않습니다. 자동 검증은 Classic 1.32와 Next-Gen 5.0+의 게임 내 확인을 대신하지 않습니다.
