## Разработка и история

[testing.md](testing.md) описывает первоначальные исследования и behavioral oracle; для игровой приёмки 0.6.2 используйте актуальный чек-лист выше. Документы отдельных этапов, старые планы, отчёты в reviews и evidence сохранены для воспроизводимости. Их формулировка «текущий этап» относится к моменту записи.

Сборка проверяет замороженные исходники и фактические архивы. Успешная компиляция, CRC и source checks не заменяют проверку игры, контроллера и сохранений пользователем. Отчёты очередной сборки могут обновляться во время её выполнения; готовность оценивается по завершённому запуску.
