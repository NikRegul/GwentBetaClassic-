# Документация Gwent Beta Classic

Готова **тестовая RU 0.6.6 / Stage 142**: [архив](../BetaGwent/release/GwentBetaClassic-0.6.6-RU.zip), [состав и игровые проверки](PRESENTATION142_RU.md), [каталог эффектов](SPECIAL_VFX_0.6.6_RU.md), [сборка](BUILD_0.6.6_RU.md). Специальные эффекты, общая погода, одновременные усиления, вступления лидеров и стабильный правый портрет, история и подсказки целей, бочки у всех корчмарей, объединённые исправления ИИ. 50 наборов регрессий, нативная компиляция 70 скриптов и четырёх меню, проверка пакета пройдены; отчёт — `evidence/validation142.json`. Старые архивы 0.6.3–0.6.5 сохранены. Остальные голосовые архивы пока на 0.6.3. Приёмка нового поведения в обычной игре ещё требуется.

Предыдущая полная линия: **0.6.3 / Stage 139**. Поддерживаемая цель — The Witcher 3 PC Next-Gen 5.01. Пять голосовых пакетов, каждый с прежними 13 языками текста. Пройдены 39 наборов регрессий, нативная компиляция и проверка всех пяти архивов по ZIP/manifest/SHA-256 и исходникам; отчёт — `evidence/validation139.json`. Парное сравнение ИИ: 184 партии, 92:92, без ошибок и без подтверждённого общего преимущества. Пользователь проверил 0.6.2 без замеченных проблем; визуальные изменения 0.6.3 требуют игровой проверки.

## Разработка и история

[testing.md](testing.md) описывает первоначальные исследования и behavioral oracle; для игровой приёмки 0.6.3 используйте актуальные сценарии выше. Документы отдельных этапов, старые планы, отчёты в reviews и evidence сохранены для воспроизводимости. Их формулировка «текущий этап» относится к моменту записи.

Сборка проверяет замороженные исходники и фактические архивы. Успешная компиляция, CRC и source checks не заменяют проверку игры, контроллера и сохранений пользователем. Отчёты очередной сборки могут обновляться во время её выполнения; готовность оценивается по завершённому запуску.
