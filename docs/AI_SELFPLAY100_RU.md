# Самообучение ИИ Gwent Beta Classic

> **Устарело для 0.3.0.** Актуальная инструкция: [AI_TRAINING_RU.md](AI_TRAINING_RU.md).


Рабочая папка проекта: `D:\w3mod`. Обучение выполняется вне игры: два ИИ играют
по перенесённому полному ядру правил мода. Все **40 активных архетипов** берутся
из того же каталога, который используется для колод обычных NPC (пресеты 54–93).
Игра, REDkit и Wwise во время обучения не нужны. На этой машине уже доступны
Python и .NET SDK 7. Для пересборки игрового пакета нужен установленный REDkit.

## Запустить на ночь

Открой PowerShell и вставь **одну команду**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\w3mod\tools\ai\Train-AI.ps1" -Generations 1000 -Output "D:\w3mod\BetaGwent\training\night01"
```

Оставь окно открытым. Экран можно выключить, но компьютер не должен уходить
в сон или гибернацию. Здесь используется CPU; мощная видеокарта не требуется.
Время зависит от компьютера и числа дополнительных проверок. 1000 поколений —
заданный объём работы, а не таймер на восемь часов. Можно поставить 300 или 2000.
Для следующей независимой ночи используй другую папку, например `night02`.

**Не запускай два обучения одновременно и не меняй правила/колоды или исходники
ИИ во время обучения.** Симулятор имеет общую папку сборки. Игра использует
установленный пакет и сама себя не обучает.

Более длинный вариант проверки каждого кандидата:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\w3mod\tools\ai\Train-AI.ps1" -Generations 1000 -Cycles 2 -Output "D:\w3mod\BetaGwent\training\night02"
```

`Cycles 2` примерно удваивает количество партий каждого этапа. Для первой ночи
достаточно обычной команды с `Cycles 1` по умолчанию.

## Остановить и продолжить

Прогресс и экспорт лучшего принятого кандидата сохраняются **после каждого
поколения**. Чтобы закончить после текущего поколения, в другом окне PowerShell:

```powershell
New-Item -ItemType File -Path "D:\w3mod\BetaGwent\training\night01\STOP" -Force
```

Для продолжения удали этот файл и запусти с `-Resume`:

```powershell
Remove-Item -LiteralPath "D:\w3mod\BetaGwent\training\night01\STOP" -ErrorAction SilentlyContinue
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\w3mod\tools\ai\Train-AI.ps1" -Generations 1000 -Resume -Output "D:\w3mod\BetaGwent\training\night01"
```

Это ещё 1000 поколений **с места остановки**. При продолжении сохраняй прежние
`Seed` и `Cycles`. Если остановить через Ctrl+C, незавершённое поколение будет
повторено; предыдущий checkpoint остаётся. При изменении исходников правил или
тренировщика нужен новый запуск в другой папке: несовместимые checkpoints
не смешиваются. Запуск без `Resume` в папку с checkpoint намеренно запрещён.

## Что читать утром

В папке `D:\w3mod\BetaGwent\training\night01`:

- `checkpoint.json`: номер завершённого поколения, чемпион и история принятых улучшений.
- `export\report.json`: `hasLearnedPolicy`, принятые кандидаты и результаты отбора.
- `export\duelAITraining.ws`: готовая таблица весов для WitcherScript.
- `g00000-summary.json` и следующие: результаты отдельного поколения.
- `*.jsonl`: результаты партий; `*.batch.json`: составы и seed для воспроизведения.
- `source-manifest.json`: точные исходники, по которым проводилось обучение.

`accepted=True` в консоли означает прохождение предварительного отбора и
проверки на других раздачах. `hasLearnedPolicy=false` означает, что улучшение
не доказано даже этим предварительным отбором; в экспорте остаются нейтральные
веса. В таком случае импорт сохраняет текущий игровой ИИ. Число сыгранных
партий само по себе не доказывает, что ИИ стал сильнее.

## Перенести результат и пересобрать RU

Когда обучение остановлено, закрой игровую сессию REDkit. Для импорта и полной
сборки русской версии:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\w3mod\tools\ai\Rebuild-AI.ps1" -TrainingFolder "D:\w3mod\BetaGwent\training\night01" -Stage 102 -Version "0.2.7-ai.1"
```

Скрипт проверяет совпадение правил и экспорт с принятым checkpoint, сохраняет
копию предыдущего файла, обновляет исходник, компилирует WitcherScript и три
меню, затем собирает ZIP. Он не устанавливает мод в Steam и не публикует его.

Результат:
`D:\w3mod\BetaGwent\release\GwentBetaClassic-0.2.7-ai.1-RU.zip`.

Если stage 102 уже существует, выбери **новый** `-Stage 103` и новую версию
`-Version "0.2.7-ai.2"`. Существующие замороженные сборки не перезаписываются.
Лицензия REDkit ранее принята тобой; Wwise повторно запускать не требуется.

Только импорт без сборки:

```powershell
python -X utf8 "D:\w3mod\tools\ai\import_policy.py" "D:\w3mod\BetaGwent\training\night01"
```

При ручном переносе заменяется **один** исходник:

```text
ОТКУДА: D:\w3mod\BetaGwent\training\night01\export\duelAITraining.ws
КУДА:   D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelAITraining.ws
```

Рекомендуется проверяемый импорт выше: копирование некомпилированного `.ws`
прямо в установленную игру не заменяет сборку. Резервные копии импортера:
`D:\w3mod\BetaGwent\training\backups\<дата-время>\duelAITraining.ws`.
Перед установкой кандидата **сохрани резервную копию сейвов**.

## Что именно обучается

Это эволюционный подбор ограниченных весов оценки хода, а не обучение нейросети.
Существующие правила архетипов служат исходной стратегией. Изменяются 16
признаков: немедленный темп, будущая ценность, сохранение сильных карт, связки,
ранние золото/серебро, лидер, погода, прореживание, шпионы, движки и таймеры.
Поколения чередуют общие веса и веса одного архетипа. Архетип дополнительно
играет против восьми других колод; общий пул из 40 остаётся в каждой проверке.

Кандидат сравнивается с прежним чемпионом на одинаковых раздачах и с обменом
местами. Улучшение проверяется на независимых seed, включая старый ИИ.
Партии с ошибками не засчитываются как победы и блокируют принятие кандидата.
Отбор пока предварительный: поле `strongEvidence` отдельно показывает, есть ли
достаточно статистики среди партий с изменившимся результатом. Публикации
кандидата должна предшествовать проверка в настоящей игре.

Обучаемая прибавка не считается реально набранными очками и **отключается
после паса противника**. Существующий расчёт фактического темпа, включая бонус
Импера за шпионов, продолжает определять возможность догнать одной картой.
Кандидат не может обойти проверки полезности лидера, легальности целей и
существующие ограничения паса. Новые признаки не читают скрытую руку врага.
Таргетинг способностей, мулиган и базовые правила паса выполняются текущим
кодом; их отдельная оптимизация — следующий этап.

Симулятор переводит реальные core/duel `.ws` в C#, сохраняя семантику массивов
и меняя перспективу двух ботов. Это большая часть игровой логики, но совпадение
с REDkit на всех картах ещё не подтверждено; обучение не заменяет нативные проверки.

## Где менять ИИ руками

- `D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelArchetypeAI.ws`: приоритеты связок, резервы, мулиган и условия архетипов.
- `D:\w3mod\data\beta924\ai\rules.json`: сгенерированный каталог всех 40 профилей; составы меняются через `D:\w3mod\deck_rules` и генераторы `build_ai_rules.py` → `build_duel_catalog.py`.
- `D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelAITraining.ws`: признаки и экспортируемые веса.
- `D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelSession.ws`: выбор хода, лидера, пас и фактический темп.
- `D:\w3mod\tools\ai\train.py`: мутации, расписание партий и условия отбора.
- `D:\w3mod\tools\ai\host\SelfPlay.cs`: адаптер двух ботов и обмен перспективой.
- `D:\w3mod\tools\ai\build_simulator.py`: перевод правил в headless-сборку.

Не редактируй автоматически созданный `BetaGwent\build\ai-selfplay\Rules.cs`:
следующая сборка восстановит его из `.ws`.
