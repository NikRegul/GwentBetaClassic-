## Обязательный пункт перед сборкой пакетов 0.8

По просьбе пользователя от 15 октября 2026: до фиксации исходников и сборки пакетов 0.8 для 5.0+ и 1.32 реализовать, документировать и проверить консольные команды получения ресурсов и диагностики магазина. Ниже — целевой интерфейс; кроме уже существующей bg_allcards команды пока считаются запланированными.

| Команда | Назначение |
|---|---|
| `bg_kegs(10)` | Добавить 10 неоткрытых бочек в сохранённый счётчик мода. |
| `bg_card(132102, 1)` | Добавить карту по ID и количеству; пример — один Имлерих. Соблюдать лимит копий. |
| `bg_find('Имлерих')` | Найти карты по части названия и вывести название и ID. |
| `bg_scraps(1000)` | Добавить 1000 обрывков для создания карт. |
| `bg_faction('monsters')` | Заполнить коллекцию выбранной фракции до допустимого количества копий; перечислить поддерживаемые значения в справке. |
| `bg_leaders()` | Выдать всех недостающих лидеров. |
| `bg_allcards` | Сохранить существующую выдачу всей коллекции и лидеров до лимита копий. |
| `bg_status()` | Показать коллекцию, неоткрытые бочки, обрывки, незавершённый выбор бочки и режим НГ+. |
| `bg_help()` | Вывести доступные команды, параметры и примеры. |
| `bg_shopcheck()` | В открытом магазине проверить режим НГ+, доступность определения бочки, фактический запас и флаги выдачи; вывести результат диагностики. |
| `bg_shoprefill(5)` | В открытом магазине довести запас бочек текущего продавца до пяти; повторный вызов не должен увеличивать его сверх указанной цели. |

Требования: выдача бочек идёт через счётчик мода, а не предмет в инвентаре Геральта. Команды проверяют параметры, существование карт и контекст вызова, показывают фактически выданное количество и итоговый баланс либо понятную причину отказа. Изменения включаются в механизм резервирования профиля и сохраняются после штатного сохранения/загрузки. Диагностика магазина должна подтверждать наличие предмета, а не только выполнение скрипта; конкретный способ проверки доступности определения выбрать при реализации.

Условия закрытия пункта: команды включены в обе платформенные версии; проверены неверные параметры, лимиты карт, повторная выдача, отказ создания предмета и повторное открытие магазина. В игре на 5.0+ и 1.32 проверить выдачу ресурсов и сохранение/загрузку, а для магазина — обычное прохождение и НГ+: корчмарь → диагностика → пополнение/покупка → повторное открытие → сохранение/загрузка. Зафиксировать результаты и добавить справку к пакетам. Успешная выдача через bg_kegs не заменяет проверку настоящей покупки у корчмаря.

Этот пункт не запускает сборку 0.8: запуск самих сборок 0.8.0 остаётся отдельным действием; сейчас запрошена подготовка скриптов.

## Игровая приёмка и дальнейшая работа

Stable означает отсутствие известных падений, зависаний, потери профиля и блокировки поддерживаемого игрового цикла. На обеих платформах требуется проверить NPC → колоды → муллиган → партия → результат → возврат; повторную партию и сохранение/перезапуск; покупки и бочки, включая НГ+; ввод имени колоды, управление и звук. Компиляция, CRC и SHA-256 не заменяют запуск в игре. До приёмки пакет обозначается кандидатом.

От 0.8 к 1.0: улучшать ИИ, переводы, исправлять баги и другие проблемы стабильности. Проверять ИИ на одинаковых seed и зеркальных сторонах, контролировать время решения и доступную информацию. Переводы вычитывать и проверять в реальном интерфейсе. Изменения сопровождать проверками по затронутой области.
