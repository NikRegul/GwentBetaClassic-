# Gwent Beta Classic 0.4.0

Перед установкой сохраните резервную копию сохранений. Устанавливайте только один языковой пакет. Удалите предыдущую папку `Mods/modBetaGwent0924` и скопируйте новую папку Mods в каталог игры.

## Изменения

- Игровой ИИ пишет связанные записи `AI_REASON`: контекст решения, оценки рассматриваемых карт, выбор карты или лидера, причины паса, сравнение рядов и целей. Симуляции возможных ходов не засоряют игровой лог.
- Добавлены воспроизводимые проверки 46 архетипов: безопасный ряд, соседство с усилителем, экономия карты при недостижимом догоне, полное разрешение хода и неизменность исходного состояния при расчёте. Для подходящих составов проверяются призывы, подготовка сброса и сохранение движков. Общие проверки дополняют прежние проверки конкретных связок; это не доказательство идеальной игры всех составов.
- Сравнение двух замороженных версий ИИ использует одинаковые составы, исходную раздачу и состояние генератора случайных чисел. Каждая версия играет обе колоды в обоих местах. Мулиган каждая версия выбирает самостоятельно. Статистика сохраняется отдельно по всем 46 архетипам.
- Стенд сравнения теперь использует настоящие экспортированные веса обучения из `duelAITraining.ws`, если не задана внешняя политика. Ранее этот путь стенда возвращал нулевые веса. Игровой ИИ уже использовал файл весов.
- Темп 1×, 1,5× или 2× и сокращённые эффекты сохраняются в профиле игрока. В сокращённом режиме остаются указание источника, цели и изменение значений; показ действия длится минимум 320 мс.
- До выбора подсвечиваются известные цели и область действия поддерживаемых способностей, выбранные погодные ряды и число оставшихся выборов. Предпросмотр постановки показывает место вставки. Скрытые карты, случайные цели и результат случайного добора не раскрываются.

## Сборка самостоятельно

Рабочий каталог: `D:\w3mod`. Требуются настроенные REDkit, Python, Node.js и локальные зависимости проекта. Игрокам эти инструменты не нужны.

```powershell
powershell -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-0.4.0.ps1 -Language both -CheckAI
```

Скрипт `D:\w3mod\tools\Build-0.4.0.ps1` вызывает редактируемый `D:\w3mod\tools\Build-GwentBeta.ps1`. Шаги: генерация каталогов и профилей, проверки, экспорт четырёх меню, проверка связей, компиляция WitcherScript, cooking, строки и звук, упаковка и проверка ZIP. Результат — `D:\w3mod\BetaGwent\release`. Сборка не устанавливает мод в обычную игру. REDkit-проект после сборки возвращается к русским меню.

Можно запускать отдельные шаги `-Step prepare`, `scripts`, `menus`, `package`. После изменений исходников сначала пересоберите соответствующие скрипты и меню, затем пакет. `-Compiled` допускается только для одного языка и должен указывать на свежую компиляцию. Прежний ZIP с тем же именем переносится в подпапку `old`.

## Сравнение ИИ, в том числе на ночь

```powershell
powershell -ExecutionPolicy Bypass -File D:\w3mod\tools\Compare-AI.ps1 -Cycles 20 -Seed 119
```

Один цикл — 184 партии: все 46 архетипов против следующего состава, четыре зеркальные партии на пару. С каждым циклом сдвиг соперника меняется; за 45 циклов каждый состав встречает все остальные. 20 циклов — 3680 партий. Время зависит от компьютера и сложности карт; остановить можно Ctrl+C. Уже завершённые партии сохраняются, сводка обновляется после каждой группы из четырёх партий. Для нового запуска нужна новая выходная папка.

По умолчанию кандидат замораживается из текущих исходников, база — `D:\w3mod\BetaGwent\training\stage118-check\snapshot`. Можно задать `-Baseline`, `-Candidate` и `-Output`. Для проверки одинакового запуска сохраняйте оба снимка и используйте те же Seed и Cycles. Эти проверки не изменяют обученную политику и не устанавливают её в игру.

В выходной папке:

- `REPORT.md`, `report.json`, `archetypes.csv` — общий результат и показатели каждого состава.
- `games.jsonl` — завершённые партии.
- `matches/*.json.gz` — исходное состояние, шаги и логи каждой партии.
- `errors/*.json.gz` — ошибочные партии с состоянием непосредственно перед ошибкой.

Повтор партии и читаемый разбор:

```powershell
node D:\w3mod\tools\ai\replay119.js D:\w3mod\BetaGwent\training\comparison119-acceptance2\matches\game-000001.json.gz
python -X utf8 D:\w3mod\tools\ai\explain_log119.py D:\w3mod\BetaGwent\training\comparison119-acceptance2\matches\game-000001.json.gz
```

Разбор также принимает текстовый лог игры или REDkit. Записи связываются номером решения; OPTION показывает tempo/utility/reserve/setup/evaluation, SELECT — выбранный ход, ROW — погоду и стоимость размещения, TARGET_OPTION/SELECT — цели, PASS — конкретное условие паса. Не каждый легальный ход просчитывается одинаково глубоко: подробный расчёт ограничен бюджетом ИИ.

Признак `confirmedBetter` требует полного прогона без ошибок, минимум 46 групп и нижней границы 99% нормального приближения выше 50%. Это ориентир стенда, а не гарантия превосходства против человека. Отдельно проверяйте партии в обычной игре и REDkit.

## Где редактировать ИИ

- `D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelSession.ws` — выбор карты, цели и ряда, точный расчёт, последовательности и логирование.
- `D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelArchetypeAI.ws` — оценка синергий, движков и целей для поглощения/сброса.
- `D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelAIPass.ws` — экономика раундов и пас.
- `D:\w3mod\data\beta924\ai\researched115.json` — составы и исследованные стратегии; изменения должны пройти генераторы сборки. Не правьте только генерируемые каталоги: генератор перезапишет их.
- `D:\w3mod\BetaGwent\development\scripts\game\betagwent\duelAITraining.ws` — экспортированные веса. После переноса результата обучения пересоберите скрипты, проверьте ИИ и соберите пакет.

Встроенные проверки выполняют реальные правила WitcherScript через стенд. Они не заменяют проверку FPS, расположения подсказок, сохранения настроек и управления контроллером в самой игре. Для багрепорта приложите версию, язык, игровой/REDkit лог, составы и описание последних действий.
