## Nexus

Загрузить оба ZIP как отдельные варианты одного обновления. Пользователь
устанавливает только один язык. Вставить соответствующие NEXUS_FIELDS_*.md
или полное NEXUS_DESCRIPTION_*.md. В описание и журнал обязательно оставить
предупреждение о резервной копии сохранений и известных ограничениях.
Если приёмка пройдёт, заменить только абзац о её ожидаемом статусе.

## Steam — ручной шаг

Штатная публикация REDkit требует подключённого Steam Workshop. В Publish →
Save and publish mod project указываются имя, версия, описание и обложка;
затем язык и видимость, действие Publish to Steam Workshop. Для двух языков
удобнее два элемента Workshop с явным предупреждением устанавливать один.
Текущий `workshopId` не назначен: предметы ещё не создавались.

Официальная инструкция: [Publishing mods](https://cdprojektred.atlassian.net/wiki/spaces/W3REDkit/pages/6328254/Publishing+mods).

**Не пересобирать этот пакет обычным Publish и не считать результат идентичным
ZIP автоматически.** Наш pack97 использует несжатый bundle с встроенными
текстурами; штатный мастер может собрать другой вариант. Готовые папки выше
предназначены для загрузки проверенного содержимого. Если используемый
публикатор требует повторную сборку, нужно сравнить итоговые файлы/метаданные
и сохранить параметр pack `-compression=None`; такую интеграцию с публикатором
мы ещё не проверяли. REDkit-проекты для воспроизведения находятся в
`D:\w3mod\BetaGwent\build\release97\ru\project\BetaGwent0924` и `...\en\project\BetaGwent0924`.
Обычный ZIP не является уже опубликованным элементом Workshop.
