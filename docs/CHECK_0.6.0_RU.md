# Проверка 0.6.0 в игре — 15 минут

Архивы: `BetaGwent\release\GwentBetaClassic-0.6.0-RU.zip` / `-EN.zip`.
Порядок — по важности: если времени мало, достаточно пунктов 1–3.

## 0. Подготовка (1 мин)
- Скопировать папку сохранений игры в безопасное место.
- Установить архив 0.6.0 поверх 0.5.4. В Steam оставить `--launcher-skip -net -debugscripts`,
  чтобы писался `Documents\The Witcher 3\scriptslog.txt`.

## 1. Сохранения (4 мин) — самое важное
1. Загрузить сейв, сделанный на 0.5.4. Открыть меню колод: коллекция, свои колоды,
   осколки и бочки на месте. ✔ / ✘
2. Сыграть и выиграть у обычного NPC (не квестового). Награда выдана.
3. Сохраниться, выйти в главное меню, загрузить этот сейв. Коллекция, колоды и
   счётчик наград не изменились. ✔ / ✘
4. В `scriptslog.txt` найти строку `PROFILE_BACKUP format=2`. Она есть. ✔ / ✘
5. *(если есть 10 минут)* Проверка сейва без мода: переименовать папку мода,
   загрузить сейв, сохраниться, вернуть мод, загрузить новый сейв.
   - Коллекция, колоды, настройки, недоигранная бочка восстановились; в логе
     `PROFILE_RESTORED format=2`. ✔ / ✘
   - Снова выиграть у того же NPC: если он уже отдал 4 карты, должны прийти
     только осколки, не карта. ✔ / ✘

## 2. Память и меню (3 мин)
Цель — убедиться, что меню 55,3 МиБ (новый предел упаковщика 56) не ломают загрузку.
1. Меню колод → бой с NPC → выход → меню колод. Повторить 3 раза.
   Интерфейс не исчезает, нет вечной загрузки. ✔ / ✘
2. Открыть бочки из редактора колод (бочки поверх редактора), закрыть,
   открыть бочку ещё раз. ✔ / ✘
3. Бой с NPC в городе (Новиград или Оксенфурт — там идёт подгрузка мира). ✔ / ✘

## 3. Анимированные лидеры (3 мин)
1. Посмотреть 4–5 лидеров разных фракций: на столе, в руке, в правом портрете.
2. Цикл без заметного шва (смотреть 10 секунд). ✔ / ✘
3. Быстро водить курсором по картам руки — нет зависаний и мигания. ✔ / ✘
4. Включить «Эффекты: кратко» — портреты становятся статичными. ✔ / ✘

## 4. Язык текста (2 мин)
1. Переключить «Текст RU / EN» в настройках. Меню, карты и описания сменили язык,
   озвучка осталась прежней. ✔ / ✘
2. Сохраниться, загрузиться — выбранный язык сохранился. ✔ / ✘
3. Поиск в редакторе работает на обоих языках; название своей колоды не
   переводится. ✔ / ✘

## 5. Если осталось время (2 мин)
- Вступление с лидерами: обе реплики звучат, пропуск работает.
- Обучение с контроллера: LB/RB листают страницы, фокус виден.

## Что прислать
- Номера пунктов с ✘ и скриншот.
- `scriptslog.txt` (сразу после проблемы, не перезапуская игру).
