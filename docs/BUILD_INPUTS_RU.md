# Постоянные входы сборки

Актуальная точка входа — `Build_0.9.2.cmd`. Все постоянные локальные зависимости перечислены в `tools/build_inputs.py`:

- `BetaGwent/build-inputs` — проверенные исходные скрипты, архивы основы, UI, принятые ресурсы, звуковые банки и материалы для их редактирования;
- `BetaGwent/toolchains/classic-runtime` — изолированный компилятор Classic 1.32;
- `BetaGwent/publication` — отдельный Git checkout для подготовки публикаций.

Эти каталоги не являются промежуточными результатами и не удаляются при очистке `BetaGwent/build`. Runtime содержит намеренные ссылки на ресурсы установленной игры: их нельзя обходить при рекурсивной очистке.

`python -X utf8 tools/recon/migrate_build_inputs.py --verify` сверяет все постоянные входы по SHA-256 с `BetaGwent/build-inputs/manifest.json`. Режимы копирования нужны только для первоначального переноса из исторических сборок; после их удаления используется проверка существующих входов.

Новая сборка с явно заданным выходом: `Build_0.9.2.cmd --out BetaGwent/build/my-candidate`. Выход должен быть новым каталогом. `--resume` применим только к тому же набору замороженных исходников и проверяющих инструментов. Успех сборки подтверждают `release.json`, оба архива и контрольные суммы; игровая проверка отмечается отдельно.

Пути к старым стадиям в исторических отчётах описывают прежние сборки. Они не являются перечнем зависимостей текущего конвейера. Проверенные снимки правил и отчёты тестов сохраняются отдельно от удаляемых распакованных проектов и повторных упаковок.
