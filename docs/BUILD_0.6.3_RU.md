# Сборка 0.6.3 / stage139

Рабочий вход для подготовленного окружения `D:\w3mod`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-0.6.3.ps1 -Language all
```

Проверка существующих архивов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-0.6.3.ps1 -Step verify -Language all
```

Режимы: `full`, `scripts`, `menus`, `package`, `verify`; языки пакета: `ru`, `en`, `de`, `it`, `pt-br`, `all`. По умолчанию собирается RU. Готовые архивы 0.6.3 не перезаписываются: для новой редакции исходников нужен новый номер версии. При существующих архивах используйте `verify`.

Входы ИИ заморожены в `BetaGwent/build/audit139/{baseline,candidate}`. Это подготовленные снимки рабочей папки, не внешние зависимости. `tools/check_work139.py` проверяет кандидата и интерфейс, сохраняя отчёты stage139 отдельно от принятой 0.6.2. Менять зафиксированные снимки во время проверки или сборки нельзя.

Скрипты пяти голосовых пакетов берутся из stage138 с единственной заменой `duelSession.ws`; соответствие разрешённому изменению проверяется. Каждый набор из 70 скриптов заново компилируется REDkit. Четыре меню пересобираются и проверяются по нативному ABC, привязкам, изображениям и CRC. Текстовые ресурсы, шрифты, портреты лидеров и звук используются из 0.6.2 без правок.

Пути результатов:

- Архивы: `BetaGwent/release/GwentBetaClassic-0.6.3-<язык>.zip` и `.zip.sha256`.
- Сборка: `BetaGwent/build/stage139`; упаковка: `BetaGwent/build/release139`.
- Логи: `BetaGwent/build/stage139/logs`.
- Входы: `docs/evidence/inputs139.json`; регрессии: `docs/evidence/regressions139.json`.
- Итог после успешной проверки: `docs/evidence/validation139.json`.
- Сравнение ИИ: `BetaGwent/build/audit139/compare/REPORT_RU.md`.

Проверка релиза сверяет свежесть исходников и меню, скомпилированные скрипты, ресурсы в bundle, CRC ZIP, полное покрытие manifest и SHA-256. Отдельно подтверждается неизменность прежних архивов 0.6.2. Мод не устанавливается в игру и не публикуется этим сценарием.

[Изменения и ручная приёмка](AI_ANIMATIONS_0.6.3_RU.md). Обнаруженные критические ошибки исправляются независимо от темы версии.
