# Gwent Beta Classic 0.7.0-vfx1

Первая тестовая сборка первого блока 0.7.0. Сохранены исправления полной 0.6.10.

- Привязки стихийных эффектов расширены с особых карт на отряды и лидеров: 259 шаблонов.
- Перенесены 22 исходных префаба: физические, огненные, ледяные, светлая и тёмная магия, земля и воздух. Используются оригинальные текстуры, частицы, кривые и меши с адаптацией для GFx.
- Вороний глаз выпускает по одному пурпурному снаряду в каждый затронутый ряд; попадания следуют за вылетом.
- Звуки вылета и попадания берутся из соответствующих префабов беты. Принятая молния Альзура сохранена.
- Общий бюджет частиц ограничен; есть вариант для уменьшенного движения. Одновременные усиления от триггера сохраняются.
- После вступления фокус контроллера автоматически возвращается на первую карту мулигана. Защита от замены карты той же кнопкой, которой пропустили вступление, сохранена.
- Сброс соперника: удерживать LT + RT. Обычный способ открытия: Start → Действия → Сброс соперника.
- Исправлен поиск счётчика задания Скеллиге в Туссенте в иерархии журнала. Учтены все 19 противников, включая портного; после победы выполняется отложенная сверка по подтверждённым наградам. Повторная победа не создаёт ещё одну отметку, более высокий старый прогресс не уменьшается.
- Включено исправление соседнего агента: Гром при выборе цели ИИ учитывает, что восстановленная броня снова запускает способность реданского оруженосца, в том числе когда он сосед выбранного центра.
- Лимит меню остаётся 65 МиБ. Миграции формата коллекции нет; бочки остаются у корчмарей.

Это промежуточная сборка для проверки эффектов в игре, не завершение всего плана 0.7.0. Unity-шейдеры и объёмная геометрия адаптированы к двумерному интерфейсу; сходство с бетой требует игровой сверки.

Проверить: Вороний глаз на нескольких рядах; светлые усиления и обратные удары дуэли; физические/огненные снаряды; массовые ледяные эффекты; много целей одновременно; уменьшенное движение; отключение звука; прежнюю молнию Альзура. На контроллере: дождаться/пропустить вступление и выбрать карту мулигана без окна отмены; открыть сброс соперника курками и через меню. В Туссенте: новая победа над ещё не побеждённым соперником, обновление счётчика через несколько секунд и при открытии журнала; повторная победа без второй отметки. Для ИИ: Кейра → Гром при оруженосце без брони.

Локальная сборка из текущих исходников. Новые изменения требуют собственной игровой проверки.
