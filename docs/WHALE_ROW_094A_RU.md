# Кит из Пещеры Снов: прыжок только в другой ряд (0.9.4a)

По наблюдению автора в бете Кит из Пещеры Снов (152403) в конце хода переходил в случайный ряд, кроме того, где стоял: дважды в один ряд он не прыгал. В моде текущий ряд входил в список кандидатов (`|| row==s.locationMask`), поэтому примерно в трети случаев кит оставался на месте.

Исправление в `duelSkellige.ws`: кандидаты — только другие ряды своей стороны, где меньше 9 карт. Если таких нет, кит остаётся в своём ряду и всё равно наносит 1 урон остальным отрядам ряда. Описание карты из беты не менялось.

Проверка `tools/ai/check_whale094a.cjs` исполняет настоящий движок WS→JS: 360 ходов из каждого ряда (кит всегда уходит, оба других ряда достижимы, урон только в ряду назначения), заполненный ряд пропускается, при двух заполненных кит остаётся. 2235 проверок. Негативный контроль со старым условием даёт 142 нарушения. Все 97 групп регрессий ИИ на новом движке проходят. Тест включён в `Build-0.9.4a.cmd`. Бэкап исходника: `tmp/backup-editorfx-whale-094a-20261026`.
