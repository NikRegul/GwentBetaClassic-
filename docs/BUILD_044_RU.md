# Сборка Gwent Beta Classic 0.4.4

Редактируемый скрипт: `D:\w3mod\tools\Build-0.4.4.ps1`.
Он использует общий сборщик `Build-GwentBeta.ps1`, этап 124 и исходники из текущего рабочего каталога.
По умолчанию собирает RU и EN и запускает проверки правил, ИИ и интерфейса.

## Полная сборка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-0.4.4.ps1
```

Только русская версия:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-0.4.4.ps1 -Language ru
```

Только английская:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-0.4.4.ps1 -Language en
```

Результат — `BetaGwent\release\GwentBetaClassic-0.4.4-RU.zip` и/или `GwentBetaClassic-0.4.4-EN.zip`, рядом контрольные суммы SHA-256.
Скрипт подготавливает исходники, пересобирает локализованные меню, компилирует WitcherScript через REDkit и упаковывает ресурсы.
Установка в обычную игру автоматически не выполняется.

## Что можно менять

В начале скрипта доступны `$Language`, `$Version`, `$Step`, `$Compiled`, `$KegVideo`, `$CheckAI`.
Изменения логики вносите в `BetaGwent\development\scripts\game\betagwent`, интерфейса — в `BetaGwent\ui\src`.
Сгенерированный `duelCatalog.ws` пересоздаётся; правило выбора «до N» генерируется в `tools\build_duel_catalog.py` по данным каталога.

Для промежуточных этапов поддерживаются `-Step prepare`, `scripts`, `menus`, `package`.
После изменения игровых скриптов или интерфейса используйте полную сборку: упаковка отдельно рассчитана на уже подготовленные и проверенные результаты этого же этапа.
Вызов `-Version 0.4.4-test1` создаёт пакет с отдельным номером. Повторная сборка сохраняет предыдущие результаты в каталоге сборок.

Логи: `BetaGwent\build\stage124\powershell`. Отчёты проверок: `docs\evidence`.
При ошибке сборка останавливается; известный сбой завершения REDkit 0xC0000008 повторяется ограниченное число раз.

## Проверки 0.4.4

- Выбор 0, 1, …, N карт для Бьянки, Ваттье, Морврана, Брана и Саскии.
- Корректное продолжение способности после досрочного завершения, пустые списки и отклонение устаревшего запроса.
- Обязательное получение выбранных замен Саскии; обязательные способности сохраняют свои ограничения.
- Аард: ближний ряд → дальний → осадный; осадный остаётся на месте. Урон сохраняется при заполненном соседнем ряду.
- Кнопка «Завершить выбор», её доступность и отправка запроса в интерфейсе.

Для сборки требуется существующее локальное окружение проекта: Python, Node.js, Java, REDkit, инструменты и ресурсы меню/атласов/звука. Подробности — `docs\BUILD_RU.md`.
Проверки кода и компиляция не заменяют проверку мыши, контроллера и изображения в самой игре.
