# Перенос презентации Beta 0.9.24

Исходный клиент читается из `Gwent 0.9.24.3.432/Gwent_Data`. Управление UI
и изменение файлов оригинального клиента не используются. Материалы CD
Projekt и их производные не входят в GPL-лицензию авторского кода.

## Извлечение

```powershell
python -X utf8 tools/recon/extract_beta_presentation.py
```

Результат — `BetaGwent/build/beta-presentation91/manifest.json` и каталог
рядом. PNG содержат оригинальные текстуры. OBJ содержат геометрию/UV;
JSON рядом — материалы, компоненты и трансформации досок. Для частиц
и клипов сохраняются исходные BIN и сжатые `json.gz` с конфигурацией.
Для 81 stripped MonoBehaviour есть BIN, но нет полного типового дерева.
Они требуют отдельного декодирования с учётом managed-классов.

Извлечение включает Мороз, Туман, Дождь, очистку, прямые/рядовые/массовые
эффекты физических, огненных, ледяных, молниевых и магических ударов,
смерть, изгнание, раскрытие засады и связанные эффекты. Декодированные
клипы могут хранить данные в сжатой muscle/streamed-форме, а не в обычных
float curves: сохранение клипа ещё не означает перенос его воспроизведения.

## Подготовка к GFx

`tools/ui/beta_board_sources.py` связывает board_top/board_bottom с мешем,
материалом и _MainTex. Треугольники растеризуются по исходным UV с глубиной
в ортографической проекции. Десять половин — пять фракций × две стороны —
сохраняются в `BetaGwent/ui/assets/beta-boards`. Каждая половина занимает
четыре ячейки атласа. Восемь дополнительных ячеек содержат фон Beta.
Освещение и перспектива Unity этим способом не воспроизводятся.

`tools/ui/beta_visual_sources.py` сохраняет уголки/рамки/свечение,
вспышки, следы, дым и частицы. Чёрный фон additive-текстур преобразуется
в straight alpha для GFx. Туман разбивается на 30 кадров по UVModule 2×15;
порядок начинается с нижней строки текстуры, как в Unity. Его кривая
frameOverTime семплируется по исходным касательным Hermite.
`BetaGwentVisualTimings.as` генерируется из конфигурации и длительностей
FogFadeInAnimation, FrostInitialAnim, RainInitialAnim.

```powershell
python -X utf8 tools/ui/build_card_art.py
python -X utf8 tools/build_presentation91.py
```

Атлас: 4096×3780, 667 уникальных привязок. Оригинальные типы погоды из TW3
сохранены для постепенно заменяемого основания Мороза. Основные поля
состояния, правила, координаты выбора и API 44 связей не менялись.
Фракция выбирается по фактическому leaderIds каждой стороны, затем
по лидеру выбранного preset при отсутствии известного лидера.

Погода обновляет движение редко, а flipbook — с частотой фильма. Новые
кадры не создаются на каждом тике; меняется видимость подготовленных
спрайтов. Подсветка пульсирует изменением alpha, не перерисовывается.
Краткий режим исключает лишние эффекты. Пропуск не повторяет игровую
способность: правила остаются в WitcherScript, GFx показывает снимки.

Упаковщик native atlas теперь находит прежние доски по размерам и
порядок новых чанков определяет по ImageInfo. Он не предполагает, что
атлас или пара досок всегда находятся на фиксированных индексах.
Проверяются CRC, связи DDS, встроенный ABC, символы и исходные пиксели.

## Проверочная сборка

```powershell
python -X utf8 tools/package_presentation91.py
```

Отдельные пакеты `GwentBetaClassic-0.2.1-preview.1-RU.zip` и `-EN.zip`.
Используются проверенные native-ресурсы этапа91 и скомпилированные60 WS
этапа90 после проверки всех SHA исходников. Неизменённые строки предметов
и звуковой кэш переиспользуются только после сравнения БД строк и файлов
первого релиза. cook/dependencies/pack/metadata выполняются заново.
ZIP0.2.0 неизменяемы; новые версии получают отдельные имена.

Качество в игре принимается по `PRESENTATION91_RU.md`. Статические проверки
не подтверждают, что каждый исходный Unity-шейдер перенесён или что новое
изображение поля идеально совмещено с областями рядов.
