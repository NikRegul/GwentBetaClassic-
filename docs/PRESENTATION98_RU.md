# Gwent Beta Classic 0.2.5 — русская сборка для проверки

**Перед установкой сделайте резервную копию сохранений. Используйте отдельный тестовый слот.**

0.2.4 снова не открыла редактор и бой в установленной игре, хотя работала
в REDkit. В этой сборке уменьшаем объём встроенных текстур. Настройки памяти
игры не меняются. Устранение зависания ещё необходимо подтвердить запуском.

Основные изображения карт уменьшены с 384×540 до 288×405. Половины поля Beta
уменьшены с 2048×708 до 1536×531. Это 75% прежнего разрешения по каждой оси,
существенно больше старых карт 128×180. Дополнительные фоны DIY уменьшены
вдвое; основные фракционные поля используют масштаб 75%.

Логические размеры, рамки, кликабельные области и координаты кадров эффектов
сохранены. Исходные HD-изображения не удалены. Изображения остаются встроенными
в меню: вариант с внешними текстурами 0.2.3 не используется. Игровой bundle
хранится без сжатия. Сборщик ограничивает каждый ресурс меню размером 55 MiB.

Исправления вложенного розыгрыша, создания Медведя, выбора ряда, воскрешения
и освобождения курсора из 0.2.4 сохранены. Правила карт и ИИ не менялись.

## Проверка в обычной игре

1. Полностью закрыть игру. Заменить прежнюю папку `Mods/modBetaGwent0924`
   папкой из нового архива. Не смешивать файлы разных версий.
2. Загрузить сохранение, открыть редактор через меню паузы. Проверить наличие
   картинок карт и деревянных панелей. Закрыть редактор: ESC и управление
   Геральтом должны работать, курсор не должен оставаться в центре.
3. Начать партию с NPC. Проверить загрузку, текстуры поля и карт, просмотр
   карты ПКМ/X и выбор цели. После выхода проверить курсор и меню паузы.

В первую очередь нужны результаты этих двух открытий в установленной игре.
Если загрузка заработает, затем проверим исправления Шепчущий холм → Рык →
Медведь и Аглаису. Английскую сборку и публикацию готовим после этой проверки.

Для сообщения об ошибке: версия 0.2.5 RU, версия игры, другие моды, откуда
открывалось меню, последние действия, скриншот и лог при наличии.
