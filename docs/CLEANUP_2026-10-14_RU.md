# Очистка диска: 14 октября 2026

Скрипт: `tools/Clean-ProjectSpace.ps1`. По умолчанию показывает план, ничего не
удаляет и сохраняет полный список абсолютных путей в
`docs/evidence/cleanup/plan-*.csv`. Рабочие папки при подготовке скрипта не удалялись.

## Что можно убрать

Замер логического объёма: `docs/evidence/project-space20261014-cleanup.json`.

| Группа скрипта | Что удаляется | Объём |
|---|---|---:|
| `LegacyBuilds` — по умолчанию | Существующие `BetaGwent/build/stage106…132`, кроме **stage114**; `release106…132`; старые `board-compile106…132ru/en…` | 101,15 ГиБ |
| `PremiumExperiments` — по умолчанию | `BetaGwent/build/premium134-probe-*` с датой и временем в имени; `BetaGwent/build/premium-capture/frames134` | 6,02 ГиБ |
| `OldReleaseDuplicates` — дополнительно | `BetaGwent/release/old` — прежние варианты и промежуточные архивы | 5,94 ГиБ |
| `DownloadedZips` — дополнительно | `DiyGwent-AITest-Windows-2.1.10-premium.zip`, `LegacyGwent-2.1.10.zip`, только при наличии одноимённых распакованных папок | 3,02 ГиБ |

Основной план: **107,17 ГиБ, 158 путей**. Все четыре группы: около **116,12 ГиБ**.
Это логические размеры: жёсткие ссылки и сжатие могут уменьшить реальный прирост
свободного места. Список и размеры пересчитываются при каждом запуске.

Удаление старых сборочных результатов означает, что для повторной проверки или
упаковки соответствующих исторических этапов понадобится заново подготовить их
выходы. `release/old` можно удалить, если эти прежние варианты не нужны для отката.
Текущие ZIP в корне `BetaGwent/release` сохраняются, включая базовые архивы 0.3.0-test.
ZIP исходных плееров придётся скачать повторно, если они снова понадобятся.

## Запуск из PowerShell

Только посмотреть основной план:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Clean-ProjectSpace.ps1
```

Удалить основной набор после просмотра списка — удаление окончательное, без корзины:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Clean-ProjectSpace.ps1 -Apply
```

Для симуляции удаления добавьте `-Apply -WhatIf`.

Все четыре группы: запускать непосредственно в PowerShell, чтобы передать массив:

```powershell
& D:\w3mod\tools\Clean-ProjectSpace.ps1 -Groups LegacyBuilds,PremiumExperiments,OldReleaseDuplicates,DownloadedZips
```

После просмотра этого расширенного плана повторите команду с `-Apply`.
Если локальная политика запрещает запуск, используйте отдельный сеанс
`powershell -NoProfile -ExecutionPolicy Bypass`, затем выполните команду внутри него.

## Что оставлено

- **stage114**: `tools/core-check/check_ai_rules.py` читает из него эталон каталога.
- **stage133 и новее**: среди них сборочная основа `stage143`, текущие результаты
  и промежуточные входы. Также сохранены все `audit*`, `history*` и quarantine.
- `release87`, `release89`, `release060-preparation`, `languages137`, `text138`,
  `audio*`, материалы эффектов, портреты и актуальные кадры лидеров.
- `resource-backups`: один конкретный ресурс нужен тесту `check_resource_update.py`.
- Вся `BetaGwent/ui/build`: здесь есть используемые кэши и шрифты.
- Исходники, документы, `data`, `tools`, Wwise-проекты, исходные игровые клиенты,
  `GwentB`, `depot`, `.git` и `BetaGwent/build/github-0.3.0`.

Скрипт использует общий замок сборки `presentation-build.lock`, проверяет
абсолютные пути и ограниченный список целей, отказывается обходить junction,
символьные ссылки и вложенные `.git`. Старые инструменты, не использующие общий
замок, перед очисткой следует завершить.
