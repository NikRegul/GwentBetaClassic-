# Сравнение старого и нового ИИ

Скрипт: `D:\w3mod\tools\Compare-AI.ps1`.
Нужны PowerShell, Python и Node.js. Игра и REDkit могут быть закрыты.
Скрипт сравнивает решения, не обучает ИИ и не меняет установленный мод или рабочие игровые исходники.

## Сравнить 0.4.2 с 0.4.1

Запустить из любого каталога:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Compare-AI.ps1 -Cycles 10 -Seed 422 -Output D:\w3mod\BetaGwent\training\compare-041-042
```

Папка результата должна быть новой. По умолчанию используются сохранённые снимки:

- Старый ИИ 0.4.1: `D:\w3mod\BetaGwent\training\stage120-release\snapshot`.
- Новый ИИ 0.4.2: `D:\w3mod\BetaGwent\training\stage121-release\snapshot`.

Один цикл — 184 партии. Все 46 архетипов участвуют; на пару колод приходятся четыре партии с одинаковой исходной раздачей и состоянием генератора случайных чисел. Каждая версия играет обе колоды и оба порядка хода. Обмен карт каждая версия выбирает сама. После разных решений случайные события могут разойтись — результаты случайных доборов заранее не навязываются.

Старые методы принятия решений и веса переносятся в копию новых правил. Составы колод, определения карт, эффекты и не относящиеся к решениям методы сессии берутся из нового снимка. Это сравнение ИИ на общих правилах, а не противостояние двух полных версий мода с разными исправлениями карт. При существенном изменении структуры ИИ очень старый снимок может оказаться несовместимым; подготовка или партия сообщат об ошибке, и такой результат нельзя считать оценкой силы.

## Сравнить 0.4.3 с 0.4.2

После этой сборки сохранён отдельный снимок 0.4.3 со всеми исправлениями Моркварга и возврата ослабленных карт. Для нового эксперимента используйте отдельную папку:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Compare-AI.ps1 -Baseline BetaGwent/training/stage121-release/snapshot -Candidate BetaGwent/training/stage123-release/snapshot -BaselineLabel 0.4.2 -CandidateLabel 0.4.3 -Cycles 10 -Seed 422 -Output D:\w3mod\BetaGwent\training\compare-042-043
```

Для ночного прогона замените `-Cycles 10` на `-Cycles 45`. Старые результаты 0.4.1/0.4.2 сохраняются отдельно. Само сравнение 0.4.3 ещё не запускалось.

## Длительный запуск, например на ночь

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Compare-AI.ps1 -Cycles 45 -Seed 422 -Output D:\w3mod\BetaGwent\training\compare-041-042-night
```

45 циклов — **8280 партий**, каждая колода встречает все остальные 45. Это покрывает 1035 уникальных пар разных архетипов; зеркальные назначения повторяют пары намеренно. 10 циклов — 1840 партий; 1 цикл — 184. Число циклов задаёт объём, а не длительность: время зависит от компьютера и карт. Оставьте компьютер включённым без перехода в сон. Сжатые записи всех партий занимают дополнительное место на диске.

Остановка — Ctrl+C. После каждой завершённой партии сохраняются отчёт и запись. Прерванная незавершённая партия при продолжении рассчитывается заново. Продолжить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Compare-AI.ps1 -Resume -Output D:\w3mod\BetaGwent\training\compare-041-042-night
```

Продолжение использует сохранённые Seed, Cycles, версии и код стенда. Новые параметры Cycles/Seed при Resume не меняют эксперимент. Входные файлы проверяются по SHA-256; подмена запрещает продолжение. Одну папку нельзя использовать одновременно в двух запусках.

## Проверить свои следующие правки

Чтобы сравнить изменённые рабочие исходники с релизом 0.4.2:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Compare-AI.ps1 -Baseline D:\w3mod\BetaGwent\training\stage121-release\snapshot -BaselineLabel 0.4.2 -Candidate current -CandidateLabel experiment-1 -Cycles 10 -Seed 422 -Output D:\w3mod\BetaGwent\training\compare-experiment-1
```

`-Candidate current` сначала создаёт отдельную копию исходников и компилирует стенд внутри неё. Во время создания снимка не редактируйте исходники. После подготовки можно продолжать работу: эксперимент использует сохранённые копии. Можно передать `-Candidate` путь к другому готовому снимку вместо `current`. Для старого ИИ нужен полный каталог `snapshot` с `manifest.json` и `sources`, одного файла весов или игрового ZIP недостаточно.

Дополнительные параметры:

- `-PrepareOnly`: подготовить копии, пока не играть. Запуск подготовленного эксперимента — той же командой с `-Resume`.
- `-MaxGames 8`: выполнить максимум восемь **новых** партий за этот запуск. Полезно для проверки; продолжение добавляет партии к сохранённым.
- `-Output`: каталог результата; относительные пути считаются от `D:\w3mod`, а не от текущего каталога PowerShell.

## Какие файлы прислать для разбора статистики

В выбранной папке результата:

- `REPORT_RU.md`: общий итог и таблица всех 46 архетипов.
- `archetypes.csv`: таблица для Excel, UTF-8; победы, поражения, ничьи, ошибки, доля очков и среднее число шагов.
- `report.json`: полная статистика, в том числе порядок хода, парные результаты и хеши версий.
- `games.jsonl`: результат каждой завершённой партии с колодами, Seed и назначениями версий.
- `matches\*.json.gz`: исходное состояние, решения и логи каждой партии.
- `errors\*.json.gz`: партии с ошибками и состояние перед ошибкой.
- `compare.log`: ход запуска.

Для сравнения пришлите `REPORT_RU.md`, `archetypes.csv` и `report.json`. При ошибках нужны соответствующие записи из `errors` и `compare.log`. Для воспроизведения партии сохраните всю папку эксперимента с `candidate`, `baseline` и кодом стенда.

Повтор конкретной партии (замените имя каталога/партии на своё):

```powershell
node D:\w3mod\BetaGwent\training\compare-041-042\replay119.js D:\w3mod\BetaGwent\training\compare-041-042\matches\game-000001.json.gz
python -X utf8 D:\w3mod\tools\ai\explain_log119.py D:\w3mod\BetaGwent\training\compare-041-042\matches\game-000001.json.gz
```

Первая команда проверяет воспроизводимость на сохранённых версиях; вторая переводит записи решений в читаемый отчёт.

## Как оценивать результат

Доля очков = `(победы + 0,5 × ничьи) / завершённые партии без ошибок`. Ничья не считается поражением. Смотрите общий итог, отдельные архетипы и разницу между первым и вторым ходом в `report.json`. Рост общего результата может скрывать ухудшение отдельных колод.

Четыре партии одной исходной раздачи объединяются в одну группу, чтобы не считать связанные игры полностью независимыми. Отчёт показывает среднее по полным группам и приближённый 99% интервал. `confirmedBetter = true` требует полного прогона без ошибок, минимум 46 полных групп и нижней границы выше 50%. Это ориентир стенда, не гарантия превосходства против человека. Вывод после нескольких тестовых партий делать рано.

Ошибки не записываются как победы или поражения. Незавершённый прогон сохраняет статистику, но не подтверждает улучшение. Стенд не измеряет FPS, анимации, сохранения и управление в обычной игре; их проверяем отдельно.
