Пользователь подтвердил, что история ходов и меню боя его устраивают; из
отложенных окон остался только этот пункт. Полный просмотр карты уже имел
колонку пояснений (`createDetailKeywords096`). Не хватало поведения боя.

  `CardSidePreviewTooltipHandler`, `Tooltip Context` 223,3×281,6 у карты,
  `TooltipContext`: `Placement=LeftToContext`, `Expansion=Downwards`, `margin=20`.

- Одна подсказка — `CardSidePreviewTooltip` (`AbilityTooltip`): фон
  `side_preview_info_bg_*` фракции, металлическая линия снизу, отступы 14.

## Перенос (`BetaGwentBoard.as`, пять копий и Classic overlay)

`scheduleSideKeywords102` / `updateSideKeywords102` / `clearSideKeywords102`.
Только для превью при наведении в бою (не мулиган, сброс, редактор, каталог,
выбор колод), только для открытых карт с пояснениями. Через 750 мс столбик
подсказок появляется слева от карты превью (отступ 20, верх по карте, вниз),
каждая — те же фон фракции и линия, что в полном просмотре. Короткий сдвиг
появления как у превью; при reducedMotion — сразу и без анимации. Столбик не
перехватывает мышь, удерживается в пределах экрана, исчезает при смене карты,
закрытии превью и открытии полного просмотра. Переключатель скрытия общий с
колонкой полного просмотра (кнопка «Описание» / стик). Тексты — те же
пояснения, что в полном просмотре, уже переведённые; новых строк нет.

Значение `TooltipDelay` в бандлах не найдено (сериализуется в сцене);
750 мс взяты из константы `BasePanelMouseTooltipHandler`. Масштаб корня
подсказок в префабе 0,5 без кадров беты не сверялся: ширина взята равной
панели описания превью (312), шрифт 17. Это отличие возможно и требует
сверки в игре.
