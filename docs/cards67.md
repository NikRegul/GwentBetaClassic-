# Этап67: особые и связанные с ними отряды

Обновлено 2026-10-03. Строгая Beta0.9.24.3.432. Добавлено17 определений:
8 особых,6 коллекционных отрядов и3 служебных отряда. Версия установлена
в рабочий проект; игровой прогон новых эффектов пока не проведён.

## Особые карты

| Карта | Реализация |
|---|---|
| Славная охота | При меньшем счёте создаёт и разыгрывает Имперскую мантикору13; при равном или большем — Яд мантикоры13. Для отряда выбирается место, для Яда — обычная цель. |
| Леденящий кровь рык | Уничтожает своего отряда с обработкой Завещания, затем создаёт и разыгрывает Медведя11. |
| Ополчение крестьян | Создаёт до3 Крестьян3 в выбранном своём ряду с учётом свободных мест. Не вызывает Played. |
| Кровавый бич | Наносит5 урона выбранному отряду любой стороны и создаёт Призрака5 в случайном доступном своём ряду. Не вызывает Played для Призрака. |
| Каменный вал | Наносит7 урона врагу, затем сдвигает выжившего из ближнего ряда в дальний, из дальнего в осадный. Полный следующий ряд уничтожает отряд; осадный не двигается. |
| Намордник | Перемещает в свой соответствующий ряд бронзовый/серебряный вражеский отряд силой<=8. Нужны свободное место и допустимые токены. Сила/instance ID сохраняются, Deploy не запускается. |
| Чучело | Возвращает свой бронзовый/серебряный отряд в руку, сбрасывает временную силу/броню/токены и условно таймер; усиливает на3 до повторного розыгрыша. Новое место и способность выбираются заново. Возврат не вызывает Killed; Doomed сохраняется в руке. |
| Мазь | Выбирает из своего сброса бронзовый отряд силой<=5 и разыгрывает его с выбором места/способности. Реальный ID. Минимум1 задан проводом графа, несмотря на raw MinChoices0. |

Служебные Медведь152406/Крестьянин201677/Призрак201758 добавлены с исходными
силой, фракцией и токенами. У них нет CardAbility в исходной Beta, поэтому
это полные простые отряды, а не заменители недоделанных способностей.
Мантикора132209 и Яд113306 уже реализованы ранее и используются напрямую.
Служебные отряды не добавлены в коллекцию/редактор.

## Обычные отряды

| Карта | Сила | Способность |
|---|---:|---|
| Киприан Вилли |8|Ослабляет выбранный отряд на4 изначальной силы.|
| Ан Крайт: боец |5|Увеличивает текущую силу своего выбранного отряда на50%.|
| Махакамская стража |4|Усиливает своего выбранного отряда на7.|
| Тиршах: ловчий |6|Наносит5 урона выбранному отряду любой стороны.|
| Темерский барабанщик |5|Усиливает своего выбранного отряда на6.|
| Молотобоец Аэдирна |7|Наносит4 урона выбранному вражескому отряду.|

Данные, маски целей, ограничения и параметры взяты из оригинальных графов,
включая подключённые переменные вместо неиспользуемых literal-портов.
Усиление/урон/ослабление проходят очередь действий. Для перемещения отдельное
действие без Deploy; смена стороны меняет Spying, а owner ID сохраняется.
Возврат в руку сбрасывает таймер только при исходном ResetInInactive=true.
Новые способности не выданы остальным отрядам по сходству описаний.

## Проверка позже одним заходом

Полностью перезапустить REDkit, открыть прежний проект и тестовый сейв,
выполнить `bgboard_open()`. Import и menuResource прежние; файлы переложены.
В редакторе копировать существующую колоду и добавить доступные нейтральные
новинки. Проверить в обычной партии: Чучело на отряде со способностью;
Рык и выбор места Медведя; Ополчение в ряду; Намордник на враге<=8;
Каменный вал на выжившем враге; Славную охоту при меньшем и большем счёте.
Киприан должен менять изначальную силу. Полный каталог показывает остальные
фракционные добавления; Мазь и новые фракционные отряды для обычных партий
станут доступны после включения соответствующих колод.

Не требуется новый набор консольных тестов. Runtime67, полный parity
оригинального контроллера/произвольных графов и save/reload не подтверждены.
Обязательная сборка Wcc67b успешна без Script errors; AS3/GFx/native/receiver
и совпадение authoritative/active/compiled patch проверены.37 .ws, четыре
оригинальных board texture chunks сохранены; предыдущая66 сохранена backup.
Результаты: `docs/evidence/stage67-cards-result.json`, исходные графы:
`docs/evidence/cards67-source.json`, движение: `docs/evidence/moves67-il.txt`.
