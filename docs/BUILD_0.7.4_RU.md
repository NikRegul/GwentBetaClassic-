# Сборка 0.7.4b RU

Актуальный кандидат: Stage 200 для Next-Gen 5.0+, только RU.
Архив: BetaGwent/release/GwentBetaClassic-0.7.4b-RU.zip (316504377 байт).
SHA-256: 24a1cf304f199cd71001841b584f5cd7ec7091635d8cecbe4280d94b91315d10

Прошли 81 набор регрессий, компиляция 70 нативных скриптов и четырёх меню, проверка manifest/CRC/SHA-256. Максимальное меню — 62.882 МиБ при пределе 63. Проверка: docs/evidence/validation200.json. В игре исправление ещё не подтверждено.

Исправлена структура BetaGwentBoard.drawBacks: поиск карты и статусы вынесены в enemyHandView191/drawEnemyHandStatuses191. Реальный ABC меню колод: 1172 → 921 байт, 22 → 17 локальных переменных, 2 → 1 перебор. 110 целевых проверок включают 102 сравнения полного рисования и снимков статусов с 0.7.4a. Скрытие раскрытой карты и порядок слоёв сохранены. Подробности: docs/evidence/drawbacks-abc200.json, drawbacks-preservation200.json.

По сравнению с 0.7.4a изменён только целевой участок класса BetaGwentBoard. Все 70 WS-скриптов, остальные классы UI, атласы и рецепты эффектов совпадают. Сохранены три стрелы Йотуна, Казнь Хеймдалля, начало/тики Рагнарёка, огонь/пиво, статусы/броня и НГ+ бочки. Эксперимент с переносом запуска вступления и передачи звука отменён до компиляции меню; Stage 199 не упакован.

История проверки: 0.7.4 / Stage 197 зависал до колод (64.507 МиБ). 0.7.4a / Stage 198 открыл колоды, но падал при «Начать бой». Пользователь определил drawBacks по четырём параметрам метода в дампе; сохранённый SWF подтвердил 756/1172/27/22.
