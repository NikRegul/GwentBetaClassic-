# Составы колод ИИ

Файл для авторских замен: `D:\w3mod\data\beta924\ai\deck_overrides.json`.

Для Эредина «Морозные призраки» указаны `profileId: 29` и `copyPresetId: 16`. Генератор копирует весь стартовый пресет №16: лидера и массив карт с повторениями. Получатель — пресет №80. Название архетипа и его профиль погоды остаются прежними; пул содержит все 40 колод.

Исходный состав стартовой колоды задаётся в `D:\w3mod\data\beta924\design\starter_decks.json`; текущие игровые пресеты — в `D:\w3mod\data\beta924\duel\presets.json`. Не редактируйте сгенерированный `duelCatalog.ws` вручную: следующая генерация заменит его.

Чтобы добавить аналогичную замену, добавьте запись с ID действующего профиля, ID исходного пресета той же фракции и пояснением `reason`. Это копия фиксированного списка при сборке, а не доступ ИИ к закрытой колоде игрока в бою.

Для пересборки текущей русской версии:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-Stage114.ps1 -Language ru -CheckAI
```

Скрипт заново создаёт профили и карточные таблицы, проверяет лимиты колод, компилирует меню и WitcherScript, затем собирает архив. Для изменения стратегии, а не состава, см. `D:\w3mod\docs\AI_MANUAL95_RU.md`.
