# Запуск сборки из исходников

В корне проекта дважды нажмите **Build-Mod.cmd**. Окно останется открытым после завершения, включая случай ошибки. Журнал запуска находится в `BetaGwent/build/source-logs`; журналы отдельных этапов — в новом `BetaGwent/build/stageNNN/logs`.

По умолчанию создаётся отдельная RU-версия вида `0.7.0-local-20261014-010000` и новый номер этапа. Архив появляется в `BetaGwent/release`. Существующие релизы и каталоги сборок не перезаписываются. Запуск включает заморозку текущих исходников, подготовку 70 скриптов, текстуры специальных эффектов, 62 набора проверок, компиляцию четырёх меню и скриптов, упаковку и проверку архива. Русская озвучка и 13 языков текста сохраняются. Оригинальная иконка бочки отдельно готовится в кеше текстур инвентаря; её PNG и привязка проверяются перед упаковкой. Подготовка 0.7.0 продолжается: состояние блоков — в `docs/V070_PROGRESS_RU.md`.

Для новых полных сборок используется порог GUI 65 МиБ, как у принятой пользователем полной 0.6.8. Настройки памяти игры не меняются. Для явного ограничения укажите `-GuiLimitMiB 56`; при превышении сборка остановится, качество ресурсов автоматически не понижается.

Можно задать новую версию:

```powershell
.\Build-Mod.cmd -Version 0.7.0-local-test
```

Проверка окружения без сборки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-FromSource.ps1 -CheckOnly
```

Повторная проверка своей локальной сборки (укажите версию и этап из её отчёта; исходники должны совпадать с замороженными):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-FromSource.ps1 -Verify -Version 0.7.0-local-test -Stage 163
```

Для проверки другой локальной сборки укажите её версию и номер этапа из журнала. При изменении исходников после выпуска требуется новая сборка; проверка старого пакета в изменённом рабочем дереве может отвергнуть несовпадение входов.

Исторический порог GUI 56 МиБ сохраняется как явная опция `-GuiLimitMiB 56` для проверки компактных ресурсов. Полные новые сборки используют 65 МиБ после успешного игрового запуска полной 0.6.8 пользователем; это разрешает упаковку более крупного меню и не меняет настройки памяти игры.

Неудавшуюся упаковку после успешной компиляции можно продолжить без повторной сборки меню:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-FromSource.ps1 -ResumePackage -Version 0.6.8 -Stage 148 -GuiLimitMiB 65
```

Продолжение сверяет замороженные исходники, отчёты проверок и компиляции. Оно поддерживает сбой до заморозки проекта, например превышение GUI-порога на `prepare`; уже созданный архив не перезаписывается.

Скрипт рассчитан на это подготовленное локальное окружение Windows: Python с установленными зависимостями, Node.js, REDkit/GFx по настроенным путям, ранее принятую пользователем лицензию SDK, оригинальные извлечённые ресурсы, шрифты, вступления и RU-банк. Свежего клона недостаточно; недостающие входы выводятся до запуска тяжёлых этапов. Генераторы правил/каталогов при изменении исходных данных остаются отдельным шагом разработки. Скрипт собирает текущие подготовленные исходники, не устанавливает мод в игру и не публикует его.
