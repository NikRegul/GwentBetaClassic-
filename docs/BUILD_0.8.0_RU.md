# Сборка 0.8.0: все языковые пакеты

Подготовлены два отдельных запуска: Next-Gen и Classic 1.32. Каждый создаёт пять полных ZIP с озвучкой RU, EN, DE, IT, PT-BR. Каждый ZIP содержит все 13 переключаемых языков текста: русский, английский, немецкий, французский, итальянский, польский, испанский, латиноамериканский испанский, бразильский португальский, японский, корейский, китайский упрощённый и традиционный. Отдельных 13 пакетов озвучки нет: доступны пять исходных голосовых банков.

## Порядок запуска

Из каталога `D:\w3mod`:

```powershell
.\Build-All-0.8.0.cmd
```

Дождаться успешного завершения Next-Gen, затем:

```powershell
.\Build-All-0.8.0-1.32.cmd
```

Первый сценарий создаёт свежий Stage с версией 0.8.0, компилирует четыре меню и 70 скриптов, выполняет поддерживаемые регрессии, собирает RU и остальные четыре голосовых пакета. Общий предел меню — 63 МиБ. Старые архивы не перезаписываются.

Второй сценарий автоматически определяет Stage по manifest готового `GwentBetaClassic-0.8.0-RU.zip`. Для каждой озвучки он использует соответствующий замороженный пакет Next-Gen, а не текущие редактируемые исходники. Выполняется адаптация и нативная компиляция 1.32, преобразование банка в Wwise 88 и проверка ZIP. Classic-меню с мостом ввода и графические ресурсы собираются один раз на RU, затем проверяются и используются во всех пяти пакетах. Скрипты и звук каждой озвучки собираются отдельно. В пакет входят 79 скриптов: ядро и девять адаптированных файлов игры.

Оба сценария изменяют только проект и его каталоги сборки. Установка в игру не выполняется. Полноценная проверка игры 1.32, озвучки и сохранений остаётся отдельной приёмкой; имя версии 0.8.0 само по себе её не подтверждает.

## Проверка без сборки

```powershell
.\Build-All-0.8.0.cmd -CheckOnly
.\Build-All-0.8.0-1.32.cmd -CheckOnly
```

Эти команды выводят план, языки и наличие исходных пакетов. Они не запускают компиляторы, не создают Stage и архивы. При отсутствии готовой базы 0.8.0 Classic показывает `sourceStage: null` и `sourcePackagesReady: false`; это ожидаемо до первого Next-Gen запуска.

## Другие пути и проверка готовых архивов

```powershell
.\Build-All-0.8.0-1.32.cmd -GamePath "D:\GOG Galaxy\Games\The Witcher 3 Wild Hunt"
.\Build-All-0.8.0.cmd -Verify
.\Build-All-0.8.0-1.32.cmd -Verify
```

`-Verify` проверяет уже созданные пакеты и никогда не достраивает отсутствующие. Проверяются язык/версия/Stage, список файлов, ZIP CRC и SHA-256. Обычный повторный запуск пропускает проверенные готовые архивы. Для продолжения Classic нужно сохранить его исходный каталог сборки с общими RU-ресурсами. Если изменились входы или требуется повторить незавершённую упаковку, задайте новый `-OutputRoot` внутри `BetaGwent\build`; готовые архивы остаются неизменными. Существующие ZIP нельзя заменить другой сборкой под тем же именем: для нового релизного набора используйте новую версию.

Параметры PowerShell-сценариев доступны через `tools\Build-All-0.8.0.ps1` и `tools\Build-All-0.8.0-1.32.ps1`: `-Python`, `-Version`, `-Stage` / `-SourceStage`; у Classic дополнительно `-GamePath` и `-OutputRoot`. По умолчанию версия 0.8.0, Stage определяется автоматически, Classic использует установленную 1.32 по указанному выше пути.

## Результат

Все архивы сохраняются в `BetaGwent\release`:

| Платформа | Имена архивов |
|---|---|
| Next-Gen | `GwentBetaClassic-0.8.0-RU.zip`, `-EN.zip`, `-DE.zip`, `-IT.zip`, `-PT-BR.zip` |
| Classic 1.32 | `GwentBetaClassic-0.8.0-1.32-RU.zip`, `-EN.zip`, `-DE.zip`, `-IT.zip`, `-PT-BR.zip` |

К каждому ZIP создаётся `.zip.sha256`. Next-Gen отчёт: `docs/evidence/voice-batch<Stage>.json`; Classic: `docs/evidence/classic132-voice-batch<Stage>.json`. Логи Next-Gen находятся в выбранном Stage; Classic — в `BetaGwent/build/classic132-0.8.0-stage<Stage>/<язык>`.
