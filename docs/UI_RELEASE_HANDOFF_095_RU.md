Подготовлено 28.10.2026; тексты карт обновлены после аудита 29.10.2026. Версия остаётся **0.9.5**, платформы Classic 1.32 и Next-Gen 5.0+. Это передача входов и проверок, а не собранный релиз. Общую сборку запускает чат аудита **после завершения своей сверки**.

## Что не объявляется законченным

Полный перенос точной графики и исходных анимаций окон не завершён. Открыты силуэты/полная карусель и анимации итогов/корон, точная история с ribbons/маской/анимацией папки, некоторые детали выбора и popup-рамки. События отсутствующих анимаций рангов/корон не получили выдуманных триггеров. В игровых текстах это названо функциональной адаптацией, а не полной копией беты.

Визуальная проверка в игре, фактическое прослушивание всех событий и проверка сериализации «сохранить — выйти — загрузить» остаются открытыми. Готовность технического архива не заменяет их. Подробности: [BETA_UI_WINDOWS_095_RU.md](BETA_UI_WINDOWS_095_RU.md).

## Порядок действий чата аудита

1. Завершить аудит и адресные регрессии своего направления. Не считать сам факт технического прогона 511 шаблонов полной семантической сверкой. Не переносить ошибки тестов в поражения; не заявлять прирост силы без отдельного сравнения.
2. Сохранить UI/audio-код и исходники этого прохода. Для аудита **не заморожены здесь** правила WS/JS, каталог и генерируемые описания/связи карт/подписи выбора. Их актуальное состояние войдёт в новый общий снимок обычным сборщиком. Hard сохраняет ограничения скрытой информации, у «Классической» доступ шире.
3. Дополнить описания **изменений карт** в генераторе `tools/features095/notes095_public.py`, если аудит обнаружил новые исправления. UI-параграфы находятся отдельно в `ui_release095_text.py`. Не редактировать только сгенерированные файлы: сборка создаёт их заново. Вывод теперь идёт в новый каталог `docs/releases/0.9.5-public-20261029-final-audit`; прежний `rebuild05` не перезаписывается. Подготовлены 39 файлов на 13 языках.
4. Проверить передачу командой ниже. Если намеренно менялись её закреплённые инструменты/тексты, заново выполнить `prepare_ui_handoff095.py` в **новый** каталог и проверить результаты. Если менялись UI-исходники, сначала снова проверить/скомпилировать соответствующий UI-кандидат и согласовать его ссылки; не исправлять SHA вручную ради обхода ошибки.
5. Запустить `Build-0.9.5.cmd` с новым `--out`. Дождаться всех проверок, обоих нативных компиляторов, восьми новых меню, упаковки и независимой проверки архивов. Не использовать `--finish-prepared` или старый UI-only каталог как замену полного прогона.
6. Передать результат с `release-readiness.json`, `archive-verification.json`, SHA-256 архивов и игровым checklist. Готовые релизы не затирать; ничего не устанавливать, не публиковать и не делать push без отдельной задачи.

```powershell
Set-Location D:\w3mod
python -X utf8 tools/features095/prepare_ui_handoff095.py --out BetaGwent/build/ui095-release-handoff-20261029-07 --verify
python -X utf8 tools/recon/check_project_layout.py --hash-inputs
.\Build-0.9.5.cmd --out BetaGwent/build/release095-after-audit-20261029-04
```

Имя последнего каталога — пример нового выхода: если он уже существует, выбрать новый суффикс. Продолжать можно только явно указанный незавершённый **общий** выход с `--resume`, при неизменных входах. Обычный запуск без `--out` также выбирает свежий каталог.

## Что проверяет сборщик дополнительно

`ui_release095.py` фиксирует `ui-release-inputs.json` после подготовки нового общего входа. Фиксируются UI/атлас/аудио и SHA обоих кэшей; правила фиксируются отдельным существующим механизмом. При продолжении/упаковке изменение этих входов отклоняется.

Обязательные свежие отчёты для обеих платформ:

| Отчёт | Проверок |
|---|---:|
| `windows-<platform>.json` | 159 |
| `preview-keywords-<platform>.json` | 2707 |
| `battle-cleanup-<platform>.json` | 19 |
| `pad-legend-<platform>.json` | 23 |
| `window-audio-check.json` | 89 |

Отчёты привязаны к SHA проверенного Board/звукового исходника. Отсутствие файла, старое количество, другая ревизия, сбой или попытка подставить старый аудиокэш блокируют gate. Контракт и отчёты включаются в `user-release-checks.json`; контракт UI и описание ограничений — в архив. Независимая проверка сверяет доставленные кэши с выбранными SHA, а не только наличие имён файлов.

`Build-0.9.5.cmd` запускает полную существующую цепочку, включая все регрессионные группы, 92 JS/WS партии, 10 технических партий, проверки сохранений/профилей, платформенные правила и шрифты. Количество групп правил после аудита может увеличиться; это не меняет описанные выше UI-контракты. UI-only нативные проверки этого чата **не заменяют** компиляцию объединённых скриптов после аудита.

Команда повторной подготовки передачи без полной сборки (использовать новый каталог):

```powershell
python -X utf8 tools/features095/notes095_public.py
python -X utf8 tools/features095/prepare_ui_handoff095.py --out BetaGwent/build/ui095-release-handoff-НОВЫЙ
```
