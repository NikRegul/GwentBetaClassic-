# Этап 83 — квесты, книга коллекции и турнирные соперники

Дата: 2026-10-04. Изменения записаны в workspace REDkit; игровая приёмка
ещё не проводилась. Установленная TW3 на F: не изменялась.
Работа через файлы/CLI, без управления интерфейсом.

## Что добавлено

**«Собрать их все».** Согласованное условие — одна копия каждой из 479
доступных карт Beta, включая 21 лидера. Вторые и третьи копии бронзы не
увеличивают прогресс. Каталог показывает общий счётчик и остаток.
Получение новой карты обновляет прогресс; дополнительная копия не запускает
повторный пересчёт. При заполнении стартового набора пересчёт выполняется
после выдачи карт и миграции старых колод, чтобы избежать лишней работы.

Книга учёта карт («Gwent Almanac») показывает коллекцию Beta, остаток
по фракциям, правило завершения и способы получения. Замена содержимого
работает через штатный метод для инвентаря и глоссария.
`gwint_all_cards_collected` и достижение `EA_GwintCollector` выставляются
при полном сборе Beta. Старый завершённый квест и полученное достижение
не сбрасываются.

При добавлении старого карточного предмета временно подавляется проверка
старого достижения, которая могла завершить сбор по исходным картам TW3.
После штатного `OnItemAdded` снятые теги возвращаются. Основной тег карты
и обработчики наград/квестов сохранены. Квестовый граф нужно проверить
в игре; компиляция этого не подтверждает.

**Именованные соперники.** Всего 33 назначения золотых наград и 33 разных
фиксированных состава. У Роше отдельные Синие Полоски; другие составы
основаны на существующих архетипах, включают назначенное золото и одну
фиксированную замену бронзы. Индивидуальные стратегии ИИ ещё отложены.
Все составы по 25 карт, с ограничениями фракции, копий, четырёх золотых
и шести серебряных. Всего 53 пресета. Обычные NPC выбирают из первых 15.

**Туссент.** В исходном `cg700_card_game.w2phase` подтверждены четыре
фактических запроса боя:

| Запрос | Кто | ID золотой награды |
| --- | --- | --- |
| NMLTournament2 | Первый соперник турнира | 132101 |
| NilfTournament2 | Второй соперник турнира | 162103 |
| SkelTournament2 | Финалист | 152104 |
| ScoiaTournament2 | Главарь пуристов после турнира | 142106 |

Их источники указаны в каталоге. Личные имена актёров не угадывались:
использованы конкретные роли. `NKTournament2` есть в XML, но этим квестом
не запрашивается, поэтому пятый бой не добавлен. Во всех четырёх запросах
исходный квест требует у игрока Скеллиге.
[Разбор графа](evidence/native-tournament83.json).

**Допуск к турнирам.** Вместо оценки старых карточных предметов используется
наличие доступной легальной стартовой колоды Beta; для Туссента — Скеллиге.
После исходного метода обновляются штатные факты допуска и цели подготовки.
Начальные наборы уже позволяют пройти эту проверку; старый порог силы
коллекции TW3 не применяется. Деньги за вступление и сигналы результата
остаются в исходной цепочке.

Штатное обучение TW3 пропускается при запросе NPC: оно обучает другим
правилам и ожидает прежние обработчики Flash. Первым открывается выбор
колоды Beta. Исходный запрос боя вызывается через `wrappedMethod`.

**Конец сбора коллекции и бочки.** По ответу пользователя бочка за 150 крон
даёт до четырёх доступных копий бронзы и редкий выбор. Если бронзы осталось
меньше четырёх, выдаются все оставшиеся; если нет совсем — только редкий
выбор за ту же цену. Лишних копий нет. Это позволяет закончить сбор золота
и лидеров после заполнения бронзы. Если редкий пул заполнен, бочка не
продаётся и деньги не списываются. UI и описание товара отражают фактическое
количество; журнал записывает его вместо постоянного `ordinary=4`.

## Один общий игровой проход

После полного перезапуска REDkit, на отдельном тестовом сохранении:

1. Меню колод: только редактор; стартовые наборы, прежние колоды, имена,
   ограничения копий. Каталог показывает `собрано / 479`.
2. Книга учёта: такой же общий счётчик, остаток по фракциям, правило одной
   копии. Новая карта увеличивает счётчик на один; дополнительная бронза — нет.
3. Торговец и квартирмейстер Барона: новые карточные товары, стоимость,
   бочка 150, выбор редкой карты, корректные деньги и количество копий.
4. Обычный NPC: вход без старого обучения/зависания, автоматические раунды,
   возврат в диалог. Карта только за первую победу; повторная — без карты.
5. Квестовый NPC/турнир: фиксированный состав, назначенное золото либо
   300 крон за уже имеющееся; результат засчитывается. В Туссенте требуется
   Скеллиге. Недоступные сейчас турниры можно проверить перед выпуском.
6. Сохранить и перезагрузить: коллекция/колоды/выплаты не повторяются;
   оплаченная незавершённая бочка показывает прежний выбор без нового списания.

Все 479 карт ради текущего теста выдавать не требуется. Полная приёмка
завершения квеста, старых сейвов и NG+ остаётся перед выпуском.
Логи агент читает сам; новых отдельных консольных серий нет.
