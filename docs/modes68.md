# Этап68: выбор режима особых карт

Обновлено2026-10-03. Строгая Beta0.9.24.3.432. Пять новых коллекционных
особых, общий выбор режима с иллюстрациями и описанием. После обязательного
выбора показываются допустимые цели или начинается вложенный розыгрыш.
Повторный розыгрыш заново спрашивает режим. Версия установлена в проект,
новые действия в игре ещё не проверены.

| Карта | Режимы |
|---|---|
| Мардрём | Мутаген: сбросить текущую силу к изначальной+постоянной, затем укрепить изначальную на3. Токсин: такой же сброс, затем ослабить изначальную на3. Броня/токены/таймер этим сбросом не сбрасываются. Цель можно пропустить. |
| Мандрагора | Наливка: вылечить повреждённый отряд и укрепить на6; уже усиленный отряд сохраняет усиление. Экстракт: сбросить текущую силу и ослабить изначальную на6. Цель можно пропустить. |
| Костяной талисман | Зверь: воскресить бронзового зверя/сектанта из своего сброса с выбором места и способностью. Регенерация: вылечить своего отряда (исходный RestorePower99), затем укрепить на3. |
| Сигилль | Равенство: по3 урона всем нечётным врагам; Разрыв: по3 всем чётным. Список фиксируется перед уроном, затем общий death batch. Экипировка: случайный бронзовый/серебряный отряд своей колоды с полным розыгрышем. Один RNG draw, без shuffle и без создания копии. |
| Меч Вандергрифта | Ровный разрез: уничтожить бронзовый/серебряный проклятый отряд. Свирепый удар:9 урона с бронёй, при силе<=0 удалить до обработки смерти, без Killed/Завещания. |

У Меча оба GetCardsNode имеют незаданный PlayerId3 и не подключены к
GetOwnerOpponentPlayerId: исходный клиентский граф допускает обе стороны,
несмотря на слово «вражеский» в локализации первой ветви. Реализация сохраняет
именно граф. Это явно отмечено в evidence; полный server/controller parity
пока не заявляется.

11 исходных шаблонов вариантов служат только для выбора и описания.
Их отдельные CardAbility не запускаются; варианты не входят в коллекцию,
не считаются ещё11 реализованными игровыми картами и не создаются на поле.
Иллюстрации вариантов привязаны по точным DIY IDs либо исходному ArtId.
Воскрешение использует настоящий instance ID; обычные сыгранные отряды
уже поддержанного набора выполняют свои реальные способности.

При проверке числовых примитивов исправлено ослабление Киприана: отрицательный
AddBasePower учитывает броню, как его IgnoreArmor=false в графе. Отряд,
который погибает с изначальной+постоянной силой<=0, удаляется в Void без
Killed, согласно CardManager.KillWaitingToDie. Это не обычное уничтожение;
его Завещание не запускается. Для остальных смертей прежний Killed сохранён.

ИИ использует текущую эвристику для выбора режима/целей; оценка не расходует
gameplay RNG. Это не планирование25–30с, которое оставлено после всех карт
и колод по указанию пользователя.

## Проверка позже одной партией

Полностью перезапустить REDkit, прежний проект/тестовый сейв,
`bgboard_open()`. Файлы уже перенесены; menuResource/Import прежние.
В копию колоды добавить доступные нейтральные Мардрём, Мандрагору, Сигилль.
Проверить: видно варианты и описания; Мардрём сбрасывает усиление перед
укреплением/ослаблением; Наливка Мандрагоры сохраняет усиление; оба режима
Сигилля поражают правильную чётность, Экипировка разыгрывает отряд из колоды
и позволяет выбрать его место/способность. Киприан на бронированной цели
должен сначала израсходовать соответствующую броню.
Фракционные ветви проверить после открытия соответствующих колод.
Новых console suites не требуется; save/reload и runtime68 не подтверждены.

Сборка: Wcc68b explicit Success без Script errors;441479bytes blob. AS3/GFx,
native ABC/receiver, совпадение37 authoritative/active/patch sources проверены.
Четыре board texture chunks сохранены; native67 сохранён backup.
Доказательства: `docs/evidence/stage68-modes-result.json`, исходные графы
`docs/evidence/modes68-source.json`, примитивы `docs/evidence/modes68-il.txt`.
