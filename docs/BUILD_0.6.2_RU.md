# Сборка 0.6.2 — stage 138

Русский пакет для ручной проверки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-0.6.2.ps1 -Language ru
```

Все пять пакетов озвучки (RU, EN, DE, IT, PT-BR), каждый с 13 языками текста:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\w3mod\tools\Build-All-0.6.2.ps1
```

Сборка готовит актуальные каталоги и колоды, создаёт отдельный снимок ИИ, запускает регрессии, нативно компилирует 70 скриптов, пересобирает четыре меню, готовит нативные ресурсы текста и проверяет фактический ZIP. Сравнение силы старого и нового ИИ не является условием готовности этого пакета и не запускается этим скриптом.

Озвучка и страницы лидеров используют проверенные ресурсы этапа 137. Для версии 0.6.2 создаются свежие варианты скриптов с фактической длительностью реплик; старые варианты скриптов stage 137 не используются. Новые подписи и шрифты размещены отдельно в `BetaGwent/build/text138`.

Выход: `BetaGwent/release/GwentBetaClassic-0.6.2-RU.zip` и контрольная сумма `.zip.sha256`. Основной отчёт — `docs/evidence/validation138.json`, исходные составы и контрольные суммы входов — `docs/evidence/inputs138.json`, регрессии — `docs/evidence/regressions138.json`. Логи находятся в `BetaGwent/build/stage138/logs138`.

Файл `BetaGwent/build/stage138/prior-archives.json` хранит контрольные суммы всех пяти архивов 0.6.1 до начала работ; итоговая проверка подтверждает их сохранность. Существующая 0.6.2 при повторной полной сборке сохраняется в `release/quarantine/0.6.2-<дата>`, её замороженный проект — в `build/history138/<дата>`. Архивы 0.6.1 не переименовываются и не заменяются.

Для диагностики доступны `-Step prepare`, `scripts`, `menus`, `package`, `verify`. После изменения исходников запускайте `full`. Нельзя запускать две сборки одновременно: используется общий замок проекта. Сборка не устанавливает мод в игру и не публикует его.

Список новых возможностей интерфейса и сценарии ручной проверки: [UI_0.6.2_RU.md](UI_0.6.2_RU.md). Дополнительно проверьте в игре обе возвращённые колоды, ранний добор шпионом при большом отрыве или отставании и поведение в третьем раунде.
