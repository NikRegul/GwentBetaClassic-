# Гуль и поглощение из сброса: этап48

Правила из строгой Beta0.9.24.3.432; иллюстрация из DIY.
[Граф152](D:/w3mod/docs/evidence/duel-ghoul-source.json),
[RequestCardChoice/tiers IL](D:/w3mod/docs/evidence/beta-grave-choice48-il.json),
[DestroyCards/Banish/AfterBanished IL](D:/w3mod/docs/evidence/beta-consume-passive47-il.json).
Ручная проверка45–48 отложена до общего просмотра; новых console suites нет.

Гуль132306: бронза,4 силы. При розыгрыше можно поглотить один бронзовый или
серебряный **отряд из собственного сброса**. GetCards: own player, location32,
Unit4, Tier6=Bronze2|Silver4, Ignore0. Золотые карты, особые карты, сброс соперника
и уже удалённые карты в выбор не входят. Нет ограничения силы≤7: это правило
Кейрана, не Гуля. RequestCardChoice: min0/max1, выбор необязателен.
При пустом списке RequestCardChoiceNode не создаёт action; Гуль завершает
розыгрыш как отряд4. При отказе из непустого списка — то же поведение.

Текущая сила выбранной карты сохраняется **до** удаления и усиливает Гуля.
Сила карты в сбросе берётся из её текущего состояния после обычного reset,
не из последнего урона на поле. Броня к усилению не добавляется.
Original DestroyCardsNode при Consume1 выделяет для цели в Grave32
CardBanishAttackAction: переход в Void512, без Kill, без второго Killed
и без повторного Завещания. Счётчик сброса уменьшается; картой нельзя
воспользоваться повторно. Preview удерживает скрытый объект/ID для снимков,
полный оригинальный Banished/registry coordinator ещё не переносился.

После Apply Banish исполняется **AfterBanished(Consume)**. Неккеры своей стороны
на поле/в руке/колоде получают+1 с теми же live/Lock/Ambush и player filters,
что для AfterDestroyed(Consume). Различие события хранится явно; генератор
выводит поддержку обоих событий из двух исходных trigger nodes графа151.
Усиление проходит общую очередь до завершения розыгрыша Гуля; полное покрытие
остальных Before/After triggers не заявляется. Поглощение из сброса не активирует
Завещание Неккера/Дао/Гнильца второй раз.

В UI отдельное окно выбора сброса: иллюстрация, название, текущая сила,
описание при наведении, страницы по12 карт и кнопка «Не поглощать».
Условия отбора проверяет серверная сессия. Native bridge передаёт в view
только собственные публичные карты сброса из действующего choice list;
zone32 не рисуется ни в руке, ни на поле. Выбор использует Choices kind1,
обычный Targets kind2 для него отклоняется; revision/requestId и input gate
остаются действующими. Отказ, выбор и пустой сброс завершают корневой розыгрыш
один раз. Сбор может вложенно разыграть Гуля и дождаться этого же окна выбора.

В обеих25-карточных колодах по2 Гуля вместо Грома Альзура и «На куски».
Три Неккера и карты45–47 сохранены. Всего28 definitions/art bindings;
atlas768×900, четыре текстуры досок сохранены. AI оценивает собственный
eligible grave list, текущую силу цели и бонус живых Неккеров; не прибавляет
ценность повторного Завещания и не использует RNG для оценки.

Позже в обычной партии: дать отряду попасть в сброс, сыграть Гуля, выбрать
его в новом окне. Гуль получает силу карты, сброс уменьшается на1, Неккеры
усиливаются; повторное Завещание отсутствует. Заодно посмотреть отказ от
поглощения, пустой сброс и Сбор → Гуль. Логи DUEL_GRAVE_CHOICE,
DUEL_BANISH_CONSUME, DUEL_CONSUME_BOOST fromGrave=true,
DUEL_PASSIVE_CONSUME afterBanished=true, обычные визуальные batch/ack.
Import/menuResource менять не требуется. Последний принятый игровой этап44.
