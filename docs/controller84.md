# Этап84 — управление с контроллера и действие бочек

Обновлено: 2026-10-05. Реализовано в исходниках и подготовлено для REDkit.
Проверка настоящим контроллером ещё не выполнена. Интерфейсом агент не управлял.

| Кнопка Xbox / PlayStation | Действие |
|---|---|
| Крестовина / левый стик | Перемещение видимого золотого фокуса |
| A / × | Выбрать карту, цель, позицию или кнопку меню |
| B / ○ | Закрыть просмотр, отменить предварительный выбор карты, вернуться |
| X / □ | Открыть подробности карты с исходной силой и описанием |
| Y / △, удерживать 0,65 с | Пас на своём ходу |
| Y / △, короткое нажатие; Start / Options | Экран действий в бою |
| LB RB / L1 R1 | Страницы меню; перебор карт/целей/позиций в бою |
| View / Select / touchpad | Посмотреть свою колоду |
| LT RT / L2 R2 | Ваш сброс / сброс соперника |
| R3 | Способность лидера |
| Правый стик | Прокрутка описания; в подробностях также LB/RB |

Системная настройка перестановки подтверждения/отмены учитывается;
подсказки меняются для Xbox и PlayStation. При переходе на мышь/клавиатуру
подсказки контроллера скрываются, запрос курсора переключается обратно.
Кнопки подтверждения удерживаются до отпускания: новый снимок состояния
не приводит к повторному розыгрышу. Стики имеют мёртвую зону и задержку
повтора. Смена меню восстанавливает фокус; закрытые слои исключены из выбора.

После выбора отряда фокус переходит к месту вставки. Каждая допустимая
позиция, включая конец ряда, имеет отдельный узел. Полупрозрачная карта
показывает будущее место, соседи сдвигаются. Подтверждение передаёт
точный anchor/ряд, не использует положение мыши. Особая карта может
подтвердить допустимый отряд или ряд напрямую. Обязательный выбор способности
не пропускается кнопкой отмены; возможность отказа берётся из WitcherScript.

Редактор, каталог, выбор колоды перед NPC, муллиган, просмотр сбросов и
редкий выбор бочки используют ту же навигацию. В редакторе можно выбрать
поле имени/поиска и вызвать штатную виртуальную клавиатуру. Имя становится
окончательным после сохранения колоды. Колода противника не открывается.
Автоматический переход раунда ждёт закрытия просмотра/экрана действий.

Для входа используются коды из локального штатного `KeyCode` и события
Scaleform. Четыре штатных типа `Extensions`, `GamePad`, `GamePadAnalogEvent`
и `KeyboardEventEx` включаются компилятором из установленного REDkit;
файлы SDK не изменяются. Нулевые заглушки констант GamePad нельзя подставлять
как числовые коды: их заполняет GFx, поэтому чтение остаётся динамическим.
См. [документацию расширений Scaleform](https://help.autodesk.com/cloudhelp/ENU/Scaleform-Help/scaleform_help/as3_reference.html).

## Бочки

Лог подтвердил покупку 16 бочек за 2400 крон. Пользователь сообщил,
что в категории «Прочее» отсутствует «Использовать». Перехват
`GetItemActionType` перенесён с `W3GuiPlayerInventoryComponent` в
`W3GuiBaseInventoryComponent`: этот путь сериализует `actionType` предмета
для Flash. Бочка получает `IAT_Consume`, а штатные Buy/Sell/Transfer
производных компонентов сохраняются. Предмет остаётся `misc`, не становится
едой и не получает эффект лечения. Открытие по-прежнему расходует ровно одну
из уже купленных бочек и сохраняет оплаченный редкий выбор.

## Один короткий проход руками

1. Полностью перезапустить REDkit, загрузить отдельный тестовый сейв.
2. Выйти из окна торговли. Выбрать уже купленную бочку в инвентаре:
   должна появиться кнопка «Использовать». Открыть одну, выбрать редкую
   контроллером; убедиться, что осталось на одну бочку меньше.
3. Открыть меню колод: фракция, добавление/удаление карты, имя через
   виртуальную клавиатуру, сохранение; затем каталог и подробности через X/□.
4. Один бой: муллиган; отряд между двумя союзниками и в конец ряда;
   особая карта на цель/ряд; обязательный выбор; просмотр колоды и двух
   сбросов; лидер; удержание Y/△ для паса и автоматический следующий раунд.
5. Проверить смену на мышь и обратно, удержание A/× без двойного действия.

Если что-то не реагирует, сообщить модель контроллера, кнопки и экран;
лог агент прочитает сам. Сборка и проверка ABC не заменяют этот проход.
Далее — тестовый пакет с текущим звуком/ИИ. Полный Wwise и остальные
архетипы ИИ остаются после тестового релиза.

Сборка: Wcc84a успешен, 57 исходников + неизменённый probe. Все три UI имеют
43 функции связи; проверены приёмник native-вызова, арности и присутствие
четырёх типов Scaleform. Ресурсы установлены в workspace GwentB.
