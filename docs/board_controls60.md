# Управление и анимации: версия60

Обновлён интерфейс поля; игровые правила и составы колод из59 сохранены.
В проект установлен новый native ресурс, с резервной копией версии59.
Компиляция AS3/GFx и проверка встроенного bridge успешны. Игровая проверка
управления/анимаций60 ещё не выполнялась.

## Мышь

Клик по карте в руке выбирает её и приподнимает над остальными. Повторный
клик снимает выбор. Доступные ряды подсвечены; полный ряд не предлагается
для отряда. Клик по живому союзнику ставит выбранный отряд перед ним.

Карту из руки можно перетащить. Движение начинается после небольшого смещения
курсора, поэтому обычный клик сохраняется. Под курсором появляется карта с
артом/силой; подсветка показывает подходящий ряд либо место перед союзником.
Отпускание в подходящем месте отправляет одну игровую команду. Отпускание
вне подходящего места оставляет карту в руке и сохраняет выбор.

Перетаскивание доступно в свой ход для карт руки. Для лидера и отряда из
Сбора сохраняется выбор места кликом или клавиатурой. Во время незавершённой
способности и проигрывания последовательности другой розыгрыш недоступен.
Выбор союзника передаётся по ID; позицию/ход/вместимость проверяет WitcherScript.

## Клавиатура

| Клавиши | Действие |
|---|---|
| ← / → | Выбрать карту руки, цель способности, вариант или союзника для вставки. |
| ↑ / ↓ | Выбрать доступный ряд; Enter подтверждает размещение. |
| Enter | Подтвердить выбранную цель/вариант/ряд. Без выбранной цели завершает допустимый необязательный выбор; в лобби начинает партию. |
|1 /2 /3 | Сразу разыграть выбранную карту в свой ближний/дальний/осадный ряд. При погодном запросе выбирают соответствующий ряд соперника. |
| F | Завершить выбор, если правила разрешают кнопку завершения. |
| P | Пас в свой ход. |
| L | Выход доступным лидером. |
| N | Начать следующий раунд, когда он доступен. |
| Space / Enter во время анимации | Пропустить оставшуюся последовательность. |

Фокус выделяется светлой рамкой, описание видно справа. При выборе по
страницам интерфейс сам открывает страницу сфокусированной карты.
Удержание P/L/Enter/Esc не отправляет повторных действий; стрелки повторяются
с ограниченным темпом. До нового авторитетного снимка повторные игровые
отправки блокируются. Закрытие, смена доски и просмотр остаются доступны.

Esc сначала отменяет перетаскивание, снимает выбранную карту либо отменяет
размещение лидера до выхода. Во время анимации пропускает последовательность.
Уже сыгранную способность Esc не откатывает: остаётся выбор цели/варианта,
и завершить его можно кнопкой/F только при разрешении правил. Без выбора
и активного запроса Esc закрывает поле. Кнопка «Закрыть» доступна явно.

## Анимации

- Выход из руки: плавный перелёт по дуге и переход от размера карты руки к размеру на поле.
- Призыв/выход из колоды: перелёт от области колоды или источника способности.
- Вставка: соседи плавно сдвигаются; выделение руки движется быстрее розыгрыша.
- Урон/усиление/броня: цветные вспышки и числа, цвет эффекта зависит от изменения; от источника к цели летит импульс.
- Смерть: карта уменьшается и уходит к сбросу. Обречённая карта исчезает на месте.
- Начало/конец раунда: появление баннера со смещением и плавной прозрачностью.

Внизу справа есть темп1×/1,5×/2× и «Эффекты: полно/кратко». Сокращённый режим
убирает дуги/погодные частицы/летящий импульс и быстро показывает кадры.
Снимки не пропускают игровые события и не исполняют правила; кнопка пропуска
показывает итог уже выполненной последовательности. Настройки хранятся
внутри открытого меню, без изменения сейва.
