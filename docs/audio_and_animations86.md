Из оригинальных ресурсов Beta извлечены звуки UI, попадания, усиления, брони,

диктор и зацикленные premium-preview звуки остаются вне боевого банка.

У особых карт увеличен показ иллюстрации и добавлено увеличение в полёте
из руки. Приземление отряда подчёркивает цвет редкости. Попадание, изменение
силы/брони, число урона, краткая встряска и звук происходят в одной фазе.
Вместо яркой неподвижной линии используется летящий импульс. Учтены скорость
анимаций, сокращённые эффекты и пропуск повтора. Правила матча не задерживаются
анимациями — показывается уже рассчитанная последовательность снимков.

Полный просмотр по I / ПКМ / X показывает исходный tooltip из локализации
Beta0.9.24.3.432 с подстановкой чисел/названий из исходного графа способности,
оригинальные пояснения употреблённых ключевых слов и цитату карты. Начальная
сила берётся из исходного шаблона, включая внутренние призываемые отряды.
Сокращённая подсказка для боя сохраняется отдельно. Скрытые карты противника
не раскрываются. Все479 описаний каталога не содержат незаполненных параметров.

Для имени колоды добавлено отдельное окно: ввод с клавиатуры, буквы мышью
или контроллером, RU/EN, регистр, пробел, стирание, принятие и отмена. Лимит48
символов; пустое имя отклоняется. Принятие меняет черновик; «Сохранить колоду»
записывает его в профиль. Сервер проверяет ревизию и наличие черновика.

Карантир теперь позволяет явно подтвердить противоположный ему ряд без
перемещения отряда, включая пустой ряд. Ряд отмечен «МОРОЗ · без движения»,
его можно выбрать контроллером; LB/RB переключают фокус к ряду. При постановке
Карантира показан будущий Мороз. По правилам этой Beta Мороз идёт в ряд напротив
самого Карантира: произвольный другой ряд выбрать нельзя. Перемещение в этот
ряд остаётся дополнительным выбором отряда.

## Один общий проход после полного перезапуска REDkit

1. В редакторе изменить имя, принять, сохранить; снова открыть колоду и
   проверить имя. Можно попробовать экранные буквы с контроллера.
2. В бою открыть карту по I: полный текст, начальная сила, ключевые слова,
   цитата и прокрутка длинного описания; затем закрыть и продолжить ход.
3. Поставить Карантира и контроллером подтвердить пустой ряд напротив него
   без перемещения. Затем попробовать вариант с перемещением отряда.
4. Несколько розыгрышей/ударов/усилений, погода и одна засада: слышны новые
   фразы/эффекты, удар и изменение числа совпадают; пропуск и ускорение
   анимации позволяют продолжить бой.

После этого — cook/publish, локализация и тестовый пакет для обычной TW3.
Ещё остаются общая приёмка торговли/бочек, наград, сохранений и DLC; отдельные
стратегии остальных архетипов ИИ идут после первой тестовой версии.
