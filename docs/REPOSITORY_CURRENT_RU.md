# Состояние репозитория на 12 октября 2026

Текущая линия — **0.6.2 / Stage 138**. Пять полных пакетов озвучки: EN, RU, DE, IT, PT-BR; каждый содержит 13 переключаемых языков текста. Новая локализация интерфейса пробная и ожидает отзывов носителей. DE/IT используют русский голос тролля. Портреты 21 лидера анимированы; обычные premium-карты не включены. Добавлена крупная двумерная сцена лидера; оригинальные трёхмерные появления остаются в плане.

RU-пакет 0.6.2 собран и проверен: 52 набора регрессий, нативная компиляция 70 WitcherScript-исходников и четырёх меню, 282 страницы анимаций, CRC/manifest/SHA-256. Отчёт — `docs/evidence/validation138.json`; ручная игровая приёмка и остальные четыре пакета 0.6.2 ещё не подтверждены. Исправление падения лидеров из 0.6.1 ранее подтверждено пользователем на RU. Сравнение старого и нового ИИ ведётся отдельно.

В 0.6.2 включены история действий, цепочки способностей, плавная рука и фокус, редактор с пояснениями и отменой, раскрытие бочек и настройки эффектов. Возвращены два состава колод и изменена оценка шпионов с добором. [Подробности и ручные сценарии](UI_0.6.2_RU.md).

## История и границы подтверждения

Номер этапа в имени инструмента/отчёта не равен версии мода. Старые планы, README этапов и отчёты оставлены как история: их обещания и формулировки «текущий» не описывают автоматически 0.6.2. Текущий план — `ROADMAP_1.0_RU.md`, текущий сборочный вход — `Build-0.6.2.ps1`.

Публичный репозиторий содержит исходники и документацию, а рабочая папка дополнительно содержит исходные игровые ресурсы, SDK, лицензированные локальные Wwise-проекты, результаты сборок и исследовательские данные. Эти наборы различаются намеренно. Для обновления публичного репозитория используется существующая отдельная Git-копия `BetaGwent/build/github-0.3.0`; исходники копируются без переключения рабочей ветки и без изменения входов выполняющейся сборки.
