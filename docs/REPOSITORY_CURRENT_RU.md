# Состояние репозитория на 13 октября 2026

Текущие исходники — **0.6.6 / Stage 142**, готов русский тестовый пакет. Добавлены специальные эффекты, общий каст погоды, одновременные усиления, 12 одноразовых вступлений лидеров и девять динамических циклов для остальных, стабильный правый портрет, история и подсказки целей, бочки у всех корчмарей. Включены актуальные исправления ИИ другого агента и регрессия Лже-Цири/Фрингильи/Мангонеля. 50 наборов регрессий, нативная компиляция 70 скриптов и четырёх меню, проверка ресурсов, архива и звукового кэша пройдены: `docs/evidence/validation142.json`. Игровая приёмка остаётся открытой. [Подробности](PRESENTATION142_RU.md), [сборка](BUILD_0.6.6_RU.md). Остальные четыре голосовых архива остаются на 0.6.3.

Полный набор голосовых пакетов — **0.6.3 / Stage 139**. Пять полных пакетов озвучки: EN, RU, DE, IT, PT-BR; каждый содержит 13 переключаемых языков текста. Языки и озвучка сохранены из 0.6.2 по выбору пользователя. DE/IT используют русский голос тролля. Портреты 21 лидера анимированы; обычные premium-иллюстрации не включены. Оригинальные трёхмерные появления лидеров остаются в плане.

Пройдены 39 наборов регрессий, включая 1070 проверок вычислений анимаций и 36 проверок воспроизведённой ошибки ИИ. Нативно скомпилированы пять наборов по 70 WitcherScript-исходников и четыре меню. Все пять архивов прошли ZIP/manifest/SHA-256, сверку исходников, меню и банков озвучки; архивы 0.6.2 сохранены без изменений. Завершённый отчёт — `docs/evidence/validation139.json`. Пользователь сообщил, что проверенная им 0.6.2 пока работает нормально; это не закрывает полную матрицу лидеров, сохранений и языков. Новая 0.6.3 требует наблюдения в игре.

В 0.6.3 исправлен лишний расход ценных карт после паса, синхронизация полёта/эффектов/чисел/звука при ускорении, добавлены дуги при перемещении, последовательные перевороты и сохранение полной рамки при удалении. Составы и правила карт прежние. Парное сравнение всех 46 архетипов: 184 партии, 92 победы и 92 поражения нового ИИ, 0 ошибок; рост общей силы не подтверждён. [Подробности и ручные сценарии](AI_ANIMATIONS_0.6.3_RU.md).

## История и границы подтверждения

Номер этапа в имени инструмента/отчёта не равен версии мода. Старые планы, README этапов и отчёты оставлены как история: их обещания и формулировки «текущий» не описывают автоматически 0.6.6. Текущий план — `ROADMAP_1.0_RU.md`, текущий сборочный вход — `Build-0.6.6.ps1`.

Публичный репозиторий содержит исходники и документацию, а рабочая папка дополнительно содержит исходные игровые ресурсы, SDK, лицензированные локальные Wwise-проекты, результаты сборок и исследовательские данные. Эти наборы различаются намеренно. Для обновления публичного репозитория используется существующая отдельная Git-копия `BetaGwent/build/github-0.3.0`; исходники копируются без переключения рабочей ветки и без изменения входов выполняющейся сборки.
