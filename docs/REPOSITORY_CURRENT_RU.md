# Состояние репозитория на 12 октября 2026

Текущая линия — **0.6.1 / Stage 137**. Пять полных пакетов озвучки: EN, RU, DE, IT, PT-BR; каждый содержит 13 переключаемых языков текста. Новая локализация интерфейса пробная и ожидает отзывов носителей. DE/IT используют русский голос тролля. Портреты 21 лидера анимированы; обычные premium-карты и крупные анимации появления не включены.

Исправлена причина нативного падения при показе лидеров. Пользователь подтвердил исчезновение падения на исправленном RU и сам запустил сборку всех пяти пакетов. Последняя завершённая проверка исправления: 49 наборов регрессий, свежие 70 WitcherScript-исходников, четыре меню, 282 страницы анимаций, CRC/manifest/SHA-256 RU-архива. Это не означает полной игровой приёмки всех пакетов. Итог новой сборки следует смотреть в её собственном `docs/evidence/validation137.json`.

## История и границы подтверждения

Номер этапа в имени инструмента/отчёта не равен версии мода. Старые планы, README этапов и отчёты оставлены как история: их обещания и формулировки «текущий» не описывают автоматически 0.6.1. Текущий план — `ROADMAP_1.0_RU.md`, текущий сборочный вход — `Build-0.6.1.ps1`.

Публичный репозиторий содержит исходники и документацию, а рабочая папка дополнительно содержит исходные игровые ресурсы, SDK, лицензированные локальные Wwise-проекты, результаты сборок и исследовательские данные. Эти наборы различаются намеренно. Для обновления публичного репозитория используется существующая отдельная Git-копия `BetaGwent/build/github-0.3.0`; исходники копируются без переключения рабочей ветки и без изменения входов выполняющейся сборки.
