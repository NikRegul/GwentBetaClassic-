# Gwent Beta Classic 0.8.0

Shared release line for Next-Gen and Classic 1.32. Five voice packages per platform: RU, EN, DE, IT, PT-BR; each includes all 13 selectable text languages.

Retains the 0.7.4b drawBacks fix and all combat effects, NG+ keg fixes and lossless atlas compaction. The user confirmed battle startup in 0.7.4b. Classic uses the same frozen source stage with platform adapters, its own text input bridge and 1.32 resource/audio formats.

Compilation and package verification do not replace gameplay acceptance. Test the full duel flow, effects, purchases, audio and save round trips on each platform. Install only one voice package matching your game version.
