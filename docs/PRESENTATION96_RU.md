# Gwent Beta Classic 0.2.3 — исправление загрузки больших меню

Пользователь подтвердил: установленная 0.2.2 снова скрывает интерфейс при
открытии редактора и зависает на старте NPC, при этом REDkit работает.
Хеши всех установленных файлов совпадают с архивом. Исправление буфера cook
было необходимо, но проблему загрузки обычной игры не устранило.

У 0.2.2 каждый готовый redswf содержит около 99 MiB. У принятой 0.2.0 —
около 53 MiB. В стандартных ресурсных настройках игры бюджет распаковки
70 MiB, GUI-текстур — 80 MiB. Это сильная гипотеза причины остановки;
без игрового лога нельзя считать её доказанной.

## Изменение 0.2.3

Текстуры вынесены из огромного redswf в 15 отдельных родных redswfx-ресурсов,
общих для трёх меню. Меню осталось около 145 KiB; самая большая текстура —
меньше 16 MiB. Ни один файл GUI не должен превышать защитный порог 25 MiB.
Готовые зависимости, внешние handles, CRC, пиксели, размеры, формат и код GFx
проверяются после native cook. Формат ссылок сверён с CHandle и CR2WImport
в исходниках WolvenKit; классы CSwfTexture/redswfx есть в REDkit и игровом exe.

Карты остаются 384×540. Пиксели, эффекты, оформление и механика 0.2.2 сохранены.
Настройки основной игры не изменяются. Рабочие ресурсы REDkit не заменяются.

## Проверка

1. Сделать резервную копию сохранений и полностью закрыть игру.
2. Заменить Mods/modBetaGwent0924 из нового RU-архива. Новая игра не нужна.
3. В загруженной игре ESC → «Колода для игры в гвинт»: открыть список,
   отредактировать колоду и вернуться в игру.
4. Начать партию с NPC, пройти выбор/замену карт; проверить иллюстрации
   и полный просмотр. Затем ещё раз открыть редактор после боя.

Успешные проверки ресурсов не заменяют этот игровой проход. До подтверждения
новый пакет не публикуется в Git/Nexus/Steam. Если загрузка снова остановится,
дальше потребуется трасса запуска из обычной игры; REDkit её не заменяет.
