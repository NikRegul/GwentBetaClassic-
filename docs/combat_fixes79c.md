## Звук: установленный банк ещё не загружен

Пользователь сообщил отсутствие фраз и обычный звук. Последний editor.log
подтверждает `AUDIO_READY betaBankInstalled=true`, затем в15:06:14 и15:08:47
`AUDIO_BANK_PENDING nativeLoaded=false`. Это не подтверждение работы звука.
UI теперь различает наличие файла и нативную загрузку банка: до загрузки
пишет «Фразы: банк не загружен». Проверка загрузки продолжает работать и
при выключенных фразах. Подготовлен отдельный пакет дополнительного банка
`BetaGwent/build/audio79-redkit-reload`, без Init.bnk и записи Init в метаданных.

Ручной шаг по [официальной инструкции REDkit](https://cdprojektred.atlassian.net/wiki/spaces/W3REDkit/pages/6327994/HOW-TO%3A%2BImplement%2Bsounds%2Band%2Buse%2BWwise):

1. После полного перезапуска открыть проект. В **Tools → Sound → Set WWISE path**
   при необходимости указать установку `C:\Audiokinetic\Wwise_2023.1.19.8928`.
2. **Tools → Sound → Reload soundbanks** — выбрать только `BetaGwent79`.
   Файл банка: `D:\w3mod\BetaGwent\build\audio79-redkit-reload\BetaGwent79.bnk`.
   Исходный Wwise-проект: `D:\w3mod\BetaGwent\audio\wwise\BetaGwent79.wproj`;
   исходная папка вывода: `GeneratedSoundBanks\Windows` внутри него.
   Если новый банк отсутствует в диалоге, сообщить содержимое этого диалога;
   регистрация пока не подтверждена. Init.bnk импортировать не нужно.
3. Закрыть/открыть поле и сыграть Геральта из Ривии112103 или лидера с фразой.
   Агент проверит AUDIO_BANK_LOADED/AUDIO_VOICE_REQUEST после этого действия.

## Один проход проверки исправлений

После перезапуска использовать `bgboard_open()`:

1. Несколько новых партий: встречается и первый ход соперника; после замены
   карт начинается ход выпавшей стороны.
2. Офицер: выбрать одну карту руки — второго окна выбора из колоды нет;
   размер руки восстанавливается, Офицер получает соответствующее усиление.
3. Итлина → Гром: разрешаются два розыгрыша, без «Созданная карта не найдена».
4. Дрессировщик: появляется Медведь11 с выбором позиции, без ошибки токена.
5. Мечник: ранить, дождаться двух своих ходов и повторить цикл; счётчик
   возвращается к2. Проверить также полный здоровый цикл без укрепления.
6. Сила белая/красная/зелёная соответствует состоянию в руке, на поле,
   в окне выбора и при просмотре сброса. Открыть оба сброса и свою колоду.
