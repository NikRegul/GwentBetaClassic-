# Колоды ИИ 0.9.1b: составы и поведение

20 октября 2026. Изменения внесены по указаниям автора. Числа ниже — промежуточные результаты автопартий ИИ против ИИ на максимальной сложности: случайный соперник из 46 профилей, случайный seed, случайная сторона. Это не человеческий тир-лист. При 80–150 партиях погрешность составляет примерно ±8–10 процентных пунктов. Итоговое распределение всех 46 колод ещё не досчитано.

## Поведение ИИ

Профиль 3 (пресет 56):
- Накеры и Жальница — финишеры: в 1–2 раундах резерв 10 и штраф к раннему розыгрышу. Мируна в решающем раунде ставится заранее из-за таймера.
- Корм: своего Накера не скармливать (−10), заряженного Огромного главоглаза тоже (−8), Ольгерд — предпочтительный корм (+4). Правило действует для Кейрана, Врана (выбор опоры) и Королевы.
- Пугач-шпион ставится в ряд напротив своей Мируны с активным таймером, если окажется там сильнейшим: его очаруют обратно.
- Двойной крест: только если сильнейший отряд колоды — Пугач. Тогда +12 при Мируне на поле и −10 без неё.
- Жальница — после Ослизгов, Гнезда и Вранов. Стрегобор — после выхода Трутней.

Профиль 5 (пресет 58):
- Кровавые бичи меняются в муллигане, если в руке есть Замученный чародей. Оставляется до двух Чародеев, Чародеек и Рыцарей.
- Добивание Сабрины проверяется настоящей симуляцией с любыми картами, способными её убить. Раньше учитывались только Роше и Чародейка; теперь также Кровавый бич, дуэль Зельткирка, Гром Детмольда, Замученный чародей, Рубайл, Наталис и Приказ.

Общие правила (действуют для всех колод с этими картами):
- Засада на поле оценивается по эффекту, а не только по силе: Моренн +5, Моренн: дитя леса +3, Малена — сила вероятной цели очарования, Торувьель — до +8 по соседям.
- Боец «Импера» получает бонус подготовки за своих шпионов в руке (как Бригада «Импера»).
- Поглощение Архиспоры учитывает её Завещание (4 урона). Архиспора добавлена в движки, связки Архиспора → Грифон / Циклоп / Вилохвост.

Регрессии `check_consume_self`, `check_spy138`, `check_combo127`, `check_engines126`, `check_emissary_mulligan181`, `check_miruna_aglais_scorch180`, `check_followups126`, `check_no_targets127` проходят на новом снимке так же, как на базе. Нативная компиляция и игровая проверка ещё не выполнены.

## Продолжение прогона

`tmp/decks091/par.js` — параллельный случайный прогон, с ограничением памяти: один контекст движка на процесс по умолчанию.

```
node par.js config.json
{"workers":8,"out":"results/x.json","games":200,"jobs":[{"label":"56 new","snap":"snaps/c7","preset":56}]}
{"workers":8,"out":"results/rank.json","ranking":{"snap":"snaps/c7","games":1500}}
```

Режим `ranking` играет случайные пары из всего пула и засчитывает каждую партию обеим колодам — так получается распределение всех 46 колод. Снимки: `snaps/base` — 0.9.1 до изменений, `snaps/c7` — итог 0.9.1b. Файл `STOP` в папке конфигурации останавливает прогон.
